# KEI truck のエンジン音・走行音（v0.88.1）

## 2026-11-25 のユーザー決定

- Q3 は大きなマフラーの低く太い排気音。踏み込むと高く大きく吠え、アクセルを離すと時々「バリバリ・パンッ」と鳴る。BGM や画面の台詞を邪魔しない音量にする。
- Q4 は b・c。傷んだ車はせき込み、燃料が少ないと息つぎし、燃料が尽きると止まる。改修が進むと低音が太くなり、少し大きくなる。
- Q5 は B。「車の音」を独立したオン・オフ設定にし、初期値をオンにする。

## 音の作りと暫定値

| 音 | 使う値と合成 |
|---|---|
| セル・始動 | 乗車時に周波数を揺らした三角波で約0.65秒セルを回す。燃料があれば回転を約0.43秒ふかす。燃料0ではセルだけで止まる。 |
| アイドリング・加速 | 歪ませた鋸歯波の音量を脈動させ、半分の周波数の三角波を重ねる。段階0では基本周波数42Hz、速度とアクセルで最大99Hz上がる。 |
| マフラー | 高回転でペダルを戻すと、負荷に応じた確率で雑音を2〜4発鳴らす。発音間隔は約75ms。 |
| 転がり・きしみ | 車輪の接地率と速度に応じた帯域雑音。舗装路と、それ以外の草地・土・砂利を既存の道路判定で分ける。速度4m/秒を超え、横滑りが0.25m/秒を超えるときしみ始める。 |
| 着地 | 0.15秒を超えて浮いた後の接地で、165Hz以下を中心にした雑音を約0.26秒鳴らす。 |
| 停止 | 降車・燃料切れで回転を下げ、約0.38秒で止める。乗車したまま燃料を足すとセルから再開する。 |
| 傷み・燃料不足 | 車体が最大の30%未満で約0.25秒せき込み、燃料が15%以下で約0.16秒息つぎする。間隔は1.4〜3.1ゲーム秒。両方に当てはまると交互に鳴る。 |
| 改修 | 1段階ごとに基本周波数を1.1Hz下げ、低音の混ぜ方を0.055、排気の音量倍率を0.026増やす。 |

初回乗車時に連続音の Web Audio ノードを作り、同じノードの周波数と音量を更新する。破裂・着地は共有の雑音バッファを使い、再生終了時にノードを切り離す。地域の読み込みを始める時点で消音し、到着後はペダルを戻して踏み直すと再始動する。タイトルへ戻る時も消音する。一時停止とメニューでは車のバスを半分にし、台詞の表示中は通常の65%に絞る。

## 設定とセーブ

「車の音」は `AU.car` の音量を切り替える。設定キー `REWILDED_EIHEIJI_SETTINGS` の `v:1` に `car` を保存し、項目のない旧設定はオンとして読む。試遊版のビルドが置き換える設定キー名は従来どおり。ゲームのセーブ形式と運転・燃料・傷み・改修のゲーム内数値は従来どおり。

## テストと未確認

- `node tests/truck-sound.cjs` は Playwright で光明寺の修理済み車に乗り、音の周波数・音量・発音回数、設定の保存と旧設定、幅320pxでの表示、地域移動とタイトルでの停止、ページエラーを確認する。三次元描画用の `three.min.js` は `THREE_JS` で指定できる。このブラウザーテストは砂場の外で実行する。
- 砂場では `node --check tests/truck-sound.cjs` と `truck-physics.cjs`、`chapter2-save.cjs`、`hurt-drop.cjs`、`p3e2-herb.cjs` の Node テストが通過した。
- 低音の太さ、破裂の聞こえ方、BGM や台詞表示中の音量バランスは PC とスマホの実機で試聴する。
