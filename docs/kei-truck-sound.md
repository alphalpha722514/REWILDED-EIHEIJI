# KEI truck のエンジン音・走行音（v0.88.1）

## 2026-11-25 のユーザー決定

- Q3 は大きなマフラーの低く太い排気音。踏み込むと高く大きく吠え、アクセルを離すと時々「バリバリ・パンッ」と鳴る。BGM や画面の台詞を邪魔しない音量にする。
- Q4 は b・c。傷んだ車はせき込み、燃料が少ないと息つぎし、燃料が尽きると止まる。改修が進むと低音が太くなり、少し大きくなる。
- Q5 は B。「車の音」を独立したオン・オフ設定にし、初期値をオンにする。

## 音の作りと暫定値

| 音 | 使う値と合成 |
|---|---|
| セル・始動 | 乗車時に周波数を揺らした三角波で約0.65秒セルを回す。燃料があれば回転を約0.43秒ふかす。燃料0ではセルだけで止まる。（2026-11-25 に作り直し） |
| アイドリング・加速 | 歪ませた鋸歯波の音量を脈動させ、半分の周波数の三角波を重ねる。段階0では基本周波数42Hz、速度とアクセルで最大99Hz上がる。（2026-11-25 に作り直し） |
| マフラー | 高回転でペダルを戻すと、負荷に応じた確率で雑音を2〜4発鳴らす。発音間隔は約75ms。（2026-11-25 に作り直し） |
| 転がり・きしみ | 車輪の接地率と速度に応じた帯域雑音。舗装路と、それ以外の草地・土・砂利を既存の道路判定で分ける。速度4m/秒を超え、横滑りが0.25m/秒を超えるときしみ始める。 |
| 着地 | 0.15秒を超えて浮いた後の接地で、165Hz以下を中心にした雑音を約0.26秒鳴らす。 |
| 停止 | 降車・燃料切れで回転を下げ、約0.38秒で止める。乗車したまま燃料を足すとセルから再開する。（2026-11-25 に作り直し） |
| 傷み・燃料不足 | 車体が最大の30%未満で約0.25秒せき込み、燃料が15%以下で約0.16秒息つぎする。間隔は1.4〜3.1ゲーム秒。両方に当てはまると交互に鳴る。（2026-11-25 に作り直し） |
| 改修 | 1段階ごとに基本周波数を1.1Hz下げ、低音の混ぜ方を0.055、排気の音量倍率を0.026増やす。（2026-11-25 に作り直し） |

初回乗車時に連続音の Web Audio ノードを作り、同じノードの周波数と音量を更新する。破裂・着地は共有の雑音バッファを使い、再生終了時にノードを切り離す。地域の読み込みを始める時点で消音し、到着後はペダルを戻して踏み直すと再始動する。タイトルへ戻る時も消音する。一時停止とメニューでは車のバスを半分にし、台詞の表示中は通常の65%に絞る。

## 2026-11-25 作り直し（試遊の結果）

iPhone での試遊では「アクセルを踏んでいる時の音が唸り声のように聞こえる」とのことだった。「マニュアル車のトランスミッションの切り替えの時になる**間**と、**盛り上がって行く排気音**」を、速度に応じてうるさくなる日本のスポーツカーの走行音を手本に作り直した。以前は人の声に近い高さの鋸歯波を同じ高さで脈動させ、速さとアクセルを混ぜて滑らかに上下させていた。変速に伴う回転落ちもなく、ひと続きの唸り声のように聞こえやすかった。

- 音専用の仮想ギアは5段。暫定のギア比は 3.4、2.15、1.55、1.18、0.92。回転数は車速とギア比から求め、車の現在の最高速で5速が約6600rpmになるように補正する。アイドリングは900rpm、発進は半クラッチで、車速から求めた回転数と、900rpmにアクセルに応じて最大2600rpmを足した値のうち、高い方を使う。後退は1速扱い。5速の最高速で全開を続けても約6600rpmで回り、燃料カットは入らない。燃料カットはシフトアップできない5速で全開のままレッドゾーン（7800rpm）に達したときに働き、約0.06秒周期で排気が途切れる。（2026-11-25 の2回目でアイドリング850rpm、5速の最高速で約6000rpm、レッドゾーン7200rpmに変更）
- 約4200〜7300rpmでアクセルの深さに応じてシフトアップする。約0.10秒で排気をしぼりつつ回転を落とし、約0.16秒でつなぎ直す。変速時は確率0.35で小さな破裂音が1〜2発鳴る。約2300rpm未満でシフトダウンし、踏んでいれば約0.15秒の吹け上がりで回転を合わせる。数値は暫定。（2026-11-25 の2回目でシフトアップ4000〜6800rpm、シフトダウン2200rpmに変更）
- 直列6気筒の4ストロークを手本に、2回転を一周期とする72次までの波形を一度作る。6の倍数の倍音を強めて燃焼の脈を並べ、他の倍音を控えめに混ぜてばらつきを足す。燃焼の頻度はアイドリングで45Hz、レッドゾーンで390Hz。燃焼に合わせて帯域雑音の音量を揺らし、高回転で強く踏むと吸気の帯域雑音が重なる。低域通過フィルターの切れ目は回転数と負荷で動き、踏み込むほど高い倍音が聞こえる。（2026-11-25 の2回目で下記の水平対向4気筒・不等長の音に変更）
- 回転数、アクセル、車速に応じて排気音量が上がり、変速中は約3割にしぼむ。改修で低音が太くなり、音量も少し上がる。エンジンのゲインは従来の最大値と同程度に抑え、一時停止中は半分、台詞中は0.65倍。始動時は約2200rpmまで吹け上がり、地域移動後はセルを回さずアイドリングから再開する。
- 走りの物理と燃料・傷み・改修の数値、セーブと設定の形式は従来どおり。アフターファイア、せき込み、息つぎ、停止音、転がり、きしみ、着地音も引き続き鳴る。
- ブラウザーのテストでは回転数、ギア、変速中の音量、発振器と波形の使い回しを確認する。排気の立ち上がり、変速の間、他の音とのバランスがiPhoneの実機でどう聞こえるかは未確認。

### 2026-11-25 の2回目の試聴

録音を聞いたユーザーから「改善は見られたので、その調子で。**まだ音が軽いので、もっと太く**。**モーターではなく、エンジンの音であることが伝わるように**してほしい」との感想があった。

- 暫定で水平対向4気筒・不等長の排気音に変更した。基本周波数は回転数÷120、燃焼の頻度は回転数÷30（アイドリング約28Hz、レッドゾーン240Hz）。作り置きの波形では4・8・12…次の燃焼の倍音を強くし、2・6・10…次を対応する燃焼倍音の約6割、奇数次を約4分の1重ねて、2発ずつまとまる脈を作る。
- 燃焼周波数の約半分でローパスした雑音で、脈の周波数と音量を揺らす。目安はアイドリングで約±2%と±30%、高回転で約±0.6%と±12%。アイドリングではさらに0.5〜1.5秒ごとに回転が約±2%の範囲でゆっくり動く。
- 脈を整流して帯域雑音の音量を開閉し、燃焼に合わせて「バッ」という音を重ねる。雑音の中心周波数は燃焼周波数の8〜12倍で、アイドリングの変調の深さは全開の36%。吸気の音量は前回の半分にした。
- 脈と低音を係数3の tanh で歪ませ、600Hzのローパスを通す。排気の音色は燃焼周波数×（2.5＋3×負荷）、上限2400Hzのローパスで暗めにする。150Hzのローシェルフで低域を6dB上げ、95Hz・Q 0.9・+4dBのゆるいピーキングでマフラーの胴の響きを足す。改修で歪みと低音の量が少し増える。歪みと低域補正で増える音量を見込んで出力を0.70倍に調整した。全開時の聞こえ方と音量は実機での試聴待ち。
- ブラウザーのテストには乱れのローパスと整流の確認を加え、走行中に発振器、波形、WaveShaper を作り足さないことも確かめる。

光明寺でアイドリング → 全開 → 離す → 半分 → ブレーキ → 降車の順に録音し、帯域ごとの音の割合を測った。各欄は 20–150 / 150–500 / 500–2000 / 2000–8000 Hz の順（%）。

| 区間 | 2回目 | 3回目 |
|---|---|---|
| アイドリング | 94.5 / 5.5 / 0.0 / 0.0 | 99.9 / 0.1 / 0.0 / 0.0 |
| 加速（2〜3速） | 1.6 / 80.2 / 16.3 / 1.9 | 88.0 / 11.5 / 0.5 / 0.1 |
| 最高速で全開 | 0.7 / 81.1 / 16.0 / 2.1 | 84.8 / 14.4 / 0.8 / 0.1 |
| 半分の踏み込み | 4.7 / 73.2 / 21.5 / 0.6 | 60.4 / 37.2 / 2.3 / 0.1 |

録音全体は2回目が平均 −19.9dB・最大 −6.9dB、3回目が平均 −17.2dB・最大 −5.3dB。3回目は20〜60Hzに強い成分が続いた。

4回目は45Hzのハイパスを追加し、三角波を燃焼と同じ周波数・半分の量にした。低域補正を+3dB、胴の響きを110Hz・+3dBにし、歪み後のローパスを1500Hz、負荷で動くマフラーのローパスを350〜2600Hzに広げた。燃焼に合わせた帯域雑音は2.5倍にし、中心の範囲を300〜2500Hz、Qを0.8とした。出力の `trim` は見積もりで0.78倍にした。再録音では加速・全開で低い方から3帯域を30〜50%・35〜55%・6〜15%、アイドリングの150〜500Hzを25%以上、平均・最大音量を2回目の±1.5dB以内とするのが目標。

## 設定とセーブ

「車の音」は `AU.car` の音量を切り替える。設定キー `REWILDED_EIHEIJI_SETTINGS` の `v:1` に `car` を保存し、項目のない旧設定はオンとして読む。試遊版のビルドが置き換える設定キー名は従来どおり。ゲームのセーブ形式と運転・燃料・傷み・改修のゲーム内数値は従来どおり。
