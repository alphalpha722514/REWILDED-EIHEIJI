# 台詞・呼び方の変更の記録

確定した台詞を変えたときに、いつ・誰の指示で・どこを変えたかを残す。

## v0.79.3（2026-11-18）住民はヌシを「化け猪」と呼ぶ

- 2026-11-18 14:28 ユーザー：「区長のトミオを含めヌシについて何かしら会話をする住民がいればヌシの呼び方を化け猪に変えてください」
- 変えたのは、**住民が話す台詞**の中の「ヌシ」だけ（6か所）。

| 話す人 | 場面 | 前 | 後 |
|---|---|---|---|
| トミオ | 「いま大事なこと」（ヌシ討伐へ向かう段階） | 沢の奥の広場で、光明寺のヌシを討っておくれ | 沢の奥の広場で、光明寺の化け猪を討っておくれ |
| トミオ | 「いま大事なこと」（ヌシ戦の段階） | ヌシを討っておくれ | 化け猪を討っておくれ |
| トミオ | 場面ごとの一言（討伐のあと） | ヌシがおらんようになって、山も少し静かになったのう。 | 化け猪がおらんようになって、山も少し静かになったのう。 |
| トミオ | 侵攻が明けたあとの会話 | 群れを追い立てとったのは“光明寺のヌシ”と呼ばれる大イノシシやろう。… | 群れを追い立てとったのは“光明寺の化け猪”と呼ばれる大イノシシやろう。… |
| 米田 | 同じ会話 | ヌシは突っ込んできたら止まらんらしい。… | 化け猪は突っ込んできたら止まらんらしい。… |
| トミオ | ヌシ討伐へ向かう前に話しかけたとき | ヌシは沢の奥、高速道路の高架をくぐった先の広場や。… | 化け猪は沢の奥、高速道路の高架をくぐった先の広場や。… |

- 源さん・慧心・スズキの台詞には、ヌシの呼び名は出てこない（コードで確かめた）。
- **変えていないもの**（住民の台詞ではないため）：
  - ヌシ自身の名前と台詞。最後の対話の「光明寺のヌシ」と、確定した遺言。
  - 画面の表示。体力の帯の名前「光明寺のヌシ」、討伐の画面、目的欄、知らせ（「ヌシが怒り狂った！」など）、倒れたときの助言。
  - 品名と説明。「ヌシの牙」、牙槍の説明「ヌシの牙を穂先にした槍」、「ヌシ討伐で解放」、持ち物の説明。
  - 足跡を調べたときの「ヌシの足跡」（主人公が見たことの文）。
- これらも「化け猪」にするかは、ユーザーが決める。
