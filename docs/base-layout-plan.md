## 2. 止めにくい理由
- 車両基地（南西の隅）へは、南門を入ってすぐ左の見張り台 (144,73) をよけて北へ回り、無線室 (135,66) の南を西へ曲がって、柱の間（約4m）に入れる。S字に2回曲がるので止めにくい。
- 基地の柱の間が狭い（4.0m。車は幅2.1m・当たりは半径1.5m）。

## 3. 案

### 案A：車両基地を南門の外（南東の原っぱ）へ（拠点の中は変えない）
- 車両基地を (167, 88)、入口を南（国道の方）へ。国道から真っすぐ北へ入って止める（出るときは下がる）。
- よい点：拠点の建物を動かさない。物語・防衛戦への影響がいちばん小さい。道から近い。
- 悪い点：
  - 丸太置き場（約33m）・作業台・かまどから遠いので、荷台の素材を直接使えない。丸太は源さんの運搬に頼る。
  - 柵の外なので、防衛戦の南の獣の通り道（x 146〜156）に近い。ただし14mほど東にずれていて、止めた車は襲われない（2026-11-18 決定）。

### 案B：拠点の南東を「車と作業の区画」に（**おすすめ**）
- 車両基地を南東 (164.5, 68.5)、入口を西へ。南門から入って北へ少し進み、右（東）へ曲がって真っすぐ入るだけ（曲がるのは1回）。
- 資材倉庫を南西の隅（今の車両基地の所、(135.5, 72.5)）へ移す。作業台を少し北の (158, 61.5) へ移す（車の通り道を空ける）。
- かまど (161,73.9)・変換炉 (166,73.4)・作業台・丸太置き場が、止めた車から 5〜12m。荷台の素材で作る・建てる（12m 以内）と、丸太置き場に納める（14m 以内）が、基地に止めたままできる。
- 動かすもの：資材倉庫（飾り）・作業台・車両基地の3つ。物語の場所（無線室・集会所）・門・見張り台・防衛の的は動かさない。
- 気をつけること：
  - KEI truck を直す前の部品・燃料の置き場所は資材倉庫のそばなので、いっしょに南西へ移る（作業F の道案内は場所を計算で出すので動く）。
  - 南東の建物が変わるので、防衛戦の獣の動きが少し変わる。勝率を測り直す（`tools/defense-sim.cjs`）。
  - 作業台の場所を使っているテストを直す。

### 案C（参考）：拠点全体を区画分けし直す
- 北＝暮らし（集会所・食料庫・救護）、中央＝守り（火の見やぐら）、西＝田畑、南＝車と作業、のように大きく並べ替える。
- 無線室・集会所など物語の場所も動かすことになり、作業F の場面・テストの作り直しが大きい。今回はおすすめしない。
