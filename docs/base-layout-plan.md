## 3. 田んぼの役目（v0.79。数は 2026-11-18 10:50 ユーザー「良い」。試遊で変えることはある）
- 前は飾り（稲が並んでいるだけ）。v0.79 で「田植え → 育つ → 草取り → 稲刈り」をできるようにした。
- 田んぼのそばで調べると：
  - 育っている間：「田んぼ：稲が育っている ■■□□□　草取りをする（残りを20%短く）」（1回の育ちで1度）
  - 実ったら：「田んぼ：稲を刈る（米 +10・藁 +10・稲の種 +2）」
  - 刈ったあと（水だけ）：「田んぼ：田植えをする（稲の種1）」
- 育つのにかかる時間：600秒（遊んだ時間。拠点にいなくても進む）。
- 新しいゲーム・田んぼの記録が無い旧セーブ：今の見た目（育っている途中、半分）から始め、最初の1回は種なしで刈れる。
- 見た目：育ち具合で稲の高さと色が変わる（若い緑 → 濃い緑 → 実ると黄金色）。田植えの前は水だけ。
- 共同菜園（米田の畑、稲は4つ）より大きい収穫で、藁（縄・笠・保冷箱など）と米（料理）のまとまった入手先にした。
- セーブ：新しいキー `paddy:{v:1,st,t,care}`（`st` 1=水だけ・2=育っている・3=実った、`t` 育った秒、`care` 草取りしたか）。無ければ上の初期値。
