# E3-3a よろず屋の実装を引き継ぐ

v0.91 の house110 は、1階が中央通路のある売場・レジ・裏倉庫、2階が店主の住まい。拠点設立後、古い農家の蔵の棚で地図を手に入れ、よろず屋の正面で E または行動ボタンを押す。地図を持っていないと「ここから入る手がかりがない」と表示する。通常退出では入店時の店先へ、「つづきから」では上志比の屋外到着点へ戻る。

### E3-3b で家具の位置を参照する

`P3IN.shop.floors[1].plan().fixtures` に、描画と当たりの生成にも使う10件の静的な配置がある。安定した `id` は居間が `kotatsu`・`tvStand`・`phoneStand`、寝室が `futon`・`dresser`、台所が `sink`・`stove`・`cupboard`・`fridge`、収納が `linenCloset`。各要素の `room` は部屋ID、`x,z` は階内の配置原点（m）、`turn` は正面 +z からのY軸回転を90度単位で示す。

たとえば箪笥は `fixtures.find(f => f.id === 'dresser')` で引ける。ワールド座標は階定義の `o.x, o.z` を足す。実物の外縁が必要なら、生成済みの2階で `floor.g.getObjectByName('shopHome-dresser')` を取得し、`new THREE.Box3().setFromObject(mesh)` で外接箱を求める。今は階段だけが操作地点で、家具の調査・報酬・保存項目は追加していない。

## 試験の流し方

作業フォルダの直下で実行する。

```sh
tail -c 14 index.html
node tests/chapter2-save.cjs
python3 -m py_compile tests/p3e3-shop-browser.py
```

末尾14バイトは `</body></html>`。Node 試験はインラインスクリプトを構文解析する。さらに、スズキ未加入で他の状態を固定し、屋外・店の両階で保存した生の JSON の全項目を照合する。砂場ではこれらに合格した。Node の模擬試験でも階別の当たり・別階待機・転倒退出・店先全閉塞時の引き継ぎ・移動と明転の例外後の復帰を確認した。

ブラウザー試験には Python Playwright の時計 API（1.45以降）、対応する Chromium、ローカルの Three.js r128 を使う。`THREE_JS` は既存の `three.min.js` のパスで、Chromium の保管場所を指定する環境では `PLAYWRIGHT_BROWSERS_PATH` も設定する。次のコマンドは本編と素材をローカルからブラウザーへ渡す。

```sh
export THREE_JS=/手元のパス/three.min.js
python3 tests/p3e3-shop-browser.py
python3 tests/p3e3-farm-browser.py
```

よろず屋試験は PC 1280×720 と iPhone 寸法 390×844 で実行する。`boundary`（試験139行）は本物の明転が終わって面を外す直前に同期し、短い入力列の間だけ時計を止める。次の階段・出口・入口の案内を有効にした状態で、キーのリピートと新規押下、または座標タップを送り、受信先と遷移回数を検査する。タップの受信先は解除前が暗転面、解除後が行動ボタン。引き続く意図的な入力で次の遷移が成立することまで確かめる。

`raw_save`（試験210行）は `localStorage` の値を直接検査する。店を出た後の地図の描画、農家入口での同行指示との競合、上下の視角での上壁、農家・本部・整備工場跡の往復も同じセッションで調べる。E3-2 の旧版往復まで再検査する場合は、手元の v0.90 本編を明示して `OLD_HTML=/手元のパス/v0.90/index.html python3 tests/p3e3-search-browser.py` を実行する。砂場には Python Playwright がなく、ブラウザーでの結果は次の環境で確認する。

### 1階の検収と撮影

`THREE_JS` を設定した上で、作業フォルダ直下から次を実行する。正午に、入口直後・入口から中央通路へ進んだ所・棚間・レジ側から売場・奥から入口・入口で見上げる・棚を見下ろす・レジ・裏倉庫の9枚を保存する。PC 1280×720 と iPhone 寸法 390×844 で計18枚。`SHOP_SHOTS` を省くと撮影だけを省略する。

```sh
SHOP_SHOTS=./shop-shots python3 tests/p3e3-shop-browser.py
```

試験は棚端とケースの継ぎ目を含む家具15か所、棚間・レジ前・倉庫戸・階段・スズキの着地点を含む9経路を確認する。Q32は鴨居と仕切り壁への取り付け、実際のカメラの画角、掲示面までの売場内の遮蔽を両寸法・3視点で調べる。発光材質・追加光源の検査は1階グループの実メッシュを対象にする。屋内の通常描画は同じ静止場面で影を切り、1階グループを表示した時と隠した時の calls の差を取る。
