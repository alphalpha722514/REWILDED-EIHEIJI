# E3-3a よろず屋のiPhone実機検収用試遊版

本編 `fadbbfd4ea7bef8e32b0e086fdf7c16fc89dfa01` の `index.html`（blob `824feac598b742f203a534a972d074f7a417c224`）から生成します。ブラウザーとiPhoneでの起動・操作は未検証です。公開はユーザー承認後です。

## 開き方と操作

- タイトルで「よろず屋の前から始める」を押すと、古い地図を取得し、スズキを連れた状態で店先から始まります。入店、階段、退出は普段の「調べる」で操作します。
- 一時停止の「よろず屋の検収」で、時刻を昼・夕方・夜に切り替えます。スズキの「ここで待つ／ついて来る」も切り替えられます。別の階にいるときはスズキのいる階へ戻って指示します。通常の「スズキに指示する」も使えます。
- 一時停止の既存の「描く細かさ」で標準と軽量を切り替えます。「計測表示」をオンにして再開するとFPS、三角形、描画回数が表示されます。「計測を記録（30秒）」も使えます。
- 「セーブ」または「タイトルへ（自動セーブ）」の後に「つづきから」を選ぶと、試遊版の保存を読み込みます。店内で保存すると、主人公は上志比の屋外到着点から再開します。店内で待機中だったスズキは店先にいます。

## 保存の分離と検証状況

試遊版のセーブは `eiheiji_p3e3shop_save`、音・天候・影・性能表示・照準・描画詳細・カメラ上下と保存可否確認用キーは `eiheiji_p3e3shop_` で始まる専用キーを使用します。生成時に定数経由を含めたすべての保存先を検査します。HTMLの先頭で、専用キー以外への読み書き・削除と一括消去を遮断します。

Nodeで、2回生成したHTMLのバイト一致、インラインJavaScriptの構文、本編と農家試遊版の保存値の保持、試遊版セーブの読出しと専用設定キーの読み書き、上志比の地図データを使った店先の候補、開始時の地図・同行状態、待機の切替、昼・夕方・夜の切替を確認しました。保存テストは模擬 `Storage` を使用しました。既存のNode回帰10本と屋内形状テストも再実行し合格しました。生成形状は店1階6,076、2階5,622、古い農家8,162三角形です。

サンドボックスを有効にしたChromium 156は、前回の `chrome-sandbox` の所有者設定エラーとユーザー名前空間の制約が続いており、別の利用可能な実行環境は見つかりませんでした。最新の `p3e3-shop-browser.py` と前回未実施の `p3e3-farm-browser.py`、`p3e3-search-browser.py`、`suzuki-browser.py` はテスト本体未実施です。実際の上下階移動、指示の反復、台所の見え方、照明と音、WebGLのdraw callとFPS、ブラウザー上のセーブとロードは下記で確認します。

## iPhone Safariの検収チェックリスト

- [ ] 端末名、iOSの版、縦・横の向きを記録する。店先から始め、地図を開いてよろず屋の印を確認し、「調べる」で入る。
- [ ] 1階の売場・レジ・裏倉庫と2階の居間・寝室・台所・収納を一巡する。階段を各方向に繰り返し操作し、1回のタップにつき1回だけ暗転・移動することを確認する。
- [ ] 2階で通常の「スズキに指示する」を開き、「戻る」「ここで待て」「ついて来い」を繰り返す。別階での待機、同じ位置での再会、退出時の店先での待機を確認する。失敗時は操作順、案内の表示、スズキの階を記録する。
- [ ] 縦画面で台所へ入り、流し台と食器棚を左右から見る。手前の間仕切りで下部が遮られないか、視点を戻すと壁が戻るか、壁をすり抜けないかを確認する。
- [ ] 両階で昼・夕方・夜を切り替え、窓光、夜の補助光、消灯した家電、出口の発光を確認する。BGMを切って風・鳥・きしみを聴き、階移動や出入りで音が重ならないか調べる。
- [ ] 計測表示をオンにして、両階の同じ視点で標準／軽量、スズキ同行あり／なしのFPS・描画回数・三角形数を記録する。古い農家と比較するときも端末、画面の向き、設定を揃える。
- [ ] 店内で保存し、タイトルに戻って「つづきから」を選ぶ。主人公の屋外到着点、スズキの復帰先、地図と設定を確認する。試遊版で設定・保存を行った後、本編のいつものセーブと設定でも再開できることを確認する。
