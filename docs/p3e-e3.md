## 作り

- `P3IN` の建物ごとの定義から、間取り・家具・印・入口の条件と案内・入室後の処理を呼ぶ。本部と整備工場跡の間取りや処理は従来のものを使う。
- 壁の色、高さ、腰の高さ、厚さは間取りの表で設定できる。農家の壁は高さ3.0 m、腰1.1 m、厚さ0.22 m。部屋の角と戸口に木の柱を置き、手前の壁の上は既存の見下ろし処理で隠す。框は床の木の線で描く。襖と蔵戸は主人公かスズキが近づくと開き、当たりは戸口の左右にある。
- 窓光の四角形は北・南・東・西の外壁から内向きに描く。壁の位置は間取りの座標と窓の位置から求める。土間の西、囲炉裏の間と座敷の南、座敷の東、納戸と蔵の北の順に窓を設け、蔵を最も暗くする。本部と整備工場跡は従来の数値配列で北から描く。
- 囲炉裏の灰の上に小さな橙色の加算光を置き、毎フレーム濃さだけをゆっくり変える。開いた引き出し、倒れた湯呑み、ずれた座布団で避難後の様子を表す。

## 2回目の修正

上がり框は幅6.0 m、中心 z=17.4 m にそろえた。蔵の壁と床を暗くし、高い小窓の光は弱いままにした。棚と長持が見分けられ、画面の平均の明るさが蔵前より1〜2割低い状態を目安とする。土間には固定の種で濃淡の斑と小石を置いた（計1,220三角形）。西のガラス戸から入る3本の光はそれぞれ幅1.1 m、濃さ0.40に抑えた。囲炉裏の灰の上には橙色の加算光と残り火の粒を3つ置き、濃さを0.35〜0.55でゆっくり揺らす。

## テスト

`THREE_JS=/手元のパス/three.min.js python3 tests/p3e3-farm-browser.py`。手元の Three.js r128 と Playwright の Chromium を使う。入退室、部屋、戸口と通路の当たり、引き戸、壁の見え方、スズキ、保存、本部と整備工場跡、三角形数、スマホ幅、ページのエラーを確認する。`E3_SHOTS=フォルダ` を指定すると、各部屋を 1280×720 と 390×844 で撮る。

農家の屋内グループの全メッシュを輪郭線込みで数え、15,000三角形未満かを確かめる。画面全体は1280×720で両方の入室地点から同じ向きで測り、農家の三角形数が本部の1.15倍以下かを確かめる。

修正前に Claude Code がブラウザーで測った値は、農家の屋内が輪郭線込みで約7,100三角形、画面全体が農家75,588、本部76,132、整備工場跡71,602。画面の平均の明るさは蔵122、蔵前116だった。
