## 0. 要点

- **復興 Lv3**（C-3 で作った条件：Lv2 の施設3つ・正式に住む住民4人・依頼「整備工場の特殊部品の回収」）に上がると、**総合加工設備**を建てられる。
- **総合加工設備**：本部の南の鉄骨の作業場（炉・旋盤・作業台・鋼材の棚）。Lv2 の施設と同じく、拠点の管理で素材を分けて納め（持ち物 → 本部の倉庫 → 本部のそばの荷台）、住民が勤務時間に建てる（工期8時間）。
  - 素材（暫定）：木材30・石20・屑鉄16・**山地の硬木8**・古い機械部品10・**川底の鉱石8**・**加工機の主軸1**。
- 完成すると、近くで「**総合加工設備を使う**」→ 作業台と同じ形の画面（タブ：素材・武器の鍛え直し・防具の補強・車両）。本部の倉庫の素材も使える。
- 新しい素材：
  - **山地の硬木**：林道の試作の**広葉樹（33本）を切る**（今の伐採と同じ：受け口・追い口・枝払い）。丸太を割ると、1本の木で硬木2（はじめの2本の丸太）と木材。切った木は戻らない（P3-A の案）。
  - **川底の鉱石**：D-3 の浅瀬の鉱石の石（7か所・1か所3つ・300秒で戻る）。
  - **加工機の主軸**：新しい依頼「**加工機の主軸を探す**」（Lv3・リオ）。町の東の鉄工所の跡（地図の建物 bld[11]）で、中をのぞく → 崩れた鉄骨を4回どかす（屑鉄4）→ 倒れた旋盤から主軸を取り出す → 報告（古い機械部品3）。
  - **鋼材**：総合加工設備で作る。
- 住民の自動収集の強化（§4）は、C-3 で作った「Lv3 で収集の量 1.5倍」のまま。
- 状態：**コードに存在・作業ブランチにコミット済み・PC（画面のない Chromium）で確認**。公開していない・PC の実機と iPhone は未確認。

## 1. 高度加工（すべて暫定）

| タブ | 作る物 | 素材 | 効き目 |
|---|---|---|---|
| 素材（建材の高度加工） | 鋼材を作る | 川底の鉱石2・木炭2 → 鋼材1 | 下の3つに使う |
| 武器の鍛え直し | 持っている武器ごとに2段階（飛去来器は除く） | 1段階目：鋼材1・山地の硬木1・屑鉄2／2段階目：鋼材2・山地の硬木2・古い機械部品1 | 威力 +15%／+30%・耐久が長もち（減り方が 1/1.25／1/1.5）・鍛えると耐久が満タン |
| 防具の補強 | 持っている防具ごとに1回（初期の作業着も） | 鋼材1・獣素材2 | 被ダメージ -2%（4部位の上限も +2%。全体の上限 40% は変えない） |
| 車両（KEI truck） | 鋼板の外装 | 鋼材4・屑鉄6・古い機械部品2 | 車体の丈夫さ +40（どの改修の段階でも）・獣の攻撃の傷み 0.6倍 → 0.45倍 |
| | 大きな燃料タンク | 鋼材2・屑鉄4・古い機械部品3 | 燃料の減り方 1km 12% → 9% |
| | 荷台の枠 | 鋼材3・山地の硬木4・縄4 | 荷台の丸太 6本 → 8本・荷台の広さ 60 → 80 |

- 車両の3つは、それぞれ1回だけ。見た目（外装の板・枠）は変えていない（数値だけ）。
- 「施設設備の高度加工」は、今は鋼材を作るところまで（鋼材を使う施設の強化は P3-F の防衛で使う形にする）。
