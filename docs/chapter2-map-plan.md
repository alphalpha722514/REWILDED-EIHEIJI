# 上志比マップ制作 v0.1 — 2026-11-11

## 今回完成したもの

`previews/kamishihi-map/index.html` は地理調査ビューア。実際の地理院タイルを表示し、光明寺・牧福島・山王・市荒川の町域中心点へ移動する。道路や河川は架空の線で代用しない。標準地図と陰影起伏図を切り替え、起伏と集落配置を調べられる。外部ライブラリ不要。取得失敗時は表示し、資料リンクを残す。

本編 main/index.html は変更しない。今回の完成範囲はマップ制作の調査段階。上志比への移動・3Dマップ・トラックは未実装であり、調査ビューアをゲーム完成として扱わない。

## 確定方針

- 実在の主要地形・道路・集落分布・標高を調べ、ゲーム向けに縮小。
- 徒歩と軽トラック。地域境界で短いロード。
- 固定の既存建物を拠点施設として順次解放。復興に伴い住民が集まる。
- 水辺で釣り・採集。双子戦は住宅地から離した廃工場・倉庫群。
- トラックを建設地に近づけ、荷台から直接納入できる。

マーカーは国勢調査の町域の図形中心点であり、駅・建物・敷地やゲーム拠点の座標ではない。中心点を標高サンプル・施設座標に流用しない。実在の建物を廃工場と断定しない。ボス区域は架空施設として、道路・住宅分布の確認後に決める。軽トラックの発見場所・修理費用・台詞は今回補作しない。

## 次の実装単位

1. 調査範囲の道路・河川・建物形状とDEMを取得し、出典・取得日とともに固定する。標高は欠損値を明示し、平地で埋めて測量済みとしない。
2. 光明寺と上志比を別シーンとして生成・破棄できるようにする。現行の単一世界定数・当たり判定・採集ノード・敵・マップUIを地域単位へ分離。
3. 防衛戦完了で出発を解放。ロード完了まで移動確定せず、失敗時は光明寺へ復帰。旧セーブは光明寺開始を維持し、地域別状態を保存。
4. 上志比の徒歩探索と往復移動を実機確認。その後にトラック発見・修理・運転・荷台を追加。
