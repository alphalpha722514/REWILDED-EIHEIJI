## 本編での位置づけ
- 敵の種類 `mutant`（`ET.mutant`）。通常の猿（`monkey`）・双子猿には手を入れていない。
- **本編ではまだどこにも出ない。** 出すのは作業F（スズキ初登場）と、試遊版のボタンだけ。
- 呼び出し：`spawnMutant(x, z, {fleeOnly, tgt, onFlee})`。形のデータを読んでから出す。
  - 上志比など、ほかの地域で出したものは、その地域を出るときに消す。

## 動き方
- **回り込み：** 6.5 の距離を保って左右に回る。
- **攻撃を選ぶ：** 次の攻撃までの時間が来たら選ぶ（同時に攻撃するのは2体まで。既存の決まり）。
  - 5〜11 の距離なら 45% で**飛びかかり**。
  - それ以外は**突進**（速さ 11.5）。近づいたら 6:4 で、
    - **前腕のひっかき**：0.55秒振りかぶる、扇 2.6・幅2.6、30 ダメージ、吹き飛び強め。
    - **噛みつき**：凶暴化した猿と同じ。0.4秒ため、扇 1.9・幅1.8、20 ダメージ。
- **二連撃（v0.62）：** ひっかきの後、相手が近ければ 55%（猛り狂うと 85%）で、**左の前腕で返す**。
  - 予備動作は 0.32秒と短く、少し踏み込む。扇は右と同じ（地面に出る）。24 ダメージ。
  - 動きは右のひっかきの鏡写し。右を振り下ろした姿勢からつなげる。
- **飛びかかり：**
  - 0.5秒かがんで、跳ぶ先を地面の線で予告する。
  - 跳ぶ（最長11）。着地点で 26 ダメージ。
  - 着地のあと 0.6秒の隙。猛り狂っていて相手が近ければ、50% で隙なしにひっかきへつなぐ。
- **跳んでかわす（v0.62）：** 主人公が振りかぶるのを見ると、回り込み・突進・離れる途中なら、後ろへ跳んでかわすことがある。
  - 強攻撃なら 50%、通常の攻撃なら 15%（猛り狂うと ×1.3）。4.2 より近いときだけ。
  - 跳んでいる最初の 0.24秒は当たらない（「かわした」と出る）。かわした後は、すぐ次の攻撃に移る。
  - 攻撃の後の隙・ひるみ・体勢崩し・気絶の間はかわせない。**隙を突いて強攻撃を当てる**のが攻略の筋。
- **猛り狂う（v0.62）：** 体力が半分を切ると「猛り狂った！」と叫び、体が赤みを帯びる。速さ ×1.15、次の攻撃までの間 ×0.6、二連撃・着地からのひっかきが増える。初遭遇では起きない。
- **攻撃のあと：** 離れる（0.7秒）→ 回り込みに戻る。
- **体力の帯（v0.62）：** 戦っている間（26 以内で、気づかれている）は、ヌシ戦と同じ所に「変異したサル」の名前・体力・体勢を出す。倒す・逃げる・離れると消える。ヌシ戦の間は出さない。
- **初遭遇（`fleeOnly`）：**
  - 傷が 230 たまると「キィィッ！」と逃げ去る（速さ 9.5）。逃げるとき「変異した鱗」を1つ落とす。
  - さらに叩いても倒れない（体力は1で止まる）。
  - 28 離れるか5秒たつと消え、`onFlee` を呼ぶ（無ければ「変異したサルは逃げ去った」）。
- **通常：** 体力0で倒れる（倒れる動き）→ 少しして消える。
- **狙う相手：** `e.tgt`（スズキなど。`hurt(ダメージ, 敵)` を持つ相手）。無ければ主人公。

## 動きの割り当て
| 状態 | 動き |
|---|---|
| idle・alert | 待機 |
| 回り込み・突進・離れる・逃げる | 速さで「歩く」と「四つ足で走る」を切り替え、足の運びを速さに合わせる |
| 噛みつきのため | 飛びかかりの「かがむ」 |
| ひっかき | ひっかき（ため→振り下ろし→戻り） |
| 飛びかかり | 飛びかかり（かがむ→空中→着地）。空中の高さは AI が決める |
| ひるみ・体勢崩し・気絶 | ひるみ |
| 倒れた | 倒れる |

## 変異した鱗（v0.62）
- 持ち物のキー `mutScale`（表示名「変異した鱗」）。倒すと2、初遭遇で逃げられたとき1（どちらも暫定）。
- 落とし物の形：前腕の青みの鱗を3枚、扇に開いて立てたもの。上の目印は青（ほかの落とし物は黄色）。
- 持っていると、右上の持ち物の欄と持ち物の一覧に出る。
- **使い道（ユーザー決定）：** 人間が使えるように加工し直して、新しい装備・武器を作る。九頭竜の力を応用した攻撃が使えるようになる。特殊な施設の材料にもなる。詳しい作りは未定で、`docs/mutant-scale-uses.md` に決めることをまとめた。**いまのコードではまだ何にも使えない。**
- セーブ：`inv.mutScale` を新しいキーとして足した。旧セーブは 0 で読める（`docs/save-and-flags.md`）。

## 強さの測り方（`tools/mutant-duel-sim.cjs`）
防衛戦の測定ツールと同じしくみで、光明寺の開けた所（安全地帯の外）で主人公（ボット）と1体だけを戦わせる。
- ボットは近づいて叩き、サルの隙（攻撃の後・ひるみ・崩れ）には強攻撃。体力が4割を切ると食べる。
- サルの予備動作を見て、決めた割合（「回避」の列）で横へ回避する。0 は避けない、0.8 はよく避ける人の目安。
- 準備の組は防衛戦と同じ：B（レベル3・鍛えた鉈・基礎の頭と胸・おにぎり3）、C（レベル4・牙槍・山守の一式・おにぎり3・弁当2）。
- ボットの結果は人が遊んだときの値ではない。人はもっと時間がかかり、もっと当たる。強さを変えたときの増減を見る目安。

```
THREE_JS=…/three.min.js node tools/mutant-duel-sim.cjs --runs 16 --cond B,C --dodge 0,0.5,0.8 --mode kill   # 通常（倒す）
… --mode flee                                   # 初遭遇（撃退）
… --enemy bear                                  # 比べるためのクマ
… --et '{"hp":600}' --override '{"scratch":26}'  # 値を一時的に変えて試す（本編は変わらない）
DUEL_DETAIL=1 …                                 # サルが入った状態の回数も出す
```

読み方（v0.62.1）：
- 牙槍と山守の防具（C）なら勝てる。クマの約4倍の時間がかかり、避けないと食事を1回使う。人が遊ぶと、もっと長く危ない戦いになるはず。
- 鍛えた鉈（B）では、よく避ければ勝てる（94%）が、ふつうに避ける程度だと多くは負ける。v0.62（体力800）では、よく避けても56%だった。

- 試した途中の値：体力420（C は 12秒で勝つ）、700・900・1000、攻撃の間 0.8〜1.8秒など。体力を上げても牙槍では時間が少し延びるだけなので、攻撃の強さ・間の短さ・二連撃・跳んでかわす・猛り狂うを合わせた。
