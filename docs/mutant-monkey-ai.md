# 変異したサル：AI と試遊版（v0.61、2026-11-13）

形・骨・動き：`docs/mutant-monkey-rig.md`（ユーザー承認 2026-11-13「１も２もこれで良い」）。

## ユーザー決定
- 今回（スズキ初登場）は**逃げ去る**。以降は「凶暴化した猿の上位互換」として出る。凶暴化した猿も今までどおり出る（2026-11-13）。
- 攻撃：凶暴化した猿と同じ攻撃（一撃離脱）に、固有の**前腕のひっかき**（広い扇・強い）と**飛びかかり**（離れた所から跳ぶ）を足す（2026-11-13「これで良い」）。

## 本編での位置づけ
- 敵の種類 `mutant`（`ET.mutant`）。通常の猿（`monkey`）・双子猿には手を入れていない。
- **本編ではまだどこにも出ない。** 出すのは作業F（スズキ初登場）と、試遊版のボタンだけ。
- 呼び出し：`spawnMutant(x, z, {fleeOnly, tgt, onFlee})`。形のデータを読んでから出す。
  - 上志比など、ほかの地域で出したものは、その地域を出るときに消す。

## 強さ（すべて暫定）
| 項目 | 値 | 参考（凶暴化した猿） |
|---|---|---|
| 体力 | 150 | 34 |
| 体の半径 | 0.72 | 0.45 |
| 速さ | 6.4 | 6.6 |
| 見つける距離 | 16 | 12 |
| 体勢（怯み値） | 60、崩れ 1.4秒 | 20、1.2秒 |
| ひるみ | 強い一撃か、攻撃していない間だけ（1秒に1回まで） | いつでも（0.8秒に1回まで） |
| 吹き飛び | 強攻撃 0.9・弱 0.25 | 1.6・0.6 |
| 倒したとき | 毛皮3、経験値25 | 毛皮1、経験値10 |

## 動き方
- **回り込み：** 6.5 の距離を保って左右に回る。
- **攻撃を選ぶ：** 次の攻撃までの時間が来たら選ぶ（同時に攻撃するのは2体まで。既存の決まり）。
  - 5.5〜10 の距離なら 45% で**飛びかかり**。
  - それ以外は**突進**（速さ 10.5）。近づいたら半々で、
    - **噛みつき**：凶暴化した猿と同じ。0.4秒ため、扇 1.9・幅1.8、13 ダメージ。
    - **前腕のひっかき**：0.55秒振りかぶる、扇 2.5・幅2.5、18 ダメージ、吹き飛び強め。
- **飛びかかり：**
  - 0.5秒かがんで、跳ぶ先を地面の線で予告する。
  - 跳ぶ（最長10）。着地点で 16 ダメージ。
  - 着地のあと 0.75秒の隙。
- **攻撃のあと：** 離れる（0.8秒）→ 回り込みに戻る。
- **初遭遇（`fleeOnly`）：**
  - 体力が 45% 以下になると「キィィッ！」と逃げ去る（速さ 9.5）。
  - さらに叩いても倒れない（体力は1で止まる）。
  - 28 離れるか5秒たつと消え、`onFlee` を呼ぶ（無ければ「変異したサルは逃げ去った」）。
- **通常：** 体力0で倒れる（倒れる動き）→ 少しして消える。
- **狙う相手：** `e.tgt`（スズキなど。`hurt(ダメージ, 敵)` を持つ相手）。無ければ主人公。

## 動きの割り当て
| 状態 | 動き |
|---|---|
| idle・alert | 待機 |
| 回り込み・突進・離れる・逃げる | 速さで「歩く」と「四つ足で走る」を切り替え、足の運びを速さに合わせる |
| 噛みつきのため | 飛びかかりの「かがむ」 |
| ひっかき | ひっかき（ため→振り下ろし→戻り） |
| 飛びかかり | 飛びかかり（かがむ→空中→着地）。空中の高さは AI が決める |
| ひるみ・体勢崩し・気絶 | ひるみ |
| 倒れた | 倒れる |
