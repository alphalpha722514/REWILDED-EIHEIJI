## 4. 試遊版の機能

タイトル画面の右上の「**テスト：上志比の森で始める**」：
- 防衛戦と作業F（山王の初遭遇まで）は済み、レベル4、森の防具、鉄の斧（竹も切れる）と槍、食べ物を持った状態から始める。
- 上志比の**広葉樹の林の中**から始める。朝9時。
- **KEI truck**：直して燃料も満タン。荷台に**救急箱**（改修は段階4）。上志比の自分のそばに置く。
- **光明寺のかまど**：建ててある。

遊んでいる間は、画面の左上（体力などの表示のすぐ下）の「**試遊メニュー**」を押す（もう一度押すと閉じる）：

| まとまり | ボタン | すること |
|---|---|---|
| 場所を移る（上志比） | 広葉樹の林へ／杉林へ／竹林へ／山の薬草のそばへ | 近い所へ移る。押すたびに、近い順に次の所（6か所まで） |
| | 森の奥の高い所へ | 山の薬草の場所のうち、いちばん高い所。低い方を向く |
| | KEI truck をそばに呼ぶ | 自分のそばの平らな所に置く |
| かまど（光明寺） | 光明寺のかまどの前へ／上志比の森へ戻る | 地域を移る（読み込みに少し時間がかかる） |
| 持ち物 | 苗木・山の薬草・米・木材を足す | 苗木+3・山の薬草+3・米+3・木材+10 |
| | 体力を戻す・食料を足す | 体力を満タン・おにぎり+2 |
| 時間 | 5分／20分／40分進める | 遊んだ時間とゲームの中の時刻を一緒に進める（20分で山の薬草が戻る・40分で植えた苗木が育つ） |
| | 朝9時にする | 昼にする（鳥の声は昼だけ） |
| 画面 | 描く細かさを切り替える | 標準 ⇄ 軽量 |
| | 案内の表示：新しい形 ⇄ 今までの形 | 「調べる」の案内を小さくした形と、v0.88 のままの形を切り替える（2026-11-23 追加。`docs/prompt-ui.md`） |

- メニューの上に、今の状態（場所・時刻・苗木・山の薬草・米・木材・植えた苗木・次に育つまで・救急箱の残り・描く細かさ）を出す。
- 時間を進めると、食べ物の傷みや工事なども同じだけ進む。
- 本編の作り（E-2 の数・決まり）は変えていない。数はすべて暫定のまま。
