# 「調べる」の案内を小さくする（試遊版 `previews/p3e2-forest/` で試す）

- 依頼：2026-11-23 ユーザー。iPhone で v0.88 の森林の試遊版を確かめたところ、「調べる」の案内が大きすぎて画面を遮る。ゲーム全体で前から気になっていた。
- まず v0.88 の森林の試遊版だけに入れて、今までの形と比べられるようにした。
- 本編（main の v0.87）・E-2 本体（`p3e2-forest`）・セーブの形・ゲームの進み・操作の判定は変えていない。
- 作業ブランチ `p3e2-prompt-ui`（main `2a59733` から）。commit・push・main への反映はしていない（ユーザーの承認待ち）。

## 1. 今の作り（v0.88。調べた結果）
- 近くの調べられる物は、すべて `interactables()` が集め、いちばん近い1つ（`curInter`）の文を、画面の部品 `#prompt` の1か所に出す。
  - 対象：木（伐採・枝払い・切り株・苗木）・採集物（石・竹・藁・薬草・山の薬草・竹林）・施設（作業台・かまど・変換炉・車両基地・田んぼ・食料庫など）・住民（話す）・スズキ（指示・助け起こす）・探索地点（手掛かり・紙片・がれき・川辺の石）・KEI truck（乗る・燃料・荷台の施設）など。文の種類は約165。
  - 文は「名前・すること」＋全角の括弧の中の説明（素材の数・秒数・効き目など）。長いものは70字を超える。
- `#prompt` は、PC では画面の下の真ん中（手持ちバーの上）、スマホでは画面の真ん中より下（主人公の足元から胸のあたり）に、15px（スマホ縦は13px）の字で、何行にも折り返して出る。スマホでは「調べる」の札も付く。
- 調べる操作（PC の E・スマホの「調べる」ボタン）は、`curInter.act()` を呼ぶ。表示とは別。

**共通の1か所（`#prompt` を出す処理）だけを変えれば、すべての対象に同じ形が入る。**

## 2. 変えたこと（試遊版だけ）

| | 今までの形（v0.88） | 新しい形 |
|---|---|---|
| 中身 | 文の全部（括弧の中の説明も） | **名前・することだけ**（全角の括弧の中を省く。ただし「長押し」の操作の説明は残す） |
| 大きさ | 15px（スマホ縦13px）・何行にも折り返す | **12px・1行**（はみ出す分は「…」） |
| 置き場所 | PC：下の真ん中（手持ちバーの上）。スマホ：真ん中より下 | **画面の上の真ん中（目標の帯のすぐ下）**。体力の欄・目標の帯・持ち物の数・地図・操作の説明・手持ちバー・スマホのボタン・試遊メニューと重なるときは、右寄せ・左寄せの順に空いている所へ（測って決める） |
| 詳しい説明 | いつも出ている | **案内を押した（タップ・クリック）ときだけ**全文を出す。右の「詳しく」が「閉じる」に変わる。別の物に近づくと閉じる |
| 札 | PC「E」・スマホ「調べる」 | PC「E」（小さく）・スマホは札なし（「調べる」ボタンが光る） |
| 「調べる」ボタンの光 | 案内が出ている間は弱める（v0.33） | 新しい形では弱めない（案内が小さいので、ボタンで気づけるように） |

- 変えていないもの：調べる操作（E・「調べる」ボタン）と、近くの物を選ぶ決まり（`interactables()`）。会話（`#dialog`）・選択肢・大きな案内（`banner`）・通知（`toast`）・警告・チュートリアルの文・時刻と目標の帯。セーブ。
- 括弧の中を省くので、素材の数・秒数などは「詳しく」を押すと見える（例：「竹林の竹を切る」→ 押すと「竹林の竹を切る（竹+2）」）。
- 試遊メニューの「案内の表示：新しい形 ⇄ 今までの形」で切り替えて比べられる（はじめは新しい形。保存しない）。
- ついでに：試遊メニューのボタンが、スマホを横にしたときに「地図」ボタンを隠していたので、スマホのボタンも避けて置くようにした（試遊版だけの部品）。

### 作り
- `tools/build-p3e2-forest-preview.py` で、v0.88 の `#prompt` を出す5行を差し替える（今までの形の2行はそのまま残して、切り替えで使う）。
- 足した関数：`puiShort`（名前だけにする）・`puiRects`／`puiDrop`／`puiPlace`（置き場所）・`puiUpdate`（表示）・`puiSet`（切り替え）。CSS は `#prompt.cmp`。
- 置き場所を測るのは、中身が変わったときと0.5秒に1回。

- 案内を押しても、攻撃・移動などは起きない。
- 調べる操作は今までどおり（PC は E キー、スマホは「調べる」ボタンで竹林の竹+2）。

- ページのエラーなし。
- 重ならないことを確かめた物：主人公・手持ちバー・体力の欄・目標の帯・持ち物の数・地図・操作の説明・試遊メニュー・スマホのボタン8つ（調べる・攻撃・回避・強攻撃・地図・止める・持替・防衛戦）。

### 3.2 途中で見つけて直したこと
1. はじめは PC で手持ちバーのすぐ上に置いたが、森の中ではカメラが主人公に近づき、主人公の体にかかった。→ 上の真ん中へ。
