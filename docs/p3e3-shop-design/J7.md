本部の `p3bFloor()` は**本部座標固定**です。商店は専用の屋内原点と階別の原点・歩行矩形・操作点・到着点を持ちます。上階を例として `x+44` に展開する場合も、階間の空地を歩行範囲に含めません。暗転中に「入力ロック・視点入力解除 → 旧階を無効化 → 行先階の `REG.inB`・当たり・表示・操作候補を設定 → 主人公 → 同行者」の順で切り替えます。初回入店・再入店は1階。再構築でも同じ階選択を通します。両階のメッシュを常駐させ、往復時の再生成を避ける案です。`index.html:10933` `p3bFloor()`、`index.html:1190` `resolve()`、`index.html:12435` `p3bRebuild()`、`index.html:12443` `p3aEnter()`。

**カメラ。** 現行の屋内基準は水平距離5.2 m、高さ7.0 m、注視高0.6 m、先読み0.4 m、仰角35～80°。各階は独立した床にして全面天井を張らず、手前の上壁と同時に窓枠・掲示・時計を隠します。中央棚は商品込み1.2 m以下を初期目標、背の高い棚は壁際。倉庫戸は現行の近接引き戸で、戸板は正方向に幅の92%滑り、可動当たりはありません。戸の引き代、段鼻、出口の視線にレジや箱を置きません。`index.html:10044` `CAM_PITCH`、`index.html:10138` `updateCamera()`、`index.html:10204` `camObstruct()`、`index.html:12414` `p3aInteriorBuild()`、`index.html:12438` `p3bInteriorTick()`。
