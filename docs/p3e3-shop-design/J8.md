### 間取り3案

以下はすべて**設計寸法**です。各図は左が店先、右が奥。両階とも壁芯で正面幅13.60 m×奥行12.60 m、壁厚0.22 mなら内法13.38×12.38 m、外面13.82×12.82 mで外観に収まります。正面戸は中央、幅2.40 m。図の矢印は主人公と追従中のスズキが通る道です。

**A　中央通路のよろず屋〔推薦〕**

```text
       店先             奥行8.0 m       奥12.6 m
1階　┌ 食品棚　 日用品棚         │       階段↑ ┐
入口→│ ── 中央通路 2.80 m ──┐ │       段前   │
     │ 農業棚　　　　　レジ  └→戸→ 裏倉庫     │
     └─────────────────┴──── 在庫棚 ┘
2階　[正面5窓・主室      ← 開口2.40 m ← 奥室・段前]
```

売場の奥行8.0 m、裏倉庫4.6 m。棚間2.40 m。入口から二人で中央を進み、レジ手前で曲がって幅2.0 mの戸を一列で通ります。倉庫内は段前まで2.2 mを空け、在庫棚を段と反対の端に寄せます。**三つの売場と会計の位置を最もつかみやすい案**です。弱点は倉庫戸に往復が集中すること。戸の横には戸板の引き代1.84 mも必要です。

**B　対面棚から会計へ進む店**

```text
       店先          奥行6.2 m   9.0 m    奥12.6 m
1階　┌ 段前→階段　← 一列の側路    │     在庫棚 ┐
     │ 食品棚　　　　　↑         │            │
入口→│ ─ 主通路2.50 m → 会計前 ─戸→ 裏倉庫   │
     └ 日用品棚・農業棚　 レジ    │            ┘
2階　[正面窓・主室 ← 開口2.20 m ← 廊下・段前]
```

売場から奥行6.2～9.0 mが会計前、その奥3.6 mが裏倉庫。奥壁に棚を置いても倉庫の有効幅は約2.7 mです。二人で商品を両側に見ながら進み、倉庫へは幅2.0 mの戸を直進。階段へは会計前で曲がり、店先方向へ折り返します。**買い物をする順路が自然**な反面、階段への戻り道が初見で分かりにくい案です。側路幅1.85 mは一列用。床材だけで区切り、側路に壁や冷蔵ケースを置かない設計です。

```text

1階　┌ 食品壁棚　→ 上側の通路 →    │      階段↑ ┐
入口→│ 分岐　 低い中央棚　　　合流 ─戸→ 裏倉庫  │
```

### ユーザーが決めること

|---|---|
| 間取り | **A 中央通路**／B 対面棚／C 中央棚。Aは入ったところから店の全体が読め、狭い場所が少ない。 |
| 2階の用途 | **予備倉庫**なら、1階は荷ほどき中、2階は整った在庫と、同じ箱でも違って見える。居室風なら座卓・低い箪笥で窓際に変化が出るが、建物に居住用途があったかは不明。居室風＋物置なら両方を見せられるが、家具と通路が競合する。 |

### 5．将来の商店試遊版

起動先を**よろず屋の屋外入口**にし、「古い地図あり／なし」「スズキなし／追従／待機」「昼／夕／夜」「標準／軽量」「1階／2階へ」を用意する案です。地図ありは本編と同じ既存の印に反映し、通常の入口を通す試験と、階を直接選んで見た目を比べる試験を区別します。直接移動時も正式な階切替処理を通し、歩行範囲・同行者・操作点を同時に切り替えます。

保存・音・天候・影・性能表示・照準・描画詳細・カメラの各キーは商店試遊版専用に分けます。試遊版で地図を切り替え、設定を変え、保存し、「はじめから」を実行した後も、本編と農家試遊版のキー・値が開始前と一致することを検収します。生成方法の参照先は `tools/build-p3e3-farm-preview.py:58`、保存の基準は `index.html:9343` `SAVE_KEY` です。
