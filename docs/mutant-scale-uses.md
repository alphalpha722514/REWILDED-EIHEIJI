# 変異した鱗の使い道 — 決定と、作る前に決めること（2026-11-13）

## 1. ユーザー決定（2026-11-13）
- **加工：** 人間が使えるように加工し直す。
- **新しい装備・武器：** 加工した鱗から、新しい装備と武器を作れるようにする。
- **九頭竜の力を使う攻撃：** 九頭竜の力を応用した攻撃が使えるようになる。
- **特殊な施設：** 特殊な施設を作る材料にもなる。
- **入手：** 初遭遇で逃げられたときに1つ落とすのでよい。
- **変異したサル：** 体力は600にする（「若干弱く」→ v0.62.1）。跳んでかわす・猛り狂うは残す。

以下の「案」や選択肢は、どれも未承認です。

## 2. いまのコードにあるもの（v0.62.1）
| もの | いまの作り | 場所 |
|---|---|---|
| 変異した鱗 | 持ち物 `inv.mutScale`。倒すと2、初遭遇で1（暫定）。いまは何にも使えない | `MUT.killDrop`・`MUT.fleeDrop` |
| 作業台で作る | `RECIPES` の表（素材 `cost`、解放条件 `lock`、表示条件 `show`、できる物 `give`）。食べ物・柵・罠・武器・防具・道具が同じ仕組み | `const RECIPES=[` |
| 武器 | `WEAPONS`（通常・強・届く距離・耐久・木を切る力）。系統は鉈・斧・棍棒・槍。武器ごとの耐久は `prog.arms` に保存 | `const WEAPONS=` |
| 特別な技 | 技の表 `MOVES`。系統ごとに「見切り反撃」（`FAMC`。回避で見切った直後）と「持ち替え直後の技」（`FAMS`）がある。九頭竜の力の技は、新しい種類の技としてここに足せる | `const MOVES=`・`FAMC`・`FAMS` |
| 防具 | `G47`（頭・胸・脚・足の4部位）。系統は基礎・山守・沢追い。4部位一式で特殊効果1.5倍。軽減の上限は4部位で15% | `const G47=`・`G47SETS` |
| 防具の見た目 | P2 で作り直し中（初期の服と同じ作り方の丸ごとの服）。作業ブランチ `p2-armor-suzuki-draft`、承認待ち | `docs/p2-investigation.md` |
| 施設 | 柵台・罠台・食料庫・畑・丸太置き場など（光明寺）。上志比の拠点施設は P3 の予定 | `docs/phase-p2-status.md` |
| 九頭竜の力についての既存の文 | ヌシの遺言「怒りに呑まれた九頭竜様の力が、ワシの心まで奪ってしもうたのじゃ」。手がかりの文「光明寺のヌシが残したもの。青緑の鱗には、九頭竜の力の痕跡がかすかに残っている。」 | 確定した台詞。変えない |

- 既存の文で、すでに「九頭竜の力」と「鱗」が結び付いています。変異したサルの前腕の鱗も青みなので、今回の決定と合っています。

## 3. 決めてほしいこと（ユーザー・ChatGPT）
1. **加工の手順：** どこで、何を使って加工するか。
   - 作業台で「変異した鱗 → 加工した素材」にするのか。
   - 特別な施設（5）でしか加工できないのか。
   - 加工した素材の名前。加工に要る素材と数。
2. **新しい武器：** 何を何本作るか。
   - 既存の系統（鉈・斧・棍棒・槍）の上位にするか、新しい系統にするか。名前と見た目の方向。
   - 例：牙槍のように、鱗を刃や穂先にした武器。
3. **新しい装備（防具）：** 新しい4つ目の系統（4部位）にするか、既存の防具の強化にするか。名前と効果の方向。
4. **九頭竜の力を使う攻撃：**
   - どんな攻撃か（形・効果）。
   - 使える条件：鱗の武器を持つとき／防具一式／溜まる力（ゲージ）／回数制限など。
   - 操作：新しいボタンか、既存の操作（強攻撃の長押しなど）か。iPhone のボタン配置も要る。
   - 物語との関係：ヌシは「九頭竜様の力に心を奪われた」と語っている。人がその力を使うことに、代償や戒めの描写を入れるか。台詞は、承認されたものだけを入れる。
5. **特殊な施設：** 何をする施設か、どこに建てるか。
   - 光明寺に建てるか、上志比の拠点（P3）か。
   - P3 の拠点施設の一つにするか。
6. **入手量と必要数：** いま鱗は倒すと2つ。変異したサルが普段どこに・どれくらい出るかは未定で、これで集めやすさが決まる。武器・防具・施設に何枚ずつ要るか。
7. **入れる時期：** P2 の中で作るか、P3 以降（拠点施設と一緒）にするか。

## 4. 必要な3Dモデル
- 武器と防具は、主人公が身に着ける物です。いまの武器・防具と同じく Claude がコードで作り、確認用の画像（`tools/char-studio.py`）で承認を得ます。Tripo は不要の見込みです。
- 九頭竜の力の攻撃の演出（光・水・波など）も、コードで作ります。
- 施設は、形が決まってから判断します。P3 の拠点施設と同じ扱いで、まず仮モデル、一部を Tripo にする可能性があります。

## 5. 既存システムとの依存
| 決めること | かかわる仕組み |

| セーブ | 新しい持ち物・武器・防具・施設は、どれも既定値つきの新しいキーで足せる。保存キーと `v:1` は変えない（`docs/save-and-flags.md`） |

## 6. 技術的な注意
- 牙槍（通常22・強58）は、いまでも変異したサルを15〜18秒で倒します（測定ボット）。鱗の武器をそれより強くすると、強敵の意味が薄れます。強さの差は、九頭竜の力の攻撃にもたせるほうが調整しやすいです（案）。
- 新しい技は、攻撃の向き・当たり判定・見切り・持ち替えの仕組みと組み合わさります。入れたら `tests/combat-aim.cjs` を通します。
- 新しいボタンは、iPhone の画面の配置を変えます。

## 7. 推奨する順序（案）
1. 上の質問1〜7を決める。台詞が要るなら、その文も決める。
2. 加工と、新しい武器を1つ作る。鱗の数は暫定でよい。
3. 九頭竜の力の攻撃（その武器に付ける形が、試しやすい）。
4. 防具（P2 の防具の作り直しが承認されてから）。
5. 特殊な施設（P3 の拠点施設と一緒）。
6. 鱗の入手量と必要数を、試遊で調整する。
