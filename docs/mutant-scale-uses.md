# 変異した鱗の使い道（v0.63、2026-11-13）

## 1. ユーザー決定
1回目（2026-11-13）：
- 変異した鱗を、人間が使えるように加工し直す。
- 加工した鱗から、新しい装備と武器を作れる。
- 九頭竜の力を応用した攻撃が使えるようになる。
- 特殊な施設を作る材料にもなる。
- 入手：初遭遇で逃げられたときに1つ落とすのでよい。
- 変異したサル：体力は600（「若干弱く」→ v0.62.1）。跳んでかわす・猛り狂うは残す。

2回目（2026-11-13、「作る前に決めること」への回答）：

| 項目 | 決定 |
|---|---|
| 1 加工 | 特別な施設で加工する。ほかの素材は要らない。その機械を動かす燃料が要る。すぐにはできず、少し時間がかかる |
| 2 武器 | 4つの武器それぞれの上位を作れる。さらに新しい武器も足す |
| 3 防具 | 新しい系統をそろえる。ほかの装備・武器より明らかにコストを高くする |
| 4 加工した鱗の武器 | 人間が使える形にしたものなので、特殊な青っぽく光るエフェクトと、高いダメージだけ |
| 4 鱗をそのまま使う武器 | 加工せずに使っても上位武器を作れる。もっとまがまがしいオーラを放ち、何かの代償を伴う（**後で検討**） |
| 4 新しい武器 | 飛び道具を検討している（**要検討**） |
| 4 加工した鱗の防具 | 同じく青っぽいオーラと、高い防御力 |
| 4 鱗をそのまま使う防具 | 防具に体力を吸われて体力が0.7倍。機動力が大幅に上がる。一定時間ごとにためた力を周りに放ち、衝撃波で周りの敵を吹き飛ばす（ダメージはなし） |
| 5 施設 | 特殊素材を人間が使える形に変換できる施設 |
| 6 コスト | だいぶ高くする |
| 7 入れる時期 | Claude に任せる → P2 の中で、決まった分から入れる（v0.63）。未定の分は決まってから |

## 2. 実装したもの（v0.63）
名前・数値・場所・燃料は、すべて**暫定**です。

### 変換炉（特殊素材を変換する施設）
- 作業台の「変換炉を組み立てる」で作る（変異した鱗を持っていると出る）。
  - 素材：変異した鱗2・屑鉄6・石8・木材10。
  - 光明寺の拠点の南東の隅（x 166・z 73.4）に現れる。当たり判定がほかの物と重ならないことを確かめた。
- 調べると、次を選べる。
  - 変異した鱗を入れる（1つにつき燃料の木材2）。
  - 入れられるだけ入れる（最大6つまで待たせられる）。
  - できた加工した鱗を取り出す。
- 1つ90秒かけて加工した鱗になる。遊んでいる間だけ進む（菜園と同じ）。動いている間は窓が青く光り、焚き口が赤く、煙突から煙が出る。
- 変換の表は `CONV.rec` にある。特殊素材が増えたら行を足せる。
- 燃料はいま木材。**何を燃料にするかは決めてほしい**（下の質問1）。

### 鱗の武器（加工した鱗で4つの武器の上位を作る）
| 新しい武器（仮称） | 元の武器 | 通常／強 | 届く距離 | 耐久 | 素材 |
|---|---|---|---|---|---|
| 鱗の鉈 | 業物の鉈（Lv3）18／46 | 26／64 | 2.7 | 260 | 加工した鱗3・屑鉄3・獣素材4 |
| 鱗の斧 | 鉄の斧 16／44 | 22／60（木を切る力3.5） | 2.6 | 300 | 加工した鱗3・屑鉄4・木材2 |
| 鱗の棍棒 | 木の棍棒 11／32 | 20／52 | 2.8 | 240 | 加工した鱗3・木材4・獣素材3 |
| 鱗の槍 | 牙槍 22／58 | 30／78 | 3.4 | 360 | 加工した鱗4・木材4・獣素材4 |

- 作業台で、元の武器をこの武器に作り替える（鉈を鍛えるのと同じく、元の武器は無くなる）。
- 見た目：元の武器の形に、青い鱗の板と脈打つ青い光を足した。刃から青い光の粒が立ち、振ると流線が青く、当たると青い火花が出る。
- 特別な技は付けていない（決定4「エフェクトと高いダメージだけ」）。

### 鱗の防具（新しい2つの系統）
| 系統（仮称） | 素材（4部位の合計） | 効果 |
|---|---|---|
| 青鱗（加工した鱗） | 加工した鱗12・獣素材12・屑鉄2・縄8 | 被ダメージ 頭-5%・胸-8%・脚-6%・靴-5%。4部位の軽減の上限を15%→30%に上げ、一式で **-30%**（山守の一式は上限の-15%）。青い光の粒をまとう |
| 変異鱗（変異した鱗をそのまま） | 変異した鱗9・獣素材9・縄5 | 1部位ごとに最大体力 -7.5%（4部位で **0.7倍**）・移動+5%・回避消費-5%（一式で1.5倍＝**移動+30%・回避消費-30%**）。紫の光の粒をまとう。一式で**衝撃波** |

- **衝撃波（変異鱗の一式）：**
  - 10秒で力がたまる（画面の左上に「変異鱗：衝撃波 あと○秒／たまった」）。
  - たまった状態で、獣が4.5以内に来ると自動で放つ。
  - 6.5以内の獣を外へ押し出す（ふつうの獣は約4.5、クマは約2.2、ヌシは約0.6）。ダメージ・体勢削りはない。紫の輪が広がる。
- 4部位の上限・一式の1.5倍は、山守・沢追いと同じ仕組み（`G47`・`f47Stats`）。
- **見た目は仮：** 形は山守（青鱗）・沢追い（変異鱗）の服を借り、色だけ変えている。P2 の防具の作り直し（承認待ち）が決まったら、専用の形を作って確認画像で承認を受ける。

### 作業台に出る条件
- 変換炉：変異した鱗か加工した鱗を持っているとき。
- 鱗の武器：元の武器を持っていて、加工した鱗を持っているか変換炉があるとき。
- 青鱗：加工した鱗を持っているか変換炉があるとき。変異鱗：変異した鱗を持っているとき。

### 本編で手に入るか
- まだ手に入らない。変異した鱗を落とす変異したサルが、本編ではまだどこにも出ないため（作業F と、普段の出し方が未定）。
- 試遊版 `previews/p2-mutant/` の「鱗の装備を試す（拠点へ）」で、素材を足して拠点へ戻り、すぐ試せる。「変換炉を早送り」で、加工を待たずに終えられる。

## 3. まだ決まっていないこと（質問）
1. **燃料：** 何を燃料にするか。いまは木材2（1つあたり）。藁・炭・油（軽トラックと関係させる）など。
2. **名前：** 変換炉・加工した鱗・鱗の鉈／斧／棍棒／槍・青鱗・変異鱗は、どれも仮の名前。
3. **鱗をそのまま使う武器：** 代償の中身（後で検討）。まがまがしいオーラは、変異鱗の防具の紫の光を元に作れる。
4. **新しい武器（飛び道具）：** 種類（投げる・撃つ）、弾の扱い（数・拾う・作る）、操作（狙い方。iPhone のボタン）。
5. **防具の見た目：** 青鱗・変異鱗の専用の形。P2 の防具の作り直しの承認と合わせる。
6. **衝撃波：** 自動で放つ形にした（獣が近づくと放つ）。ボタンで放つほうがよければ変える。部位がそろっていないときは、体力の減りと身のこなしだけ（衝撃波なし）。
7. **数値：** 変換の時間（90秒）・素材の数・威力・防御・衝撃波の間隔は試遊で調整する。

## 5. セーブ（`docs/save-and-flags.md`）
- 新しいキー `conv`（変換炉：建てたか・待っている数・進み・できた数）。旧セーブは未建設で読む。
- `inv.procScale`（加工した鱗）。旧セーブは0。
- 鱗の武器は `prog.arms` の新しい武器名（`scNata`・`scAxe`・`scClub`・`scSpear`）、防具は `prog.gear` の新しい名前（`blue_*`・`raw_*`）。どちらも既存の読み込み（知らない名前は読み飛ばす）でそのまま動く。
- 保存キー・`v:1` は変えていない。
