# 変異した鱗の使い道（v0.63〜v0.65、2026-11-13）

## 1. ユーザー決定
1回目（2026-11-13）：
- 変異した鱗を、人間が使えるように加工し直す。
- 加工した鱗から、新しい装備と武器を作れる。
- 九頭竜の力を応用した攻撃が使えるようになる。
- 特殊な施設を作る材料にもなる。
- 入手：初遭遇で逃げられたときに1つ落とすのでよい。
- 変異したサル：体力は600（「若干弱く」→ v0.62.1）。跳んでかわす・猛り狂うは残す。

2回目（2026-11-13）：

| 項目 | 決定 |
|---|---|
| 加工 | 特別な施設で加工する。ほかの素材は要らない。その機械を動かす燃料が要る。すぐにはできず、少し時間がかかる |
| 武器 | 4つの武器それぞれの上位を作れる。さらに新しい武器も足す |
| 防具 | 新しい系統をそろえる。ほかの装備・武器より明らかにコストを高くする |
| 加工した鱗の武器 | 人間が使える形にしたものなので、特殊な青っぽく光るエフェクトと、高いダメージだけ |
| 鱗をそのまま使う武器 | 加工せずに使っても上位武器を作れる。もっとまがまがしいオーラを放ち、何かの代償を伴う（**代償は後で検討**） |
| 加工した鱗の防具 | 同じく青っぽいオーラと、高い防御力 |
| 鱗をそのまま使う防具 | 防具に体力を吸われて体力が0.7倍。機動力が大幅に上がる。ためた力を周りに放ち、衝撃波で周りの敵を吹き飛ばす（ダメージはなし） |
| 施設 | 特殊素材を人間が使える形に変換できる施設 |
| コスト | だいぶ高くする |
| 入れる時期 | Claude に任せる → P2 の中で、決まった分から入れる |

3回目（2026-11-13）：

| 項目 | 決定 |
|---|---|
| 燃料 | かまど（料理機能も足す施設。**名前は未定**）を今後の施設に足し、そこで木材を焼いて木炭を作る。木炭を変換炉の燃料にする。かまどは木材で動く |
| 名前 | 変換炉＝変換炉。加工した鱗の武器＝**蒼鱗の〜**（例：蒼鱗の鉈）。鱗をそのまま使う武器＝**変異鱗の〜**（例：変異鱗の鉈）。防具の系統：青鱗→**蒼鱗**、変異鱗→**変異した鱗** |
| 衝撃波 | ボタンで、好きなときに出せる |
| 新しい武器 | 飛去来器（ブーメラン）。名前は「**鱗の飛去来器**」。投げると自分のもとへ帰ってくる。好きなときに、飛去来器の周りに衝撃波を起こす。耐久は低め（コストのわりに10回くらいしか使えない） |
| 防具の形 | 全面を鱗で覆うのではなく、**金属を土台に、ところどころに鱗を埋め込む** |
| 防具の光 | 埋め込んだ鱗や、すき間からあふれ出る。変異した鱗のほうは、紫の光ではなく、**暗い紫のオーラがもくもくと漂う** |
| 武器の形 | ユーザーが ChatGPT と Tripo AI で作っている。通常の武器の形も変えているので、あとで届く。それまでは適当な形で進める |

4回目（2026-11-13）：

| 項目 | 決定 |
|---|---|
| 防具の形 | **納得いかない（不採用）。** あとで、防具の見た目の改善要求を個別に送る |
| 着替えの仕組み | 以前の設計（通常の服も装備として着脱できる・既存の防具の見た目の直し・帽子から髪が飛び出さない）は**採用** → v0.65 で main へ |
| かまど | 名前は「かまど」。食材の種類（肉・野菜・米など）を少し増やし、今の作業台の料理と新しい料理を作れるようにする → `docs/kamado-cooking-plan.md` |
| 飛去来器の衝撃波 | 傷を与えるものでよい |
| 防具の部位の名前 | 頭部装甲・胸部装甲・脚部装甲・足部装甲 |

## 2. 実装したもの（v0.65）
名前のうち、ユーザーが決めたもの以外（加工した鱗・木炭）と、数値・場所は**暫定**です。

### かまど
- 作業台の「かまどを築く」で作る（v0.66：石4・木材4。最初から築ける）。
- 光明寺の拠点の南東、変換炉の西隣（x 161・z 73.9）に築く。白い漆喰の胴・焚き口2つ・羽釜・炭を焼く鉄の箱・煙突の形。
- 木材3（材料2・燃料1）で、1つ30秒で木炭ができる（遊んでいる間だけ進む。最大6つ分まで待たせられる）。焼いている間は焚き口が赤く揺れ、煙が出る。
- 料理は v0.66 で入れた（`docs/kamado-cooking-plan.md`）。

### 変換炉
- 作業台の「変換炉を組み立てる」で作る（変異した鱗2・屑鉄6・石8・木材10）。拠点の南東の隅（x 166・z 73.4）。
- 燃料は木炭（v0.64）。変異した鱗1と木炭1で、1つ90秒で加工した鱗になる。木炭がないと動かない。
- かまどと変換炉は同じ仕組み（`FAC` の表、`facPut`・`facTake`・`facUpdate`）。特殊素材が増えたら表に行を足せる。
- どちらも、建てるまでは形も当たり判定も作らない（作ると乱数の進みが変わり、防衛戦の測定がずれるため）。

### 武器
| 武器 | 元の武器 | 素材 | 通常／強 | 耐久 | 見た目（仮） |
|---|---|---|---|---|---|
| 蒼鱗の鉈・斧・棍棒・槍 | 業物の鉈（Lv3）・鉄の斧・木の棍棒・牙槍 | 加工した鱗3〜4＋屑鉄・獣素材・木材 | 鉈26/64・斧22/60・棍棒20/52・槍30/78 | 240〜360 | 鱗の板と脈打つ青い光。青い流線と火花、刃から青い光の粒 |
| 変異鱗の鉈・斧・棍棒・槍 | 同じ | **変異した鱗**3〜4＋同じ | 蒼鱗と同じ（**暫定**） | 同じ | 暗い紫の鱗とにじむ暗い光。暗い紫の流線と火花、刃から暗いもや |
| 鱗の飛去来器 | なし（新しく作る） | 加工した鱗3・屑鉄3・木材2 | 当たり18・衝撃波20 | **10** | く字の金属の板に鱗を埋め込み、青く光る |

- 蒼鱗・変異鱗の武器は、元の武器を作り替える（元の武器は無くなる）。
- **変異鱗の武器の代償はまだ入れていない**（後で検討）。代償がないうちは強さが蒼鱗と同じ。代償が決まったら、強さを上げることもできる。
- 武器の形は仮。ユーザーが ChatGPT・Tripo で作っている形が届いたら差し替える（`scaleArmDeco`・`boomerShape`）。

### 鱗の飛去来器
- 持ち替え（R・持ち物・手持ちバー）で持つ。攻撃で投げ、強攻撃でもっと遠くへ投げる（スタミナ15）。
  - 通常の投げは約12、強攻撃は約16まで飛んで、自分のもとへ戻る。壁や物に当たると、そこから戻る。
  - 行きと帰りに、触れた獣に18の傷。
- 飛んでいる間にもう一度攻撃すると、飛去来器の周り（4.5）に衝撃波が起き、獣を押し出して20の傷（1回の投げで1回）。押し出す距離はふつうの獣が約3.5、クマは半分、ヌシはわずか。
- 投げるたびに耐久が1減る（10回分）。0になると投げられない。作業台の「飛去来器の手入れ」（加工した鱗1）で戻る。ふつうの「武器の手入れ」（木材1）では直らない。
- 飛んでいる間は持ち替えられない。
- 衝撃波は傷を与える（2026-11-13 ユーザー決定）。

### 防具
| 系統 | 部位 | 素材の合計 | 効果 |
|---|---|---|---|
| 蒼鱗（加工した鱗） | 頭部装甲・胸部装甲・脚部装甲・足部装甲（ユーザー決定） | 加工した鱗12・獣素材12・屑鉄2・縄8 | 被ダメージ 頭-5%・胸-8%・脚-6%・足-5%。4部位の軽減の上限を15%→30%に上げ、一式で **-30%** |
| 変異した鱗（鱗をそのまま） | 同じ | 変異した鱗9・獣素材9・縄5 | 1部位ごとに最大体力 -7.5%（4部位で **0.7倍**）・移動+5%・回避消費-5%（一式で **移動+30%・回避消費-30%**）。一式で**衝撃波** |

- **形（v0.64）：不採用（2026-11-13 ユーザー「納得いかない」）。** 改善要求が届くまでの仮として残している。金属の板を体に沿わせ、ところどころに小さな鱗を埋め込んだもの。
  - 頭：鉢と額の板（鱗3）。
  - 胴当て：胸当て・背当て・腰の帯・肩当て・籠手（鱗9）。
  - 腿当て：腿の前と外側の板（鱗1ずつ）。
  - 脛当て：脛の板・膝・つま先（鱗1ずつ）。
  - 蒼鱗は明るい鋼に青い鱗、変異した鱗は黒ずんだ鉄に暗い紫の鱗。古い体（v0.32.1）の骨に硬い板として付けた。体そのものは変えていない（防具なしの主人公は main と画素単位で同じことを確かめた）。
- **光（v0.64）：**
  - 蒼鱗：埋め込んだ鱗と、すき間（首・腰・肩・膝）から青い光の粒があふれる。胸当てと腰の帯のすき間が青く光る。
  - 変異した鱗：同じ所から暗い紫のもやが、もくもくと立ちのぼる。力がたまると濃くなる。
- **衝撃波（変異した鱗の一式、v0.64）：**
  - 10秒で力がたまる。たまったら **F キー**（スマホは「衝撃」ボタン）で、好きなときに放つ。自動では出ない。
  - 6.5以内の獣を外へ押し出す（ふつうの獣は約4.5、クマは約2.2、ヌシは約0.6）。ダメージはない。
  - 画面の左上に「変異した鱗：衝撃波 あと○秒／放てる（F）」。スマホの「衝撃」ボタンは一式のときだけ出て、たまると紫に光る。
- v0.65 で着替えの仕組み（服を丸ごと着替える体）が main に入った。鱗の防具の板は、その体の骨にも同じように付く（初期の服の上に重なる）。

### 本編で手に入るか
- まだ手に入らない。変異した鱗を落とす変異したサルが、本編ではまだどこにも出ないため。
- 試遊版 `previews/p2-mutant/` の「鱗の装備を試す（拠点へ）」で素材を足して拠点へ戻れる。「施設を早送り」で、かまど・変換炉の待ちを飛ばせる。

## 3. まだ決まっていないこと（質問）
1. **かまどの料理：** 食材の種類と料理の中身（`docs/kamado-cooking-plan.md` の質問）。
2. **変異鱗の武器の代償：** 後で検討（ユーザー）。決まったら、強さも合わせて決める。
3. **防具の形：** ユーザーの改善要求を待つ。
4. **名前：** 加工した鱗・木炭は仮の名前。
5. **数値：** 時間（木炭30秒・加工90秒）・素材の数・威力・防御・衝撃波の間隔・飛去来器の距離と耐久は、試遊で調整する。

## 5. セーブ（`docs/save-and-flags.md`）
- 新しいキー `conv`（変換炉）・`kama`（かまど）：建てたか・待っている数・進み・できた数。旧セーブは未建設で読む。
- `inv.procScale`（加工した鱗）・`inv.charcoal`（木炭）。旧セーブは0。
- 武器は `prog.arms` の新しい名前（`scNata`…`scSpear`・`rwNata`…`rwSpear`・`boomer`）、防具は `prog.gear` の新しい名前（`blue_*`・`raw_*`）。どちらも既存の読み込み（知らない名前は読み飛ばす）でそのまま動く。
- 保存キー・`v:1` は変えていない。
