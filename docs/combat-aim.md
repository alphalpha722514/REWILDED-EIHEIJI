# 攻撃の向きと当たり判定 — v0.58（2026-11-12）

## ユーザーの指摘
- 通常攻撃を連打している間は、WASD を入れても最初に攻撃した方向へ進みながら連続攻撃が続き、向きを直せない。
- 当たり判定がシビア（特に槍）。

## 原因（v0.57 のコード）
- 攻撃の向きは技が出た瞬間に固定され、連続攻撃の次の技は「ボタンを押した瞬間の向き」（キー・タッチなら体の向き、クリックならその時のカーソル）を使っていた。移動入力は見ていなかった。
- 槍の当たりは柄の穂先側の半分だけ、太さ 0.2m。横に少しずれた獣や、近すぎる獣に当たらなかった。

## 変更
1. **技が出る瞬間に、移動入力（WASD・スティック）があればその方向へ向き直す。** 連続攻撃の途中でも同じ。カーソル操作中でも移動入力が優先。
2. **狙いの補助：** 入力の向きから ±40° 以内で届く範囲（武器の間合い＋1.2m）に獣がいれば、その獣へ向ける。
3. 移動入力がないときは、カーソル操作中なら「技が出る瞬間」のカーソルへ（押した瞬間ではなく）。それ以外は従来どおり。
4. **当たりの太さ：** 斬り 0.25→0.32、突き 0.2→0.36、足払い 0.3→0.36、回転 0.25→0.3（打撃 0.4 は据え置き）。
5. **槍：** 当たりを柄の穂先側の半分→7割に。自動の狙いの範囲 0.6→0.9 rad。
6. 高さの余裕（獣の体の上下）0.3→0.45m。

武器の威力・間合いの数値、技の時間は変えていない。プレイヤーの攻撃の変更なので、第1章を含む全ての戦闘に効く。
