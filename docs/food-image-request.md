## 2. 絵の決まり

| 項目 | 決まり | 理由 |
|---|---|---|
| 大きさ | 正方形（1024×1024） | ゲームでは 256×256 に縮める。手持ちバーでは 40〜60px ほど |
| 背景 | **透明**（PNG） | 手持ちバー・持ち物の画面は暗い茶色。白い背景が付くと浮く |
| 文字 | 入れない（料理名・ロゴ・署名・枠も無し） | 名前はゲームが出す |
| 向き | 斜め上 45°くらいから見下ろす。器が画面の 8割ほど・真ん中 | 今の3Dの道具の絵と並べてそろう |
| 光 | 左上から。やわらかい | 19枚をそろえる |
| 描き方 | 温かみのある手描き風（少し厚塗り）・細めの輪郭線・色は少し落ち着かせる | 小さくしても形が分かる。ゲームの和紙の色の画面になじむ |
| 器 | 素朴な和の器（漆の椀・土鍋・竹の皮・木の盆・ざる）。災害のあと、寺や家から持ち出した器でかまどの火で作った料理 | ゲームの世界（永平寺の村・復興の途中） |
| 入れない物 | 人・手・箸を持つ手・テーブル全体・背景の景色 | 料理だけを見せる |

## 3. ChatGPT へのプロンプト

使い方：
1. 下の【最初に一度だけ送る文】を送る。
2. 続けて【料理ごとの文】を1つずつ送る（1回に1枚）。
3. 1枚目が良ければ、2枚目からは文の最後に「1枚目と同じ描き方・同じ角度・同じ光で」と足すと、そろいやすい。
4. 背景が白や格子模様で出たら「背景を透明にして、PNG で出し直して」と送る。

### 【最初に一度だけ送る文】

```
日本の山あいの村を舞台にした3Dゲーム「REWILDED EIHEIJI」の、アイテムの絵（料理のアイコン）を19枚作ってほしいです。
舞台は福井県永平寺町。災害のあと、人々が寺や家から持ち出した器を使い、かまどの火で料理をしています。
これから料理を1つずつ伝えるので、1回に1枚ずつ作ってください。

全部の絵に共通の決まり：
・正方形 1024×1024 の PNG。背景は完全に透明（白や模様の背景を付けない）。
・料理と器だけを描く。文字・料理名・ロゴ・署名・枠は入れない。人・手・テーブル全体・背景の景色も入れない。
・斜め上45度くらいから見下ろす角度。器が画面の8割ほどの大きさで、真ん中に置く。
・光は左上から、やわらかく。影は器の真下にごく薄く（なくてもよい）。
・描き方：温かみのある手描きのイラスト。少し厚塗りで、細めの輪郭線。色は鮮やかすぎず、少し落ち着いた自然な色。
・器は素朴な和の器（漆の椀・土鍋・竹の皮・木の盆・ざる など）。新品ではなく、使い込んだ感じ。
・ゲームの画面では 64px くらいまで小さくなるので、形と色がはっきり分かるように。細かい模様より、料理の特徴が一目で分かることを優先。
・19枚とも、同じ描き方・同じ角度・同じ光でそろえる。
```

## 4. 受け渡しと組み込み

- できた絵は、**このチャットに添付**してもらえれば、こちらで受け取る（ファイル名がちがっていても、料理名が分かれば対応できる）。GitHub に直接入れる場合は `assets/food/` に、上の表のファイル名で。
- 組み込み（絵が届いてから）：
  1. 透明になっているか・大きさを確かめ、256×256 の PNG に縮めて `assets/food/<ファイル名>` に置く（元の 1024 の絵は `assets/food/src/` に残す）。
  2. ゲームの起動時に絵を読み、手持ちバー・持ち物の画面など、料理の絵が出る所すべてで使う（今は `iconOf` の3Dの絵。読めなかったときは今の3Dの絵のまま）。
  3. かまどの「食べる」と食料庫の画面は、今は名前だけ。絵が届いたら、そこにも小さく出すことができる（決めてほしいこと）。
  4. 試遊版（`previews/` の下）からも読めるようにする。
  5. 版を `docs/asset-registry.md` に記録する（ChatGPT で作った絵・作った日・元の大きさ）。
- 19枚そろわなくても、届いた分から入れられる（届いていない料理は今の3Dの絵のまま）。
