## 1. 開発目標（案）と、入れないもの

**目標**：防衛戦のあと、物語として上志比へ向かい、山王でスズキと出会って仲間にするまでを、一続きのイベントにする。

1. **救援無線**：拠点の無線室の無線機から、途切れ途切れの救援の声が届く。
2. **出発**：トミオ・源さん・慧心と話し、上志比へ向かうことになる（短い会話）。
3. **山王での初遭遇**：
   - 短いカット：スズキが変異したサルに追われている。
   - 戦闘：サルは傷を受けると逃げ去る（倒せない）。
   - 会話：スズキと話す。
   - 仲間に：スズキがついて来るようになる。
4. 初遭遇のあと、上志比の町の群れに変異したサルが加わる。これで本編でも「変異した鱗」が手に入るようになる（仕組みは v0.67 で作り済み）。

**入れないもの**：第3〜5章、双子猿（第2章ボス）、スズキの探し人の物語の続き、変異鱗の武器の代償（別の判断待ち）。

## 4. 不明な仕様（ユーザー・ChatGPT に決めてほしいこと）

**台詞**
1. 救援無線・出発イベントの案（`docs/p2-drafts.md`）を承認するか、直すか。
2. 初遭遇の台詞。確定しているのはスズキの名乗りだけ。次の場面の台詞が要る：
   - (a) 追われているときのスズキの叫び。
   - (b) サルが逃げたあとの会話（お礼・名乗り・無線との関係）。
   - (c) 仲間になる流れ。
   - 誰が書くか（ChatGPT／Claude が案を作る／ユーザー）。
3. 無線の声はスズキだったのか。仲間になる会話で触れるか、伏せたままにするか。

**流れ**

4. **無線が鳴るきっかけ。** 例：
   - (a) 防衛戦を終えた直後に自動で鳴る。
   - (b) 防衛戦のあと、無線室に近づくと鳴る。
   - (c) 次の日の朝。
5. **上志比へ行ける時期。** 今は防衛戦を終えるとすぐ行ける。出発イベントのあとに限るか。
6. **すでに防衛戦を終えたセーブの扱い。** 試遊などで、もう上志比へ行けるセーブがある。次に光明寺にいるとき無線のイベントを起こすか、出発済みとして扱うか。
7. **出発イベントの場所と顔ぶれ。** 無線室の前に、トミオ・源さん・慧心が集まる、でよいか。米田は出るか。
8. **初遭遇が起きる場所と条件。** 例：山王の駅のまわり（半径30m ほど）に初めて入ったとき。そこまでの道で、ほかの獣を減らすか。
9. **カットの長さと中身。** 案：5〜8秒。スズキが走って逃げ、サルが追い、主人公に気づく。カメラは引きの画。
10. **戦闘中のスズキ。** どれか：
    - (a) 逃げ回る。
    - (b) 少し離れて見ているだけ。
    - (c) 蹴りで一緒に戦う（仲間 AI を早めに動かす）。
    - サルはスズキを狙い続けるか、主人公に向くか。
11. **初遭遇で負けたとき。** 例：西の端で起き、もう一度山王へ行くとカットからやり直す。スズキはその間どうしているか。
12. **仲間になったあと。**
    - 指示の出し方の案内（チュートリアル）を出すか。
    - 光明寺に戻ったとき、町民との会話を足すか。

**記録・報酬**

13. 初遭遇で落ちる鱗の数（今は `fleeDrop:1`。暫定）と、ほかの報酬（経験値など）。
14. 目標の表示（画面上の「次にすること」）の文言。今の「第二章：光明寺防衛戦を完了。東の出口（国道416号）から上志比へ向かえる」をどう変えるか。

## 7. 想定される技術的問題

**作業環境で確かめたこと**
- 逃げ去るサル（`fleeOnly`）は、試遊版 `previews/p2-mutant/` とテストで動いている。
- スズキの仲間 AI と、地域をまたぐセーブも、テストで動いている。

**まだ試していないこと（作るときに確かめる）**

| 問題 | 対策 |
|---|---|
| 仲間になる前のスズキを動かす仕組みがない | 「台本どおりの動き」（決まった道を走る・止まる・向く・怯える）を小さく足す。仲間 AI とは分ける |
| カットの仕組みがヌシ専用 | 黒い帯・操作停止・カメラの道筋を、イベント用に使い回せる形で新しく作る。ヌシの演出はそのまま |
| 山王で町の群れ・獣と混ざる | カットと初遭遇の間は、山王のまわりに新しい獣を出さない。近くの群れは遠ざける |
| 変異したサルの形の読み込み待ち | 山王に近づいた時点で先に読み込む。読めないときは少し待ってから始める |
| 旧セーブの扱い | 第4節6の決定に合わせる。どちらでも、上志比に行けなくなるセーブを作らない |
| 途中でセーブ・地域移動・倒れる | イベントの段階を `chapter2.progress` に残し、カットや戦闘の途中は「始まる前」に戻して保存する（防衛戦と同じ考え方） |
| iPhone の重さ | カットの間は描くものが増えない作りにする。実機の確認はユーザーにお願いする |

## 8. 推奨する開発順序

1. **第4節を決める**（ユーザーと ChatGPT）。特に、台詞（1〜3）と流れ（4〜6・10・11）。
2. **仕組みを仮の台詞で作る**（作業ブランチ）。台詞の承認がなくても作れる部分。
   - イベントの段階と保存。
   - 使い回せるカット。
   - 仲間になる前のスズキの動き。
   - 初遭遇の戦闘と逃げ去り、`mutantMet`、`szJoin()`。
   - 試遊版で通しで遊べるようにする（本編には入れない）。
3. **承認された台詞を入れる** → テスト（新しく「無線〜仲間に」の通し）・既存テスト → main へ。
4. **試遊**（PC・iPhone はユーザー）→ 調整：
   - カットの長さ。
   - 初遭遇の強さ（傷230で逃げる）。
   - 上志比の変異したサルの多さ。
