## 6〜9. FPS・描画呼び出し回数・三角形・メモリ（§26-6〜9）

画面のない Chromium（SwiftShader：GPU を使わず CPU で描く）・1280×720・同じカメラ。描く回数と三角形は、その1枚を描いたときの `renderer.info`。ジオメトリとヒープは、上志比に入って屋内に入ってから、その地点までの合計。

**屋内**（v0.80 → v0.81）

| 地点 | 描く回数 | 三角形 | GPU に送ったジオメトリ（累計） | JS ヒープ MB | FPS（SwiftShader・参考外） |
|---|---|---|---|---|---|
| 入口ホール | 38 → 53（+15） | 544,938 → 544,984 | 554 → 576 | 216.6 → 216.7 | 1.3 → 0.9 |
| 倉庫 | 37 → 63（+26） | 544,926 → 545,158 | 554 → 583 | 217.1 → 217.2 | 2.8 → 2.9 |
| 総合作業場 | 38 → 59（+21） | 544,938 → 545,086 | 554 → 585 | 216.3 → 217.3 | 2.3 → 2.3 |
| 2階 | 37 → 59（+22） | 544,926 → 545,104 | 554 → 599 | 217.3 → 217.4 | 3.1 → 2.4 |

**外（本部の前。P3-A の地点A と同じカメラ）**：描く回数 159 → 158、三角形 884,627 → 885,675（+0.1%。解体できる軽トラを別の形にした分）、ヒープ 220.4 → 225.1MB。

- 屋内で描く回数が +15〜+26 になったのは、手前の壁を消せるように壁の上半分を壁ごとに分けたのと、引き戸10枚のため。三角形はほとんど変わらない（屋内の形は数百）。
