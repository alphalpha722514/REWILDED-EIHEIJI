## 骨（21本）
座標はゲームの単位（前 +Z・上 +Y・足の裏 y=0。高さ 1.95）。体の左が +x（向かって見ると右）。
| 骨 | 親 | 関節の位置（左。右は x を逆に） |
|---|---|---|
| root | — | (0, 0, 0)（体全体の移動・倒れる回転に使う） |
| hips | root | (0, 1.10, −0.38) |
| spine → chest → neck → head | | (0, 1.30, −0.15) → (0, 1.50, 0.05) → (0, 1.55, 0.25) → (0, 1.62, 0.42) |
| tail1 → tail2 → tail3 | hips | (0, 1.156, −0.542) → (0, 1.163, −0.683) → (0, 1.135, −0.825) |

位置の決め方：v2 の形の正投影の目盛り画像（`tools/models/ortho.py`）と、高さごとの断面の中心から決めた。

## 重み（`tools/models/mm_rig.py`）
1. 骨の線分からの距離で付ける。
2. 部位の区切りを守る。
   - 左右の手足は反対側に付けない。
   - 腕は体の前側、脚は後ろ側で腰より下に限る。
   - 頭は首より前・上に限る。
   - 尾は尾の部品だけに付け、付け根は腰へ少しつなぐ。
3. 面のつながりに沿って4回ならし、上位4本に絞る。

確認：
- 骨ごとの色の点の画像（`tools/models/weights_view.py`）
- 曲げた姿勢の画像6種（腕を上げる・脚を曲げる・首を回す・尾を上げる・背を丸める・前腕を振り下ろす）

## 見た目
- `MeshToonMaterial`（ゲームの3段の陰）＋色テクスチャ（Linear。glTF の UV なので `flipY=false`）。
- 輪郭線：ならした形（毛先のとげを体に収めた形）を別に持ち、骨で一緒に動かす。太さ 0.022 は獣の線と同じ。
- 形とテクスチャは全部の個体で共有する。1体あたり、骨と2つの SkinnedMesh。

## 動き（`mutantPose(m, 名前, 秒, 進み)`）
| 名前 | 中身 |
|---|---|
| idle 待機 | 息（胸）、頭を左右にゆっくり見回す、尾を振る、重心を少し移す |
| walk 歩く | 四つ足の歩き（左後ろ→左前→右後ろ→右前）。1.05 回/秒 |
| run 四つ足で走る | 前足2本・後ろ足2本がそろって跳ねる（バウンド）。背が伸び縮みし、体が上下する。2.3 回/秒 |
| pounce 飛びかかり | 0〜0.35 かがんでためる → 0.35〜0.75 跳ぶ（体を前へ倒し、両腕を相手へ伸ばし、脚を後ろへ） → 0.75〜1 着地 |
| scratch ひっかき | 右の大きな前腕で：0〜0.4 上体を起こして振りかぶる → 0.4〜0.55 振り下ろす → 戻る |
| flinch ひるみ | 頭と胸がのけぞり、腕が少し上がり、少し後ろへ下がる（0.6秒） |
| fall 倒れる | 横へ倒れ、手足の力が抜ける（1.6秒） |

- 跳ぶ・進むときの体の移動は AI 側で行う（確認動画では見るために動かしている）。
- 数値はすべて**暫定**。

確認動画：`python3 tools/models/mutant_anim_preview.py 出力フォルダ`
- 本編のコードを画面のない Chromium で動かして撮る。
- 出力は、7つの動きをつないだ動画・動きごとの連続画像・曲げた姿勢の画像。

## 分かっていること・まだのこと
- 立った形のとき、手の指先が地面より少し下に入る（高さの約5%）。動きの中では目立たない。AI に入れるときに、腕の休みの角度で直す。
- 手足を回すだけで地面に合わせていないので、歩く・走るとき足が少し滑る（ほかの獣と同じ作り）。
- 次：AI（凶暴化した猿と同じ攻撃＋固有の攻撃。今回は逃げ去る）→ 作業F。
