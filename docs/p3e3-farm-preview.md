## 遊び方

タイトル右上の「テスト：古い農家の前で始める」を押すと、作業Fと拠点本部の設立まで済んだ状態で始まります。KEI truck は修理済みで、スズキがついて来ます。朝9時の晴れで始まり、農家のそばでは獣を遠ざけます。「古い農家に入る」「外へ出る」の案内が出たら、PC では E キー、iPhone では行動ボタンを使います。

ついて来るスズキの「指示する」より古い農家の入口を優先します。入口の範囲を出ると、スズキに指示できます。

左上の「試遊メニュー」に場所、時刻、スズキの状態が出ます。メニュー名をもう一度押すと閉じます。

| ボタン | 動作 |
|---|---|
| 古い農家の前へ | 農家の入口の前に移動する。屋内では外へ出てから移動する |
| スズキ | 「ついて来る」と「ここで待つ」を切り替える |
| 時刻 | 朝9時、夕方17時、夜23時を順に切り替える。選択直後のゲーム内1時間は、その時間帯に対応した明かりで見比べられる |
| 描く細かさ | 標準と軽量を切り替える |
| 調査記録を初期化して試す | 8か所の調査記録と古い地図の印を消して保存する。拾った物は残り、初回の調査と報酬をもう一度試せる |

## E3-2 の確かめ方

1. 農家に入り、スズキがついて来ることを確認します。かまど、流しと水甕、農具の棚、囲炉裏、茶箪笥、仏壇、箪笥と長持、蔵の棚の8か所を調べます。初回の報酬は合計12個（木炭3、米2、縄2、屑鉄3、食料1、古い機械部品1）です。仏壇では地の文が出て、持ち物の数はそのままです。
2. 同じ所をもう一度調べ、持ち物が増えないことを確認します。蔵の棚で古い地図を見つけた後は地の文を閉じ、案内の帯を確認します。iPhone の帯には「地図」ボタンの案内があります。外で地図（PC は G、iPhone は「地図」ボタン）を開くと、よろず屋・集会所・薬草の生えやすい所の印と、凡例 `#oldMapLegend` が表示されます。
3. ページを開き直して「つづきから」を押し、調査記録と地図の印が残っていることを確認します。試遊メニューの「調査記録を初期化して試す」を押し、「拾った物は残ります」の知らせを確認します。再び「つづきから」を選ぶと、持ち物を保持したまま8か所を初回から調べられます。

## 作り直しと確認

指定コミットを含むローカルの履歴がある環境では、`python3 tools/build-p3e3-farm-preview.py` で元の blob を照合して生成できます。元のファイルが手元にある場合は `--src` で指定し、出力の「元」の blob が上記と一致することを確認します。既定の出力先は `previews/p3e3-farm/index.html` です。`--out` で別の出力先を指定できます。

```sh
python3 tools/build-p3e3-farm-preview.py --src index.html
PREVIEW_BUILD_SRC=index.html node tests/p3e3-preview-build.cjs
THREE_JS=/path/to/three.min.js node tests/p3e3-farm-preview.cjs
```

生成テストは元のファイルの blob、保存済みの試遊版とのバイト一致、ページ内の JavaScript の構文を確認します。`PREVIEW_BUILD_SRC` を省くと REF のコミットから生成します。試遊テストは Node の Playwright、Chromium、ローカルの three.js r128 を使います。PC（1280×720）と iPhone（390×844）で、入退室、かまど・仏壇・蔵の棚の調査と再調査、地図と案内の帯、初期化と読み直し、本編の保存・設定キーの分離を確認します。Chromium の実行ファイルを指定する場合は `CHROMIUM_BIN` を使います。ゲーム用のファイルは手元から読みます。

元の版にカメラの上下の設定キー `eiheiji_camPitch` がある場合は、試遊版専用の `eiheiji_p3e3f_camPitch` に置き換えます。

### 2026-11-26 のブラウザー確認（Claude Code）

- 試遊版のテストは PC・iPhone で3回とも合格しました。E3-2 の197項目、農家の30項目、画面の配置の107項目、スズキの21項目も合格しました。
- 入口の前でスズキが約1 m にいても、PC の E キーと iPhone のタップで入れました。入口から約7.4 m 離れると、PC の E キーでスズキの指示画面が開きました。iPhone のタップでは画面のモードが変わらず、main と同じ版でも同じ動作でした。
- 失敗②（試遊メニュー直後の E キー）は原因を特定できなかったため、ゲームの動作は据え置き、テストに入力の記録を追加しました。
