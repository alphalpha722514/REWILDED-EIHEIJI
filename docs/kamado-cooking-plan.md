## 2. 実装（v0.66・v0.66.1）
名前・数値はすべて**暫定**です（料理の名前と効果は Claude の案）。

### 食材
| 食材 | 入手 | もつ時間（手持ち） | 生で食べる |
|---|---|---|---|
| 肉 | 獣を倒す（クマ2・ほか1。これまでの食料のかわり） | 15分 | 食べられない |
| 野菜 | 菜園の大根（3）、町の畑（これまでの食料のかわり） | 25分 | かじれる（満腹+15） |
| 米 | 菜園の稲（4＋藁4） | 50分 | 食べられない |
| 食料 | 依頼の報酬・防衛戦の報酬など（これまでどおり） | 20分 | かじれる（満腹+15） |

- 食料庫・鮮度・傷みの仕組みは、新しい食材と料理にもそのまま働く。
- **「食料」が要る所は、肉・野菜・米でも足りる**（食料から先に使う）：誘い餌（食料2）、餌の付け直し（食料1）、町の畑の手入れ、最初の「木材4と食料2を集める」。
- 右上の欄に「肉・野菜・米」の数が出る（持っているとき）。

### かまど
- 作業台の「かまどを築く」（石4・木材4）。**最初から築ける。** 拠点の南東に建つ。
- 調べると選べる：
  - **料理する**：食材を1つずつ鍋に入れる（2〜3つ）。入れるたびに「できやすい料理」が出る（◎出やすい・○ときどき・△まれに）。「火にかける」で、薪に木材1を使い、45秒でできる。
  - **木炭を焼く**：木材3で30秒（変換炉の燃料）。
  - **取り出す**：できた料理は手持ちに入る（鮮度は取り出したときから）。
- 木炭と料理は、入れた順に1つずつ作る（最大6つまで待たせられる）。遊んでいる間だけ進む。
- **何の料理ができたかは、できるまで分からない**（火にかけたときに決まり、セーブしても変わらない）。

### 料理（9つ。固有のレシピはない）
| 料理 | 出やすい組み合わせ | 効果 | 由来 |
|---|---|---|---|
| おにぎり | 米だけ | 体力+35・満腹+25（今と同じ） | 今ある |
| 薬草粥 | 米多め＋野菜 | 30秒かけて体力40（今と同じ） | 今ある |
| 精進弁当 | 米と野菜を半々 | 体力+60・満腹+50・攻撃+30%（30秒）（今と同じ） | 今ある（永平寺の精進料理） |
| 焼き野菜 | 野菜2つ | 体力+15・満腹+40・移動+10%（30秒）（今と同じ） | 今ある |
| **胡麻豆腐** | 野菜3つ | 体力+20・満腹+30・移動+10%（30秒） | 永平寺の精進料理 |
| **里芋のころ煮** | 野菜3つ | 体力+30・満腹+55 | 奥越の里芋の煮ころがし |
| **串焼き** | 肉だけ | 体力+20・満腹+25（v0.66.1） | 獣の肉 |
| **ソースカツ丼** | 肉と米 | 体力+35・満腹+45・攻撃+30%（15秒）（v0.66.1） | 福井の名物 |
| **ぼたん鍋** | 肉と野菜 | 体力+25・満腹+45・30秒かけて体力40（v0.66.1） | 猪の肉の鍋 |

決まり方（`kamaOdds`）：
- 鍋の中身を「肉・野菜・米の割合」にし、料理ごとの割合に近いほど出やすい。
- 食料は、3つすべてに半分ずつ数える（＝何ができるか読みにくい）。
- 割合が0でない食材が鍋に全くない料理は出ない（肉を入れなければ、肉の料理は出ない。食料は肉のかわりになる）。
- 食材3つのときは手の込んだ料理、2つのときは簡単な料理が出やすい。

出やすさの例（測った値）：

| 鍋 | できる料理 |
|---|---|
| 米2 | おにぎり 100% |
| 肉1・米1 | ソースカツ丼 90%、おにぎり 5%、串焼き 5% |
| 肉1・野菜1 | ぼたん鍋 89%、焼き野菜 5%、串焼き 5% |
| 野菜3 | 胡麻豆腐 42%、里芋のころ煮 42%、焼き野菜 16% |
| 野菜2 | 焼き野菜 60%、胡麻豆腐 20%、里芋のころ煮 20% |
| 肉2 | 串焼き 100% |
| 米2・野菜1 | 薬草粥 55%、精進弁当 40%、おにぎり 4% |
| 食料2 | 精進弁当・ソースカツ丼・ぼたん鍋 各27%、薬草粥 10% ほか |

### 作業台
- おにぎり・精進弁当・焼き野菜・薬草粥は、作業台に出なくなった。
- **慧心に頼む料理（v0.66.1）：** 必ず精進料理を作ってくれる。かまどと違い、料理を選べて、すぐできる。肉は使わない。
  - 頼める料理：おにぎり（精進の食材2）・焼き野菜（2＋藁1）・薬草粥（1＋藁1・縄1）・胡麻豆腐（2＋藁1）・里芋のころ煮（3）・精進弁当（3＋獣素材1）。
  - 「精進の食材」は食料・野菜・米のどれでもよい（食料→野菜→米の順に使う）。数は暫定。
- **肉の料理の強さ（v0.66.1）：** 肉の料理は、精進弁当（体力+60・攻撃+30% 30秒）より弱くした。肉は獣を倒すと手に入りやすいので、強すぎると狩りばかりが得になるため。精進料理（慧心・かまど）が一番役に立つ形。

### 手持ちバー・持ち物
- 新しい料理・焼き野菜・薬草粥・野菜は、持っているときだけ手持ちバーに出る（おにぎり・精進弁当・食料はこれまでどおり常に枠がある）。
- 持ち物に、肉・野菜・米の数と、料理ごとの「食べる」が出る。
- あわせて、v0.63〜v0.64 の鱗の武器が手持ちバー・持ち物に出ていなかったのを直した。

## 3. 決めてほしいこと・気になる点
1. **序盤：** これまでは作業台で食料2からすぐおにぎりを作れた。今は慧心（段階C 以降）に頼むか、かまどで45秒待つ。試遊で厳しければ、かまどの素材や時間を軽くする。
2. **料理の名前と効果：** 上の表は案。変えたい料理・足したい料理（例：おろしそば、油揚げ、へしこ）があれば。
3. **数値：** 料理45秒・木炭30秒・食材のもつ時間・出やすさは試遊で調整する。

## 4. セーブ（`docs/save-and-flags.md`）
- `kama` の形を変えた：`q` は作業の並び（`'charcoal'` か料理の名前）、`out` はできた物ごとの数。v0.64 の形（数だけ）も読む。
- 新しい食べ物（肉・野菜・米・新しい料理5つ）は、`inv` と鮮度の表（`f7`）に新しいキーで足した。旧セーブは0で読む。
- 保存キー・`v:1` は変えていない。
