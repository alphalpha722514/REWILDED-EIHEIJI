# かまどの料理と食材の種類 — 現状と案（2026-11-13）

## 1. ユーザー決定（2026-11-13）
- 名前は「**かまど**」。
- いまは「食料」というアイテムしかない。**肉・野菜・米など、種類を少し増やす。**
- かまどで、**今の作業台の料理**と、**新しく考えた料理**を作れるようにする。

以下の「案」は未承認です。コードはまだ変えていません。

## 2. いまのコード（v0.65）
| もの | いまの作り | 場所 |
|---|---|---|
| 食べ物の種類 | 食料・おにぎり・精進弁当・焼き野菜・薬草粥の5つ。種類ごとに「もつ時間」があり、古い順に傷む。食料庫に入れると長もちする | `FOODS`・`foodAdd` |
| 食料の入手 | 獣を倒す（クマ2・ほか1）、菜園の大根（3）と稲（4＋藁4）、採集、依頼の報酬 | `killEnemy`・`f8`・`g4` |
| 作業台の料理 | おにぎり（食料2）、精進弁当（食料3・獣素材1）、焼き野菜（食料2・藁1）、薬草粥（食料1・藁1・縄1） | `RECIPES` |
| 料理の効果 | 体力・満腹の回復、精進弁当は攻撃+30%（30秒）、焼き野菜は移動+10%（30秒）、薬草粥は30秒かけて体力40 | `eat` |
| かまど | 木材を焼いて木炭を作るだけ。変異した鱗などを持っていないと作業台に出ない | `FAC.kama` |

- 食料は、入手元が違っても同じ1つのアイテムです（獣の肉も大根も米も「食料」）。
- 食料を材料や報酬に使う所が多いので、食料そのものを無くすと影響が広いです。

## 3. 案
### 食材（3種類を足す）
| 食材 | 入手 | 備考 |
|---|---|---|
| 肉 | 獣を倒す（今の食料のかわり） | 傷みやすい |
| 野菜 | 菜園の大根、採集 | ふつう |
| 米 | 菜園の稲 | 長もちする |

- **今の「食料」は残す（推奨）。** 旧セーブの食料・依頼の報酬・村人とのやり取りはそのまま動く。食料は「どの食材のかわりにもなる」扱いにする。
- 別の道：食料を無くして3種類に分ける。旧セーブの食料をどれかに変える必要があり、食料を使う所をすべて直す。

### 料理（かまどで作る。燃料は木材）
| 料理 | 材料（案） | 効果 |
|---|---|---|
| おにぎり（今ある） | 米2 | 今と同じ |
| 精進弁当（今ある） | 米1・野菜2・獣素材1 | 今と同じ |
| 焼き野菜（今ある） | 野菜2 | 今と同じ |
| 薬草粥（今ある） | 米1・縄1 | 今と同じ |
| 新しい料理 | 肉を使うもの（例：焼いた肉、肉と野菜の鍋） | 名前と効果を決めてほしい |

- 今の料理の材料は、食料のままでも作れるようにする（食料がかわりになる）。
- 藁を燃料にしていた料理は、かまどでは木材を燃料にする。

## 4. 決めてほしいこと
1. **食料の扱い：** 残して「どの食材のかわりにもなる」にするか（推奨）、無くして分けるか。
2. **新しい料理：** 名前・材料・効果。いくつ足すか。精進料理という設定（精進弁当）と、肉の料理の兼ね合い。
3. **作業台の料理：** かまどができたあとも作業台で作れるままにするか、かまどだけにするか。
4. **かまどを築ける時期：** 今は変異した鱗などを持っていないと作業台に出ない。料理に使うなら、最初から築けるようにするか、どこかの進行で解放するか。
5. **調理の時間：** 木炭や鱗と同じく時間をかけるか、作業台と同じくすぐできるか。
6. **食材の見た目：** 落とし物・持ち物の欄・手持ちバーの絵（肉・野菜・米）。

## 5. 依存
| かかわる仕組み | 内容 |
|---|---|
| 食べ物の鮮度・食料庫 | 種類ごとの「もつ時間」と古い順の管理は、種類を足せばそのまま使える（`FOODS` に行を足す） |
| 手持ちバー・食べる操作 | 料理が増えると、バーに置く物が増える |
| 菜園・採集・獣の落とし物・依頼の報酬 | 何を出すかを変える |
| セーブ | 新しい食材は既定値つきの新しいキーで足せる。保存キー・`v:1` は変えない |
| 防衛戦の測定 | 食べ物の数を決めて測っている。食材を変えたら基準を取り直す |

## 6. 推奨する順序
1. 上の質問を決める。
2. 食材3種類を足す（入手と表示）。食料はかわりに使える。
3. かまどに料理の一覧を足す（今の料理＋新しい料理）。
4. 試遊して、材料の数・効果・時間を調整する。
