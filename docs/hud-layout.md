# 画面の配置：手持ちバー（持ち物欄）と操作表（v0.76.1）

2026-11-17 ユーザー指示：「スマホ版でプレイするときに持ち物欄が上部に来てしまうことと、パソコン版でプレイするとき持ち物欄に操作表が重なるのを修正してください」。

## 直す前（v0.76）

- スマホ：手持ちバー（10枠）が画面の上（横向きは上から 48px、縦向きは 172px）。v0.45 では下だったが、のちのレイアウトの調整（`fb8ef8c` の取り込みに含まれる）で上へ移っていた。
- PC：操作表（左下・幅 約670px・5行）が手持ちバー（下の真ん中・幅 594px）に重なる。1024〜1920px のどの幅でも重なっていた（1920px でも 18px 重なる）。
- iPad 縦：手持ちバーが強攻撃・持ち替えのボタンに重なっていた。

## 直したあと

`index.html` の `<style>` の最後の「v0.76.1」の規則（前の規則を上書き）と、`hbBuild()` の指の扱い。

| 画面 | 手持ちバー | 操作表など |
|---|---|---|
| PC 1162px 以上 | 下の真ん中（今までどおり） | 左下のまま。幅を手持ちバーの左までにして折り返す（キーと説明の組は分けない）。右下の通知も手持ちバーの右の幅で折り返す |
| PC 761〜1161px | 下の真ん中 | 手持ちバーの左に入らないので、左上（体力の下・防衛の耐久の帯より下）へ。字を少し小さく（11px） |
| スマホ 横向き | **下**。右下の戦いのボタン（強攻撃）の左の空いた所の真ん中。1枠 40px | 戦いのボタン・地図・止める・調べる帯は今までの場所 |
| スマホ 縦向き | **下いっぱい**。1枠 約33px | 戦いのボタン・地図・止める・調べる帯をその分 50px 上へ |
| タブレット | 下。右下のボタンの左の空いた所の真ん中（縦向きでボタンに重ならない） | 今までどおり |

- **指で手持ちの枠を押したとき**：今までは触れた瞬間に選んでいた（食べる・持ち替える）。手持ちバーが画面の下（スティックを動かす親指の近く）に来たので、**触れて、動かさずに離したとき**に選ぶようにした。触れたまま 14px 以上動かすと選ばない。マウスは今までどおり押した瞬間。
- 操作表の中身（文）は変えていない。キーと説明の組（「R 持ち替え」など）が行の途中で分かれないよう、組ごとに折り返さない印を付けた。

## 確認

`python3 tests/hud-layout-browser.py`（画面のない Chromium。`HUD_SHOTS=フォルダ` で大きさごとの画面）：

- PC 9種類（780×560〜1920×1080）：手持ちバーは下・操作表が手持ちバー・調べる帯・強敵の体力・通知・体力・防衛の耐久・素材・地図に重ならない・画面の中。
- スマホ・タブレット 7種類（iPhone 13／SE／Pro Max の横・縦、iPad の横・縦）：手持ちバーは下・画面からはみ出さない・ボタン・調べる帯・強敵の体力・通知に重ならない・調べる帯がボタンに重ならない・1枠が指で押せる大きさ（33px 以上）。
- 指で枠に触れて動かすと選ばない・動かさずに離すと選ぶ（10番目の枠＝持ち物で確かめる）。

いちばん混む形（調べる帯の長い文・持ち替えと衝撃波のボタン・強敵の体力・防衛の耐久・通知を全部出す）で比べている。

**PC・iPhone の実機では未確認。** 特に iPhone の横向きで、スティックを動かす親指が手持ちバーに当たらないか（当たっても選ばないようにはした）、ホームバー・切り欠き（safe area）の分の余白が足りているかを確かめてほしい。
