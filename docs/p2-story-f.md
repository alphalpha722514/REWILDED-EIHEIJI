## 3. 流れと仕組み

| 段階（`stfStage()`） | 条件 | 起きること |
|---|---|---|
| `radio` | 防衛戦の勝利で `radioHeard:false` が付く | 勝利の会話と報酬の表示（`bannerT`）が終わり、3秒たつと自動で無線（`STF_CFG.radioDelay`、暫定）。暗転 → 主人公は無線室の前・トミオ／慧心／源さんが集まる → 無線（草案3行）→ `radioHeard=true`・保存 → そのまま相談 |
| `decide` | 無線を聞いた | 相談（草案12行）→ `departureDecision=true`・保存 → 暗転して町民は元の場所へ。目標「上志比へ続く道で故障した軽トラックを探そう」 |
| `truck` | 相談した・直していない／燃料がない | 国道416号の東の出口の手前（x=560）に壊れた KEI truck（さび・開いたボンネット・前のパンク）。調べる → 発見（草案1行）と要る物。部品2つ（資材倉庫の前・国道416号の脇）と燃料（資材倉庫の前）は光明寺で拾う。直す（素材＋部品）→ 燃料を入れる |
| `sendoff` | 直して燃料も入れた | 直した報告（草案3行）と見送り（草案4行）を車のそばで → `departureComplete=true`・保存 → KEI truck に乗った状態に |
| `away` | 見送りが済んだ | 運転して東の出口へ → 上志比の西端に車ごと着く（`truck.trips` が増える）。以後は歩いても行ける（2026-11-17 ユーザー許可） |
| `open` | 作業F の記録が無い（v0.76 以前の流れ・試験の開放） | 今までどおり（無線も車も出ない） |

上志比側（`stfMeetStage()`）：見送りを終えたか旧セーブの移動権があり、スズキが仲間でなければ `meet`。

1. 山王の駅から 34m 以内に入ると（`STF_CFG.meetR`、暫定。104m で変異したサルの形を先に読む）、短いカット（約5〜7秒、黒い帯、操作は止める、台詞なし）：スズキが変異したサルに追われて走ってきて、主人公の近くで止まる。山王から 60m（`clearR`）の獣は止めて遠ざける（町の群れ・要塞の守りも乱入しない）。
2. 戦い：サルは主人公と戦う（`spawnMutant(…,{fleeOnly:true})`。傷230で逃げ去る・倒せない・鱗1枚は既存のまま）。スズキは主人公から約13m（`watchR`）・サルから10m以上の、歩けて画面に映る所へ退き、見守る（たたかれてもよろけるだけ）。
3. サルが逃げ去ると、2.2秒後にスズキが近づき、二人を横から映して会話（確定3行＋草案7行）。
4. 会話を終えたとき、`mutantMet=true` と `szJoin()`（`suzuki.joined=true`、ついて来る）を**同時に**付けて保存。「スズキが仲間になった」。止めた獣は動き出し、以後は上志比の群れに変異したサルが加わる（`kamiMutantOK()`、v0.67）。

仲間になったあとの戦闘開始の掛け声（v0.77、2026-11-17 ユーザー許可）：スズキが戦いに入ったとき（`SZ.fight` が偽 → 真。戦いの終わりはまわり15m に敵がいない状態が8秒、v0.71 のまま）、頭の上の吹き出しで「Reddishにしてやろうかああぁぁあ！？」（確定台詞。`SZ_CRY`）。前に言ってから20秒（暫定）は言わない。山王の初遭遇の戦いでは言わない。動き・強さは変えない。

途中でやめたとき（`stfAbort()`）：カットや戦いの途中で倒れる・地域を移る・タイトルへ戻ると、サルを消し、スズキを隠し、止めた獣を戻し、記録はそのまま（初遭遇の前）。倒れたら既存どおり上志比の西端で起き、山王へ戻るとカットからやり直す。**初遭遇の途中は保存しない**（`stfNoSave()`）ので、鱗を拾ってから倒れても、つづきからは拾う前に戻る（鱗が二重に手に入らない）。

## 4. セーブ（`chapter2.progress` に足したキー。`SAVE_KEY`・`v:1`・既存キーは不変）

| キー | 値 | 意味 |
|---|---|---|
| `radioHeard` | `false`／`true`／無し | 無線を聞いた。防衛戦の勝利で `false` が付く。**無し＝作業F の記録が無い**（v0.76 以前） |
| `departureDecision` | 真偽 | 出発の相談をした |
| `truck` | `{found,repaired,fueled,fuel,parts:[…],trips,region,x,z,a}` | KEI truck：見つけた・直した・燃料を入れた・持っている燃料・拾った部品（`p1`・`p2`）・上志比へ運転して行った回数・置いてある地域と場所と向き |
| `departureComplete` | 真偽 | 見送りが済んだ（このあと KEI truck で上志比へ行ける） |
| `mutantMet` | 真偽 | 初遭遇を終えた（v0.67 で予約していたキー）。会話を終えて仲間になったときに付く |
| `legacyKamishihiAccess` | `true`／無し | 旧セーブの移動権（下記） |

- 仲間かどうかは既存の `suzuki.joined` だけ（新しいキーは作らない）。仲間なのに `mutantMet` が無い保存（試遊版のボタンなど）は、読み込み後にそろえる。
- **旧セーブ**（防衛戦は済み・`radioHeard` が無い）：読み込むと `radioHeard:false, departureDecision:false, departureComplete:false, legacyKamishihiAccess:true`。歩いて上志比へ行ける権利はそのまま、光明寺にいれば無線が1回鳴る（相談・KEI truck は遊べるが、しなくても移動できる）。山王の初遭遇も起きる。新しく始めた保存には付かない。
- 初遭遇の途中・カットの途中は保存しない。KEI truck は運転している間も場所を記録し、つづきからは降りた状態で置いてある。

## 7. 【3Dモデル制作依頼】KEI truck

1. **対象名**：KEI truck（軽トラック）
2. **対応するフェーズ**：P2（作業F：初めて上志比へ向かう）。その後の地域の移動にも使う
3. **ゲーム内での役割**：光明寺から上志比へ続く道に止まっていた故障車。主人公が直して乗り、上志比へ移る。将来は荷台に物を積む・改造する（未実装）
4. **過去に確定している外観設定**：名前は「KEI truck」。日本の軽トラック。それ以外（色・年式・汚れ方）は**未確定**
5. **モデルに必要な構造**：車体1つ＋車輪4つ（別部品・回る）。運転席のドア2枚と荷台のあおり3枚（後ろ・左右）は別部品にしておくと後で開けられる。故障した姿（さび・パンク・開いたボンネット）はゲーム側で重ねるので、きれいな姿だけでよい。中の座席は簡単でよい（運転中は外から見るだけ）
6. **推奨ポーズ**：車輪をまっすぐ、ドア・あおりを閉じた姿。前が +Z、原点は4つの車輪の真ん中の地面
7. **必要なアニメーション**：無し（車輪の回転・向きはゲーム側で動かす）
8. **ポリゴン数の目安**：3,000〜5,000三角形（`docs/asset-registry.md` の目安）。テクスチャ 1024 四方1枚
9. **推奨ファイル形式**：GLB（メートル、+Y が上）
10. **ChatGPT への画像生成上の要望**：横・斜め前・後ろが分かる3面。全長約3.4m・幅約1.48m・高さ約1.8m の、平たい荷台の軽トラック。ゲームの画風（少しデフォルメ・輪郭線）に合わせ、細かい文字・ナンバー・実在のメーカーの印は入れない
11. **モデルが必要になる実装段階**：作業F を main に入れるとき（仮車体のままでも遊べる）
12. **仮モデルによる開発継続の可否**：可（今はコードの仮車体 `truckModel()`。差し替えは形を読み込む所だけ）
