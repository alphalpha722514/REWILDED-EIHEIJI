# 倒れたときの代償 — v0.56（2026-11-12 承認）

## 理由
v0.55 までは、倒れて「拠点で立て直す」と体力が全回復し、満腹は60まで上がり、傷んだ・壊れた柵が無料で半分まで直り、野の獣は傷を負ったままだった。そのため「倒れながら削る（ゾンビ特攻）」ができ、倒れるほうが得になる場面もあった（ユーザー指摘 2026-11-11）。

## 採用した内容（案 A＋B＋C）

| 案 | 内容 |
|---|---|
| A | 野の獣（`mode==='field'`）は元の場所に戻り、体力も全回復する |
| B | 拠点で目覚めたときの体力は最大の半分。満腹は25減る（下限15）。柵の無料修理はやめた（壊れた柵・傷んだ柵はそのまま） |
| C | 手に持っていた武器の耐久が、最大耐久の25％減る（下限0。0になると刃こぼれで威力40％、壊れて消えはしない） |

- 素材・防具・設置した柵や罠は失わない。防具には耐久の仕組みがないため、C は武器だけ。
- 進行中の戦い（襲撃・大規模侵攻・ヌシ戦・第2章防衛戦）は、これまでどおり準備段階からやり直し。
- 倒れた画面の説明文と、立て直したときの通知を変えた。
- コード：`retryFromBase()`。テスト：`tests/death-penalty.cjs`。

## 未確認・今後

- 落とし物（案D）・時間経過（案E）は不採用（今後の検討候補）。
