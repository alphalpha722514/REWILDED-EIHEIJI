## 2. 指示書・コードとの食い違い・足りない情報（変えずに報告）

1. **建物の用途が地図に無い**：OSM の建物には種類（住宅・倉庫・店など）の情報が入っていない（位置・大きさ・向き・面積・集落かどうかだけ）。用途は、大きさ・形・道との位置・田畑との近さから**推定するしかない**（P3-A の8軒は Claude が選んだ）。
2. **どの建物の中に入れるか**が指示書に無い（「重要建物」とだけ）。§27-5「建物内部の具体的なレイアウト」は未承認の項目。→ 決めてほしいこと 2。
3. **森林の種類の分布**の資料が手元に無い（環境省の植生図などは、この作業環境からは取りに行けない）。→ 地形と土地の使われ方から決める案（決めてほしいこと 3）。
4. **復興による景観変化の中身**が指示書に無い。→ 案（決めてほしいこと 6）。
5. **希少素材**（§18.3）が何かが無い。新しい素材はゲームの決まりに関わる。→ 決めてほしいこと 5。
6. **高品質版・軽量版**（§20.4）：今は「高画質の影」の切り替えだけ。描く距離や細かさを変える設定は無い。→ 決めてほしいこと 7。
7. 廃工場・倉庫群（双子猿のボス区域）は P4。P3-E では手を付けない（§1「P3に含めないもの」）。

## 3. 進め方（案）

4つに分けて、1つずつ作業ブランチで作り、改善前後を**同じカメラ位置**で比べて報告する（§20.3）。

| 段階 | 中身（案） |
|---|---|
| **E-1 町並み** | 833軒の用途を推定（住宅・農家・農業倉庫・車庫・商店・公共施設・作業小屋）。**近く（約120m）の家だけ** P3-A の細かい家の作りで建てる（区画ごとに作る・捨てる。D-3 の河原と同じ）。遠くは今の形。道に沿って電柱・電線・側溝・カーブミラー・標識、家に庭木・駐車スペース・自転車・農機具。荒廃（伸びた草・放置物・荒れた田畑・獣の痕跡）は場所ごとに決まった形で |
| **E-2 森林** | 森の区画を杉林・広葉樹林・竹林に分ける。近くの木は P3-A の試作の作り（枝・樹冠・下草・落ち葉・岩・倒木・切り株・木漏れ日・揺れ）、遠くは軽い形。**広葉樹は全域で切れる**（山地の硬木。C-4 の「足りなくなったら P3-E で増やす」）。森の音（木々のざわめき・竹のきしみ・森の鳥） |
| **E-3 家屋探索** | 重要建物の屋内を **3つ**足す（今の屋内の仕組みを使う）。探索地点を足す：獣道・隠れた林道・廃屋（外から探る）・獣の足跡（光明寺の仕組みを上志比へ）・鳴き声 |
| **E-4 復興の景観** | 復興 Lv ごとに、本部のまわりの景色を変える（がれきが片付く・家が直る・明かり・人の気配） |

- 性能：区画ごとに作る・近くだけ細かい・遠くは今の形。iPhone の重さは実機で見てもらうしかない（画面のない Chromium の数で目安を出す）。
- セーブ：新しいキーは作らない予定（切った木・探索の記録は今の `kami`・`p3c` の形に足す）。古いセーブはそのまま読める。

## 4. 決めてほしいこと（返事が来るまで案で進める）

1. **進め方**：E-1→E-2→E-3→E-4 の順で、1つずつ報告してよいか（案）。
2. **中に入れる重要建物**（3つ）：案は
   - (a) **古い農家の母屋**（土間・囲炉裏・座敷・蔵。生活用品・農具・古い地図）
   - (b) **商店（よろず屋）**（棚・倉庫。保存食・道具）
   - (c) **集会所**（避難所だった跡。掲示板の書き置き・救急箱の中身・避難者の記録）
   - 候補：(d) 山王駅の待合室・(e) 小さな寺の本堂（光明寺とは別）
3. **森林の種類の分け方**：案は、地形と土地の使われ方で決める。杉林＝山の斜面の大半、広葉樹林＝尾根・南向きの斜面・山すその林道ぞい、竹林＝集落のまわり・川ぞいの段丘。割合の目安は杉 約6割・広葉樹 約3割・竹 約1割（暫定）。
4. **広葉樹の伐採**：全域の広葉樹を切れるようにして、山地の硬木を取れる所を増やす（案）。切った木は戻らない（P3-A の案のまま）か、長い時間で戻すか。
5. **希少素材**：案は「**山の薬草**」（森の奥の木陰。救急箱・薬草粥に使える）を1つだけ足す。増やしたくなければ、希少素材は「多めに取れる既存の素材」（硬木・竹など）にする。
6. **復興による景観変化**：案は
   - Lv1：本部のまわりのがれきが片付く・本部の窓に明かり
   - Lv2：近くの家が3軒直る（屋根・窓）・洗濯物・畑が耕される
   - Lv3：通りの道のがれきが消える・電灯がつく・住民が通りを歩く
7. **画質の設定**：§20.4 の「高品質版・軽量版」として、設定に「描く細かさ：標準／軽量」を足す（軽量では近くを細かく描く距離を短く・木の数を減らす）。足してよいか。
