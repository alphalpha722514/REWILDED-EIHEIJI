## 2. 調べる所ごとの案

共通の案：
- 近づくと案内の帯に「〇〇を調べる」が出る（光る印は付けない＝E3-1 の決定どおり）。`E`／タップで調べる。
- 物が見つかったら `sfx('pickup')` と短い文（トースト）。物が無い所は短い地の文だけ。
- 調べた後にもう一度近づくと「〇〇を見る」になり、短い文だけ出る（物は出ない）。これは Q1 で a を選んだ場合。
- 数は**暫定**。家1軒の合計は、木炭3・米2・縄2〜3・屑鉄3・食料1・古い機械部品1（12〜13個）と、古い地図。これは既存の「物置」の依頼1件（木材8・屑鉄3・古い機械部品1、報告で縄4・藁6）より少ない。
- 文は**案**。物語の時期（避難から何日たったか）が決まっていないので、食べ物の傷み具合・人がいた気配には触れない書き方にしてある。

生活感についての考え：
- 8か所はどれも E3-1 で置いた家具そのもので、報酬のために家具を足すことはしない。
- 見つかる物も、その家具に普通に入っている物にした（かまどの炭・米びつの米・農具の縄・炭入れ・茶箪笥の乾物・蔵の古い紙）。
- 仏壇からは物を取らない案にした（北陸の家では仏壇を大事にすることが多い）。
- 古い書類は、蔵か仏壇の引き出しにしまうのが自然。仏壇から物を取らないので、蔵を第一の案にした。
- 土間の俵・臼・唐箕は8か所に入っていないので、今回は調べられないままにする（足すなら別の承認）。

## 3. 古い地図の使い道の比べ方

ほかの7か所は既存の物だけで足りる。新しく要るのは古い地図だけ。

| 案 | 地図を拾うと何が起きるか | 今すぐ作れるか | 良い所 | 気になる所 | 実装の重さ |
|---|---|---|---|---|---|
| **A 段階式（すすめる案）** | 会話欄で地図を読む。上志比の地図（`G`）に「古い地図」の層が足され、まず次の2つを描く：(1) 商店（house110）と集会所（#16）の位置。(2) 山の薬草が生えやすい所（今ある `h` 地点のあたりを丸で）。獣道・隠れた林道は、E3-5 で作ったときにこの層へ足す | (1)(2) は作れる（`p3dScoutPts()` の前例） | 次の工程（E3-3 の2軒）への道しるべになる。屋外の探索（E3-5）とも後でつながる。拾った物が「使える」 | 商店と集会所の中は E3-3 まで入れない（地図の印で「入れない家」に行かせてしまう。印の書き方の工夫が要る） | 中 |
| B 屋外の探索地点を出す | 獣道・隠れた林道・薬草を地図に出す（E-3 の最初の案、Q6 の a） | 獣道・隠れた林道はまだ無い。**E3-5 と同時でないと作れない** | 探索の手応えが一番大きい | E3-2 が E3-5 を待つことになる | 大 |
| C 読むだけ | 会話欄で読む。地図には何も足さない | 作れる | 一番軽く、物語の設定を増やさない | 拾ってもゲームが変わらない。せっかくの締めくくりの報酬が弱い | 小 |
| D 依頼につなぐ | 地図を拾うと、復興依頼が1件増える（例：昔の水路を確かめる） | 依頼の仕組み（`p3c.req`）はある | 復興とつながる | 依頼の中身と報酬が新しい仕様になる（Q11 の b） | 中〜大 |
| E 地図の上に昔の地名・水路を描くだけ | 地図の画面に、昔の田の区切りや用水路の線を重ねる（見た目だけ） | 作れる（D-3 の支流・水路のデータがある） | 福井の農村らしさが出る | 遊びの上の意味は弱い。昔の地名は実在の資料に当たる必要がある | 中 |

- 持ち方の案：古い地図は持ち物の数（`inv`）に入れず、`p3.e3` の中の「持っている」の印にする。
  - こうすると、持ち物の画面・重さ・絵の仕組みに手を入れずに済む。
  - 読むのは地図の画面の「古い地図」の層と、会話欄。読み直すのは、地図の画面の層の切り替えで行う。
  - 持ち物の画面に出したい場合は、手持ちの枠に新しく登録する作業が要る（§4 の Q5）。

## 5. 承認後の実装の進め方（案）

1. **E3-2a 調べる所と見つかる物**：農家の `marks` に8か所を足す。中身は §2 と Q1〜Q3・Q6〜Q9 の答え。保存は Q10 の答え。
   - 変えるファイル：`index.html`・新しいテスト `tests/p3e3-search-browser.py`・`docs/p3e-e3.md`。
2. **E3-2b 古い地図**：Q4・Q5 の答え。地図の画面の層は `p3dScoutPts()` の形で作る。
3. **確かめ方**
   - PC（自動）：8か所を調べる・1回だけ・2回目の文・持ち物の数・古い地図の層・セーブと読み込み・古いセーブ・v0.90 で保存し直したとき・三角形の数・ページのエラー。
   - iPhone の大きさ（390×844 のタップ）：案内の帯と `#tbAct`、会話欄を進める操作。
   - 本部・整備工場跡・E3-1 の農家のテスト（`p3e3-farm-browser.py`）が今のまま通ること。
   - iPhone の実機の試遊：古い農家の試遊版を作り直してから（`tools/build-p3e3-farm-preview.py`）。
4. **Codex**：実装は1つの作業に4回まで（目安は E3-2a で2〜3回、E3-2b で1〜2回）。Claude Code は差分を読み、ブラウザーで確かめ、セーブを行き来させて確かめる。
5. まだ決まっていない仕様は、Codex に推測で作らせない。
