## 4. 4地点の試作（STEP 2）

試作はすべて `P3A` の印の付いた1か所のまとまり（`index.html` 10084〜10470 付近）。**上志比全域には広げていない。** `P3A.on=false` にすると main と同じ見た目に戻る。

### A：拠点本部（`p3aBuildHQ`）
- 外観：2階建て（1階4.4m・2階3.4m）の波板の壁、窓の列（割れた窓あり）、錆の筋、低い切妻の金属屋根（穴があき、梁が見える）、樋、つた。
- 北の端：シャッター2枚（1枚は半開き＝入口）・勝手口と庇・文字の無い看板。西の面に鉄の外階段。
- 前庭：ひびの入ったコンクリートの土間、パレット、ドラム缶、置き去りの軽トラック（コードの形）、タイヤ。
- **入口の切り替え：** 半開きのシャッターの前で「拠点本部の候補：中へ入る（試作）」。暗転して屋内の場へ移る。

### 屋内の試案（`p3aInteriorBuild`・`p3aEnter`・`p3aExit`）
- 地図の外（x=21000・z=21000）に別の場を作り、入るときだけ見せる。上志比の景色は隠し、当たり判定は屋内の分だけ有効にする。
- 1階（36m×18m）：入口ホール・倉庫（鉄の棚・崩れた箱）・総合作業場（作業台・旋盤・溶接機・工具の壁）・廊下・機械室（配電盤・発電機）・事務所跡・階段室。
- 2階（試作では横に並べた別の場。階段で移る）：廊下・共同住居1・2（布団）・拠点管理・**板で閉じた部屋2つ（復興で開く）**。
- 調べる所（光る印）：倉庫の棚・作業場の工具（どちらも「P3-B で会話につなぐ」と出るだけ）・2階へ・1階へ・外へ出る。
- カメラは屋内では高めから見下ろす（壁を切った模型のように見せる）。
- **部屋の並びは案。** 指示書 §27-5 のとおり確定しない。

### B：周辺住宅（`p3aHouse`・`p3aBuildHouses`）
- 本部の南の通り（道551）沿いの8棟だけ、種類を分けて作り直した：農家（2階建て・平屋）・現代の家2種・農業倉庫（納屋）・車庫・物置・店。
  - 農家：白壁・柱・腰板・黒い瓦・引き戸の玄関と庇・閉まったままの雨戸・2階建ては低い下屋の上に2階の壁と**束と貫の格子の妻壁**（福井県「ふくいの伝統的民家」の永平寺町の農家の説明に寄せた）。庭に松・灯油タンク・耕運機・稲架。
  - 現代の家：サイディング・寄棟の金属屋根・雪止め・ベランダ・玄関ポーチ・室外機。カーポートに置き去りの車、倒れた自転車、ブロック塀。
  - 農業倉庫：金属の納屋、半開きの引き戸、トラクター、コンテナ。店：ガラスの正面・日よけ・文字の無い看板・自販機。
- 通りに側溝と格子のふた、電柱（32mごと。腕木・変圧器）とたるんだ電線、カーブミラー、止まれの標識。
- **屋内探索へ広げる準備：** どの家も玄関の位置を `P3A.doors`（`future:true`）に登録してある。P3-B で建物ごとの屋内を足せば、入口はそのまま使える。
- 注意：この8棟は main では「伝統」などの見た目だった。試作では種類を混ぜたので、通りの印象が変わる（§5 の B の比較）。どの種類をどれだけ混ぜるかは決めてほしい（§13）。

### C：九頭竜川・河原（`p3aRiverWater`・`p3aBuildRiver`）
- 範囲：x 6420〜6640・z 300〜540（南岸の約220m）だけ。
- 水面：岸からの距離で深さを決め、浅い所は黄緑で透け、深い所は青緑で濃い。流れの向き（西）に動く波、浅い所に白波。
- 川底：岸の近くは砂と礫、真ん中ほど深く暗い坂の底を水の下に足した。水の中の石も見える。
- 河原：水際から礫の帯と小石、岩（十二面体を重ねた形・苔）、流木、ヨシと草、ヤナギ。
- 護岸：国道側の土手にコンクリートのブロックの斜面。
- 釣り場：水際の平らな岩と目印の杭を3か所（`P3A.fishSpots`。P3-D の釣りで使う想定。今は飾り）。
- 川の音：河原に近いほど流れの音が大きくなる（環境音に重ねる）。

### D：林道・森林（`p3aTreeGeo`・`p3aBuildForest`・`p3aPaintGround`）
- 範囲：山すその林道（道182）のまわり半径62mだけ。
- 木：杉（幹＋円錐の段4つ）・広葉樹（コナラなど。二股の幹＋丸い葉のかたまり7つ）・竹（細い稈11本＋葉）。林道の片側を広葉樹と杉、反対を竹と杉に分けた（前の計測で杉299・広葉樹33・竹91本）。
- 林床：地面の絵に落ち葉（杉の赤茶・広葉樹の黄茶・竹の枯れ葉）を塗る。岩（苔つき）・倒木（苔つき）・切り株・シダ。
- 獣道：林道から斜面へ踏み跡の筋と足跡のくぼみ。木漏れ日（淡い光のまだら）。
- この範囲の main の木（伐採できる木）は消さずに隠しただけ（番号がずれないので、切った木の記録はそのまま使える）。**試作の木は今は切れない**（P3-B 以降で、伐採と素材をどうするか決める）。

## 7. 性能の比較（STEP 6）

画面のない Chromium（SwiftShader：GPU を使わず CPU で描く）・1280×720・同じカメラで、main（`40f989c`）→ 試作（`p3a-survey`）。描く回数と三角形は、その1枚を描いたときの `renderer.info`。ジオメトリとヒープは、上志比に入ってから A→B→B2→C→D の順に撮った**その時点までの合計**（後の地点ほど前の分を含む）。

| 地点 | 描く回数 | 三角形 | ジオメトリ（累計） | JS ヒープ MB（累計） | FPS（SwiftShader・参考外） |
|---|---|---|---|---|---|
| A | 148 → 159（+11） | 829,312 → 879,283（+6%） | 454 → 465 | 210.1 → 231.5 | 5.3 → 7.5 |
| B | 119 → 133（+14） | 802,216 → 897,053（+12%） | 498 → 515 | 210.5 → 217.8 | 1.3 → 2.2 |
| B2 | 148 → 156（+8） | 982,978 → 1,026,299（+4%） | 548 → 565 | 210.2 → 218.3 | 0.9 → 1.4 |
| C | 85 → 93（+8） | 695,674 → 748,442（+8%） | 557 → 576 | 212.5 → 220.6 | 0.9 → 1.3 |
| D | 132 → 142（+10） | 1,119,244 → 1,439,358（+29%） | 580 → 605 | 212.8 → 221.9 | 1.1 → 1.6 |

- 試作で増えたのは、描く回数 +8〜+14、三角形 +4〜+12%（林道だけ +29%：杉・広葉樹・竹・下草）、ヒープは最初の地点で約+21MB（試作の形・材質・地面の絵）、そのあと約+7〜9MB。
- **FPS は参考にならない**（CPU で描くので 1〜8。実機の GPU とは桁が違う）。
- **iPhone 実機では計測していない（未確認）。** PC の実機（GPU）でも計測していない。実機では F11 の計測（`btnPerf`）で同じ地点を見てほしい。
- 林道の三角形が多いのは、試作の木（約420本）を近くでだけ描く形にしていても、全部を1回で描いているため。全域に広げるなら、遠くは今の円錐の木に切り替える（LOD）必要がある。

### 8.1 今のゲームで集まる量（コードから）

| 縄 | 荒らされた田の藁8か所×3 → 作業台で藁3＝縄1 | 180秒 | 約6 |
