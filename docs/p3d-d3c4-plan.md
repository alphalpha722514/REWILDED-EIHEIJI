## 2. D-3：川の改修（§19）の進め方

P3-A の試作（承認済み）の作りを、**本流の全部と支流・水路**へ広げる。指示書 §20.5「全域展開の条件」（見た目・操作・永平寺町らしさ・性能）を同じカメラの比較と数で確かめる。

| 項目（§19） | 作り（案） |
|---|---|
| 水面（19.1） | 本流全部を P3-A の水面に（岸からの距離で浅瀬と深場・流れの向きに動く波・瀬の白波・透け方・照り返し）。区画ごとに分けて、見えない所は描かない |
| 川底・河原（19.2） | 川底は浅い所（岸から約10m）だけ作る（深い所は水が濃いので見えない）。礫の河原は地面の絵に塗る（遠く）＋近く（約150m）だけ小石・岩・流木・ヨシ・草・ヤナギを置く（区画ごとに、近づいたら作り、離れたら捨てる。同じ場所はいつも同じ形）。護岸は川に沿う道の土手のコンクリートブロック。橋脚は川の中の物を丸い水切りの形にし、まわりに白波 |
| 支流・水路 | 名前のある支流：流れる水面・川底の石・岸の草。名前の無い水路：コンクリートの U 字の水路（田んぼの用水路） |
| 環境音（19.3） | 川の流れ（いちばん近い水までの距離で大きさ。本流は大きく、支流・水路は小さく）・浅瀬の水音（瀬の近くで、ときどきちゃぷちゃぷ）・風（河原で少し強く）・鳥（昼。上志比と光明寺）・虫（夕方と夜は今のまま、昼は草の多い所で小さく） |
| 探索と生態系（19.4） | 川底の鉱石（浅瀬の黒っぽい石をつるはしで割る。C-4 の素材）・水の中を泳ぐ魚の影（近くの浅瀬）・**特別な観察地点**3か所（瀬のアユの群れ・中州のサギ・カワセミの止まり木。近づいて「観察する」→ 図鑑に「観察」のタブ）。釣り場・河原の採集・カニ・水生昆虫は D-1・D-2 のまま |

性能：本流の水の三角形は今も約6万（板1枚）。川底を浅い所だけにして、近くの物は区画ごとに出し入れする。改善前後を**同じカメラ位置**で、描画回数・三角形数・（画面のない Chromium の）フレームの時間を比べる。iPhone の実測は未確認のまま書く。

## 4. 指示書・コードとの食い違い（変えずに報告）

1. **高度加工の中身が無い**：§4 は「武器・防具の高度加工／車両の高度加工／建材・施設設備の高度加工」と名前だけ。§3 の④は Claude の案（決めてほしいこと 2）。
2. **山地の硬木の取れる所**：P3-A の案は「林道・山すその広葉樹」。広葉樹は林道の試作（33本）にしか無い。森を全域に広げるのは P3-E（§24）。
3. **特別な観察地点**（§19.4）：何を観察するかが書かれていない。§2 の3か所は案（決めてほしいこと 3）。
4. **施設設備の高度加工**：今は鋼材を作るところまで。鋼材を使う施設の強化（防衛設備など）は P3-F で使う形にする。

## 5. 決めてほしいこと（返事が来るまで案で進める）

1. **川を広げる範囲**：案は本流の全部＋名前のある支流6本＋水路20本。重ければ、本部のまわり（約1km）から段階的に広げる。
2. **高度加工の中身**（§3 の④）：案のままでよいか。足したい・減らしたいものがあれば。
3. **特別な観察地点**：瀬のアユの群れ・中州のサギ・カワセミの止まり木の3か所でよいか。
4. **加工機の主軸**：町の鉄工所の跡で見つける依頼（リオから）でよいか。
