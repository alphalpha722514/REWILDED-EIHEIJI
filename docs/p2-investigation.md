## 2. 地域切替に必要な改修箇所

`docs/phase-p2-status.md` 第6節の表のとおり。要点：

- **地図と範囲**：`MAPDATA`・`BOUNDS` を地域ごとにする。上志比のデータは別ファイルにし、上志比へ移るときだけ読む（指示書の第5章）。
- **作る・捨てる**：`buildWorld()` を「地域を作る」と「地域を捨てる（ジオメトリ・テクスチャ・当たり判定を解放）」に分ける。光明寺の拠点・柵・やぐら・村人は光明寺にいるときだけ。
- **当たり判定**：`circles`・`gridQuery` を地域ごとに作り直す。
- **採集・獣**：`NODES`・`SPAWNERS`・伐採 `f4`・探索 `f5` を地域ごとに持つ。**光明寺の今のセーブの中身はそのまま**、上志比の分は `chapter2` の中に新しく足す（キー名の変更なし・`v:1` のまま）。
- **地図画面**：`drawMap`・ミニマップを地域ごとに描く。
- **襲撃**：上志比にいる間は光明寺の襲撃を起こさない。防衛戦の最中は移動できない。
- **時間**：畑の成長 `f8Update(dt)` はデータだけで動くので、上志比にいる間もそのまま呼べる（3D の更新はいらない）。食料の傷み（`F7.spoil:true`）はすでにあるので、そのまま進む。新しい腐敗の仕組みは足さない。

## 3. 上志比の地理データの作り方

この作業環境から **実際に取得できること** を確かめた（2026-11-12）：

| データ | 取得元 | 結果 |
|---|---|---|
| 標高 5m・10m | 国土地理院 標高タイル（`dem5a`・`dem`） | 取得できた |
| 道路中心線 | 国土地理院 ベクトルタイル（`experimental_rdcl`） | 取得できた |
| 建物の外形・道路縁・水涯線 | 国土地理院 基盤地図情報タイル（`experimental_fgd`） | 取得できた（山王の1枚に建物42・道路縁50・水涯線42） |
| 建物・田畑（`landuse=farmland`）・道路・川・鉄道 | OpenStreetMap（API 0.6 の範囲取得） | 取得できた（山王の小さな範囲で建物151・田畑59） |
| OSM の一括取得窓口（Overpass） | — | つながらない |

方針：

1. 範囲：牧福島〜山王を主な経路、市荒川まで（町域の中心点：牧福島 36.0840,136.3849／山王 36.0798,136.3937／市荒川 36.0756,136.4201）。
2. 道路の**つながり**は国土地理院の道路中心線を基準にし、架空の道は作らない。建物・田畑は OSM と基盤地図情報を合わせる。
3. 取得したデータは出典・取得日・利用条件と一緒にリポジトリに保存し、作る道具（`tools/`）も入れる。光明寺の地図を作った道具は残っていないので作り直す。
4. 表示：タイトル画面の出典表示に国土地理院・OpenStreetMap（ODbL）を足す。OSM の API は少しずつ・回数を控えて使う（利用規約）。
5. **縮尺の問題**：光明寺から牧福島まで約3.4km、山王から市荒川まで約2.4km。0.8倍のままだと上志比は約2.7km×1.3km（光明寺の地図の約3倍の広さ）。案：
   - 案1：牧福島〜山王は0.8倍、山王〜市荒川の間の田畑と山道を詰めて、全体を光明寺の2倍程度にする（位置関係・道の順番は保つ）。
   - 案2：全体を0.5倍にする（形は正確だが、家や道が小さく感じる）。
   - 推奨は案1。データを取ってから、実際の歩く時間（例：牧福島→山王が徒歩で何分か）を出して提案し直す。

## 4. 防具の表示が出ない原因（特定済み）

- 今の体（`makeHumanClassic`）は、上着・ズボン・靴を**体と同じ1つの形の中に作り込んでいる**。
- `makeHuman()` はプレイヤー用に `m.layers={head:[],chest:[],legs:[],feet:[]}` を用意するが、**中に入れているのは頭のかぶり物だけ**。胸・脚・靴は空のまま。
- `f47ApplyVisual()` は `pm.layers[部位]` の中身の表示を切り替えるだけなので、空の部位は何も起きない。
- `f31ArmorVis`・`f31BuildArmor` は `f47ApplyVisual()` を呼ぶだけの名前の残り。`pm.anatomy48`・`underShirt48` は以前の体の名残（今の体では使われず、害はない）。
- **ついでに見つけた不具合**：基礎防具の頭「藁の笠」は、組の名前を `work` に読み替える処理のせいで、今の体では一度も表示されていなかった。
- 籠手（引き継ぎの `inv.armor`）の見た目も、今の体では出ていない。
