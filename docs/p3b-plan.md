## 2. 使える今の仕組み

- 時計：`prog.f10.tod`（1日1200秒・保存あり。物語の場面では止まる）。**2026-11-18 決定：1日を均等に24時間、1時間＝50秒、tod 0＝6:00**。時刻の表示は今は無い（「昼・夕暮れ・夜」だけ）。
- スズキ：仲間になると `SZ.joined`。屋内へ一緒に入る（v0.80）。
- 物語の進み：作業F の `stfMeetStage()`（`'done'` で仲間になった後）。仲間になった後の目標は「第二章：スズキとともに上志比を探索しよう」（目的地なし）。
- 会話の仕組み：今の会話（`dialog`）をそのまま使う。
- 素材：木材・石・屑鉄・縄など。**古い機械部品・専用部品・鉄の塊はまだ無い**。

## 3. 決めてほしいこと

1. **拠点本部に入れる時期**
   - A（おすすめ）：スズキが仲間になる前は、シャッターが重くて開かない（「一人では開けられない」と出る）。仲間になった後に、目標が本部を指し、2人で入ると調査が始まる。
   - B：今のように、いつでも入れる。調査と会話はスズキが仲間になった後だけ。
2. **スズキを待たせたまま入ったとき**（会話にスズキの台詞があるため）
   - A（おすすめ）：3か所を調べ終えても、スズキが屋内にいなければ会話を始めず、「スズキを呼んでこよう」と出す。
   - B：会話の場面でスズキを主人公のそばへ呼び寄せて、そのまま始める。
3. **初回修復の素材**（P3-A の案のまま暫定で入れてよいか）
   - 倉庫Lv1：木材12・石6・屑鉄4・縄4・専用「棚の金具」1
   - 総合作業場Lv1：木材16・石8・屑鉄6・縄4・古い機械部品3・専用「作業場の工具一式」1
   - 「古い機械部品」「専用部品」は新しい素材。P3-B では、本部の中と前庭（機械室・置き去りの軽トラ）で**必ず取れる**ようにし、町じゅうの解体（採用済み）は P3-C 以降で広げる、でよいか。
4. **倉庫と総合作業場が直ったら何ができるか**
   - 総合作業場：上志比で光明寺の作業台と同じ物が作れる（案）。
   - 倉庫：今は持ち物に上限が無いので、倉庫の役目が無い。案：①素材を預けておける置き場（光明寺と上志比で別々）②P3-C で持ち物の上限を入れるまでは見た目だけ。
5. **修理で進むゲーム内の時間**：1か所直すごとに何時間進めるか（案：倉庫は2時間の工期を3か所に分ける＝1か所約40分＝約33秒進む）。夜をまたいでもよいか。
6. **本部のまわりの獣**（§3.1「周囲の獣を警戒しながら」）：最初に本部へ来たとき、前庭にサルやイノシシを数体置くか（案：凶暴化したサル2体）。
7. **時刻の表示**：画面に「8:15」のような時刻を出すか（工期・勤務時間が分かりやすくなる）。

## 4. 進め方の案（作業ブランチ `p3b-hq`）

1. 屋内を「間取りの表」から作る形に直す（見た目は v0.80 と同じ）。ドア・手前の壁の扱い。
2. セーブ `p3`（調べた所・会話・修理の進み・開いた部屋）。古いセーブ・不正な値の読み込み。
3. 3か所の調査 → 拠点設立会話（指示書の台詞そのまま）→「上志比復興計画を開始」。
4. 初回の倉庫・作業場修復（修理する所・素材・時間が進む・直った見た目）。
5. 目標の表示（本部を指す）・入れる時期（質問1）。
6. テスト：新しい `tests/p3b-hq-browser.py`（入る・調べる・会話・修理・セーブとつづきから・地域の往復・スズキ）と、今のテスト一式。
7. 報告（指示書 §26 の15項目）→ ユーザーの試遊 → 承認後に main へ。
