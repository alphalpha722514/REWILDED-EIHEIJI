## 2. 新しい作り（`index.html`「v0.76 鱗の防具」）

- **体の形を測って沿わせる**：骨ごとに、体の表面までの距離を向きごとに表にする（`saProf`：骨の軸のまわりの円筒／中心からの球）。板と鱗はその表面から決まったすき間で作るので、体の輪郭に沿い、体にめり込まない。兜は髪・鉢巻を除いた頭の形、靴の板は靴の形だけを測る。肩当ては肩の丸みに合わせた楕円体。
- **厚みのある板**（`saPlate`）：外側・内側・ふちの壁を持つ本物の厚み。縁を少し厚く（`lip`）・明るく（縁の色）。変異は小さなへこみ（`dent`）。形は上下・左右で幅や高さを変えて、首まわりの切り欠き・下のとがり・角を落とした台形などにする（四角い板を貼るだけにしない）。
- **立体の鱗**（`saScale`）：丸い頭・とがった先・ふくらみ・中央の稜線・厚みの縁。先を少し浮かせて重ねる。
  - 変異：盾形の厚い鱗を、行ごとに数を変えて互い違いに重ねた「かたまり」（`saPatch`。大きさ・位置・向きを少し不ぞろいに）。大きな鱗は黒鉄の**爪**で留める。
  - 蒼鱗：大小の鱗を左右対称に1枚ずつ。銀の**縁金**で留める。板のふちの内側に細い**縁取り**（`saTrim`。精密な加工の見た目）。
- **変異の亀裂**（`saCracks`）：鱗のまわりから板の上へ、枝分かれしながら広がる細い線。淡く光る。
- **鋲**（`saRivet`）：変異の額当て・腹の板・膝上の板。
- **部位ごとに3つの形**（どれも体と同じ骨で動く skinning。骨ごとに重み1）：
  1. 本体：金属・鱗・亀裂を1つにまとめた形（頂点の色と「光る量」を持つ）。金属は傷・摩耗の絵（変異）／研ぎ目の絵（蒼鱗）。
  2. 輪郭：ほかのキャラクターと同じ墨の線（亀裂・縁取り・爪は除く）。
  3. 演出：変異は炎のようなゆらぎの殻、蒼鱗は鱗のふちの光の筋。
- **初めて着たときに作る**（`saEnsure`。8部位を全部作って計 約0.5秒＝1部位あたり平均 約70ms、画面のない Chromium・SwiftShader）。作るのは一度だけで、あとは見せる・隠すだけ。
- 体の形を測るとき、腕・脚の円筒の軸は高さごとの断面の真ん中にする。ただし点の少ない段（体の輪と輪の間に縫い目などの点が少しだけ入る段）は軸を決めず、前後の段から補い、1段だけ飛び出した軸は上下5段の真ん中の値にする（途中の版では蒼鱗の腿の板がギザギザに崩れていた）。
- 形の頂点は「体を作ったときの位置」（`skin.bindMatrix`）を基準に置く。`skin.bindMatrixInverse` は three.js が毎フレーム「今の位置」に書き換えるので使わない（途中の版で使っていて、歩いた後に初めて着ると防具が体から約160m離れた所に出ていた。確認のテストで見つけて直した）。
- 体の形・服・ほかの防具は変えていない。兜をかぶると、帽子と同じく鉢巻と頭の上の髪をしまう（横と後ろの髪は残る）。

## 3. 8種類の形（数はすべて暫定）

| | 変異した鱗 | 蒼鱗 |
|---|---|---|
| 頭 | 額から後頭部まで覆う厚い兜。厚い額当て（鋲16）・前後の稜。額に大きな鱗（爪4）とそのまわりの鱗、側頭部に小さな鱗のかたまり。亀裂が広がる。顔の前は開ける | 額・側頭・後頭を巡る細い輪、額から頭頂への稜に蒼鱗5枚（大→小）、側頭の小さな板。顔の前は開ける |
| 胸 | 首まわりを丸く切った厚い胸当て（胸のふくらみ）と、下の中央がとがる腹の板・背当て。胸の中央に大きな鱗（爪4）と鱗のかたまり、左右の胸・腹・背に大小の鱗。肩当ては外へ角張って張り出す板と下の板（腕の骨に付けて、胸と分ける） | 左右が分かれた薄い胸板（外の下を斜めに落とす）、中央の細い板に大きな蒼鱗、左右に大小の蒼鱗。細い背当て。小さな肩当てに蒼鱗 |
| 脚 | 太ももの前と外を覆う大きな板（大きな鱗とかたまり）、膝の上の厚い板（鋲）、膝の下の厚い板、すねの小さな板（小さな鱗）。膝そのものは開ける | 太ももとすねを部分的に守る薄い板（下がとがった台形）、大小の蒼鱗。膝は開ける |
| 靴 | 初期の革のブーツの上に、足の甲の大きな黒鉄の板と足首の上の板（足首は開ける）、革のベルト。甲から足首へ鱗が続く | 足の甲の薄い板に大きな蒼鱗、足首の小さな板に小さな蒼鱗 |

色：変異＝黒鉄 `0x4a4d53`・鱗 青緑 `0x22675a`〜`0x3f9480`・亀裂 `0x46d6b4`・ゆらぎ `0x2fe8b8`。蒼鱗＝銀灰色 `0x6f7a87`（縁 `0xbac4ce`）・鱗 青 `0x1d56c0`〜`0x4a90ea`・光の筋 `0x9fe0ff`。
