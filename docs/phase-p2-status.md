## 1. P2 の開発目標と、入れないもの

**目標（作業A〜F と、その後の追加）**
- A 地域の仕組み：光明寺と上志比を行き来できる。
- B 上志比の地図：実在の地形・道路・家並みを縮めて作り、歩いて探索できる。
- C 防具の作り直し：初期の服も着脱でき、帽子で髪が飛び出さない。
- D スズキのモデル。
- E スズキの仲間 AI：追従・蹴り3種・臭い・戦闘不能・救助、地域をまたいでついて来る。
- F 物語イベント：救援無線 → 出発 → 山王でスズキと変異したサルの初遭遇。
- 追加（ユーザー指示）：
  - 変異したサル（強敵）と「変異した鱗」。
  - 鱗の使い道：変換炉、蒼鱗／変異鱗の武器、鱗の飛去来器、鱗の防具。
  - かまどと食材・料理。

**入れないもの**
- 軽トラック・上志比の拠点施設・復興（P3）。
- 双子猿と廃工場（P4）。
- 第3〜5章。

## 3. 過去の確定仕様（P2 に関わるもの）

**地図と移動**
- 上志比の縮尺は案1（牧福島〜山王は0.8倍、山王〜市荒川を詰めて全体を光明寺の約2倍。11-12）。
- 範囲は九頭竜川の南側と市荒川まで（11-13）。倒れたら西の端で起きる（11-12）。

**スズキ**
- 見た目：主人公より少し小柄、大きな角の丸い四角の眼鏡（黒に近い青）、細マッチョ、濃い緑のズボン。**試作は未承認**。
- 台詞「おれはスズキ！探してる人がいるんだ。だから俺はここに残ったってかんじかな。」（11-12 修正）。
- 光明寺へもついて来る。上志比に残るよう指示もできる（11-12）。
- 「1回の戦闘」の区切り：周り15mに敵がいない状態が8秒続いたら終わり（暫定、11-12）。

**変異したサル**
- 今回（初遭遇）は逃げ去る。以降は凶暴化した猿の上位互換として出る（凶暴化した猿も今まで通り出る）。
- 凶暴化した猿の攻撃に加えて、固有の攻撃を持つ。
- 強敵で、貴重な素材「変異した鱗」を落とす。体力600。跳んでかわす・猛り狂うは残す。初遭遇でも鱗を1つ落とす。
- スズキを追う場面は短いカットにする。

**鱗**
- 変換炉で加工し、燃料は木炭（かまどで焼く）。
- 蒼鱗の武器は青い光と高い威力だけ。変異鱗の武器はまがまがしいオーラと代償あり（**代償は後で検討**）。
- 飛去来器は戻ってきて衝撃波を起こし、傷を与える。耐久は約10回。
- 防具は蒼鱗（高い防御）と変異した鱗（体力0.7倍・機動力・衝撃波はボタンで）。部位名は頭部・胸部・脚部・足部装甲。
- **防具の形は不採用で、改善要求待ち。**

**かまど**
- 食料は残し、どの食材のかわりにもなる。料理は組み合わせで出やすさが決まる（固有のレシピなし）。
- 料理はかまどだけで、かまどは最初から築ける。料理も時間がかかる。
- 慧心は必ず精進料理を作る。肉の料理は強くしすぎない。

## 7. 想定される技術的問題

1. **上志比の採集・伐採の保存。**
   - 今は光明寺の木・岩の番号で保存しているので、上志比の分を別に持つ必要があります。
   - 上志比は入るたびに作り直すので、取った物が戻らない形にする必要があります。
2. **獣と地域の行き来。**
   - 地域を出ると獣は消えます。上志比の獣は入るたびに配り直すことになります。
   - 戦闘中に地域を出たときの扱い（逃げられるか）を決める必要があります。
3. **スズキの引っかかり。**
   - 上志比は家と田畑が多いので、仲間が建物に引っかかりやすいです。
   - 一定時間動けなければ主人公の後ろへ移します。
4. **iPhone の重さ。**
   - 上志比で獣とスズキと光の粒が同時に出るので、実機での確認が必要です（ユーザーにお願いします）。
5. **防衛戦の測定の乱数。**
   - 新しい物を初めて作ると乱数が進みます。測定ツールでは先に作るようにしています（`docs/p1-sim-baseline.md`）。
   - 新しい種類の物を足すたびに、同じ対策が要ります。
6. **テストのゆれ。**
   - 地域の往復のテストは、ほかの重い処理と同時に回すと、遅れて作られる物の数え方で落ちることがあります。
   - 1つずつ回すと通ります。

## 8. 推奨する開発順序

1. **4の質問を決める**（ユーザーと ChatGPT）。特に、物語の台詞（1〜4）と上志比の獣・変異したサルの出方（7・8）。
2. **上志比の獣と採集**（台詞の承認がなくても作れる）。
   - 獣の配置と、変異したサルの普段の出現。
   - 採集・伐採と、その保存。
   - これで鱗の装備が本編で手に入るようになります。
3. **スズキの見た目の承認** → 正式な形に。
4. **スズキの仲間 AI**。仮の台詞のまま先に作れます。
5. **物語イベント**（台詞の承認後）。
   - 救援無線 → 出発 → 山王で初遭遇のカット → 戦闘 → 仲間に。
6. **試遊**（PC・iPhone はユーザー）→ 調整。
   - 鱗の装備とかまどの数値、変異したサルの強さ、上志比の獣の多さ。
7. 鱗の防具の形（改善要求が届いたら）、武器の形の差し替え（届いたら）は、並行して入れます。
