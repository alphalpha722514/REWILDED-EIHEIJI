## 3. 指示書とコード・指示書どうしの食い違い（変えずに報告）

1. **宗一との出会い**：§7.3・§11 は「主人公が川辺で**釣りを始めたとき**」だが、釣りは **P3-D**（§24）。P3-C の中だけでは出会いが起きない。
2. **Lv3 の素材**：総合加工設備 Lv3 の「山地の硬木」「川底の鉱石」の取れる所は、P3-D（川）・P3-E（森林）で作る。P3-C の中だけでは Lv3 に届かない。
3. **住居の定員と住民の数**：Lv2 は定員4人・Lv3 は6人（§4）だが、名前のある住民は澄江・リオ・宗一の3人。Lv2→Lv3 に必要な住民の数も書かれていない。
4. **澄江の救助のスズキの台詞**：§10（リオ）には「スズキが同行中の場合のみスズキの台詞を出す」とあるが、§9（澄江）には書かれていない。澄江の場面にもスズキの台詞（「よし、これをどかせば……って、結構重いな！」）がある。
5. **ト書き**：「主人公が障害物を取り除き、扉が開く。」（§9）・「主人公が棚を動かす。」（§10）は、台詞ではなく動作の説明。
6. **Lv2 に着いたあとの「見張りがサルの大群を報告」**（§4）と、上志比の襲撃（§21.1）は **P3-F**。P3-C では Lv2 に着いても何も起きない（P3-F でつなぐ）。

## 4. 決めてほしいこと

1. **住民の見た目**（§2）：澄江は A・B・C、リオは A・B・C、宗一は A・B のどれにするか。直してほしい所（色・帽子・ゴーグルの有無など）があればそれも。
2. **宗一との出会い**（§3 の1）
   - A（おすすめ）：P3-C では宗一の見た目の承認とデータの枠（発見済み・協力者・加入依頼完了・正式居住・担当業務を別々に記録）だけ作り、出会いと加入依頼は P3-D の釣りと一緒に作る。
   - B：P3-C で、釣りの前の仮の出会い（川辺で話しかける）と加入依頼（釣り道具の修理と紛失道具の探索）を先に作る。
3. **名前のある3人のほかの住民**（§3 の3）
   - A（おすすめ）：共同住居の依頼「避難住民の手がかり」で見つかる**名前の無い避難住民**（今の画風で Claude が作る。新しい台詞は作らず、短い案内文だけ）を足し、Lv2→Lv3 には住民4人（定員いっぱい）を条件にする。
   - B：住民は3人だけ。Lv3 の条件に住民の数を入れない。
4. **澄江の救助でスズキがいないとき**（§3 の4）
   - A（おすすめ）：§10 と同じ決まりにする（スズキがいないときはスズキの台詞を出さない。ほかの台詞はそのまま）。
5. **ト書きの扱い**（§3 の5）
   - A（おすすめ）：プレイヤーが自分でする動作にする（障害物を「調べる」で数回どかす・棚を動かす）。そのあと、ト書きは地の文として出す（P3-B の会話と同じ）。
   - B：動作は自動で、ト書きの文だけ出す。
6. **新しい台詞**：依頼を出すときの澄江の言葉・リオの修理の手伝いの途中・住民の普段の一言など、指示書に無い台詞が要る。
   - A（おすすめ）：ChatGPT に下書きを作ってもらい、ユーザーが承認する（作業F と同じ）。承認まではゲームの中では案内文だけにする。
   - B：P3-C では台詞を足さず、案内文（調べた結果の表示）だけにする。
7. **必須の復興依頼**（§4「指定復興依頼の達成」）：どの依頼をレベルアップの必須にするか。
   - 案：Lv1→Lv2 は「基本防衛設備：侵入経路と獣の痕跡の調査」（P3-F の襲撃につながる）。Lv2→Lv3 は「車両整備場：整備工場の特殊部品の回収」。ほかの依頼は任意（報酬だけ）。
8. **住民の仕事**（§6「仕事内容」）：案は「建設」（工事の担当）・「回収」（Lv2 の収集運搬施設：町の金属・素材を少しずつ集める。P3-A で採用した「取り切った後は住民の回収」）・「見張り」（基本防衛）・「農園」（Lv2）・「整備」（リオ：車両整備場で KEI truck の修理と改修を少し安く）・「研究」（リオ：Lv3 の総合加工設備）。数（1日に集まる量など）は暫定で決める。
9. **場所**（§27-4 のとおり、地図の建物の ID は承認が要る）：澄江の家は本部の近くの住宅地の家、リオの整備工場跡は本部の東 約420m の細長い建物（地図の bld[14]、34m×12m）か、南東 約610m の大きな建物（bld[3]、29m×70m）。Claude が選んで画面で見せ、承認をもらう形でよいか。
10. **施設の働き**（指示書に中身が無い所）
    - 共同住居：住民が寝起きする（夜は部屋にいる）。主人公もここで眠れる（時間を朝まで進める）ようにするか。
    - 基本防衛設備：P3-C では建てるだけにし、働き（襲撃を防ぐ）は P3-F でよいか。
    - 総合加工設備（Lv3）で作れる物：「武器・防具・車両・建材の高度加工」（§4）の中身が決まっていない。

## 6. 想定される技術的な問題

- **上志比は離れると片付く**：住民・工事中の形は、上志比に入るたびに作り直す（P3-B の屋内と同じ）。進み具合はデータだけで持つ。
- **住民の数と重さ**：住民はスズキと同じ骨のある形。6人まで増えると描く数が増えるので、遠い住民は描かない（v0.81.1 の獣と同じ考え方）。
- **工事の時計**：§5.6 の勤務時間（8:00〜17:00）は、P3-B の時刻（tod 100〜550）で数える。物語の場面では時計が止まるので、そのあいだ工事も止まる。
- **荷台からの納入**：荷台の素材は「建設地から12m 以内」で使える（v0.78）。上志比の建設地は本部のまわりなので、車を本部の前に止めればよい。
- **iPhone**：管理画面の4つのタブとカードは、作業台の画面と同じ大きさにそろえる（画面の配置のテストに足す）。
