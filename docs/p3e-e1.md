> 基準：main **b5b7e31**（v0.86.2）。準備 `docs/p3e-plan.md`（2026-11-20 14:55 ユーザー回答：7つとも案のまま。§5）。

## 1. やったこと（要点）

- 上志比の建物 833軒のうち、近くの家だけを**細かい家**に建て直す。遠くは今までの形のまま。
- 約80m 四方の区画ごとに、近づくと作り（1フレームに少しずつ。5ms まで）、離れると捨てる（P3-D の河原と同じ考え方）。
- 細かい家を出している間、その家の今までの形は**頂点をつぶして隠す**（輪郭線の形も。離れると元の位置に戻す）。
- 当たり判定（家の大きさ・向き）は今までのまま。壊れた家の記録（がれきの場所・番号）も変えない。
- 用途（地図に無い）を大きさ・道・集落かどうかから決めて、**19種類の形**で建てる。
- 正面はいちばん近い道に向ける（足場の四角は同じ。90°・180° 回すだけ）。
- 道と庭の小物：
  - 道：コンクリートの電柱と電線、側溝、カーブミラー、止まれ、矢羽根、ゴミ集積所、消火栓の標識。
  - 庭：ブロック塀・生垣と御影石の門柱、手入れされた松・シュロ・つつじ、灯籠、置き去りの軽トラック・乗用車、自転車、スコップとスノーダンプ、耕運機・コンテナ・タイヤ。
- 荒れ（§17.4）：
  - 伸びた草（家のまわり。風で揺れる）。
  - 壊れた家の被害の重ね（板を打ちつけた窓・ブルーシート・破られた戸口・規制テープ・がれき）は、今までと同じ所に同じ見た目で。
  - 落ちた瓦、倒れたバケツ、倒れた自転車、猪が掘り返した土、壁のつた、割れた窓（荒れ具合で増える）。
- 設定に「**描く細かさ：標準／軽量**」（2026-11-20 ユーザー「よい」）。
  - 軽量は細かく描く範囲を狭くし（約95m→約50m）、庭の小物を半分にする。
  - スマホ・タブレット（画面が小さいか指で操作する端末）は、最初は軽量。押して切り替えると保存する（`localStorage` の `eiheiji_detail`）。

  - 温室（green）。

## 4. 区画ごとに作る・捨てる（`e1Init`・`e1Update`・`e1Step`・`e1Drop`）

- 上志比を作るとき（`kamishihiBuild` の 5）建物）に、今までの形の中の**家ごとの頂点の範囲**を覚える（`e1rng`）。
- 区画は 80m 四方（`E1.DC`）。家・電柱・矢羽根・交差点を区画に分けておく（`e1Init`）。
- カメラから区画までの距離で、作る・捨てるを決める。

  | 設定 | 作る距離 | 捨てる距離 | 庭の小物 |
  |---|---|---|---|
  | 標準 | 95m より近い | 135m より遠い | すべての家 |
  | 軽量 | 50m より近い | 80m より遠い | 半分の家 |

  距離はどれも暫定。
- 1区画を4つの段階に分けて、何フレームかかけて作る。
  1. 家と庭：1フレーム 5ms まで。
  2. 道の小物。
  3. 形にする。
  4. 輪郭線を作って並べ、今までの形を隠す。
- 輪郭線（反転した殻）は `inkGeo` と同じ作り方。同じ位置の頂点を数の鍵でまとめて速くした（`e1InkGeo`）。
- 区画の中の描き分け（暫定）：

  | 描くもの | 区画までの距離 |
  |---|---|
  | 輪郭線 | 85m まで |
  | 細い物（板の目・瓦の筋・電線・側溝など） | 110m まで |
  | 草 | 60m まで |

- 隠し方：今までの形の、その家の範囲の頂点を1つの点に集める（三角形の面積が 0 になり描かれない）。輪郭線の形も頂点が1対1なので同じ範囲を集める。捨てるときに覚えておいた位置へ戻す。
- 小物の当たり判定（電柱・カーブミラー・止まれ・塀・生垣・車・松・シュロ・灯籠・ゴミ集積所・家の前に出た柱）は区画を捨てると外す。
  - 名前（tag）は `pole`・`wall`・`prop`・`post`・`tree`・`rock`。
  - `house` は使わない。家だけを見る判定（`f10HouseBlock`・サルの視線 `kfLOS`）は今までどおり。
  - `pillar` も使わない。ヌシの戦いの大岩の名前なので。
- 小物を置かない所：
  - 道の上・川・ほかの家の足場。
  - 試作の範囲（`p3aFree`）。
  - 依頼の場所と Lv2 の施設の場所（`E1.avoid`）。
  - 採集・がれきの場所（`E1.na`）。
  - サルの要塞のまわり。
- `E1.off=true` で細かい家を出さない（比べるとき・試験のとき）。

| 場所 | 置くもの（数・割合はどれも暫定） |
|---|---|
| 集落の道（生活道路・県道など。家が 32m 以内にある所） | コンクリートの電柱（足場ボルト・変圧器・番号札）を道の片側に 30m ごと。となりの電柱と電線（4本・たるみ） |
| 幹線（県道・国道） | 矢羽根（赤白の矢印）を電柱と反対側に 40m ごと |
| 集落の中の道の両側（家が 22m 以内） | 側溝（コンクリートの蓋）を 2m ごと |
| 交差点（道の端が重なる所・家が 30m 以内） | カーブミラー 6割・止まれ 2.5割。ゴミ集積所 2割・消火栓の標識 1.5割 |
| 住まいの家の前（道まで 0.8〜14m） | 玄関から道までのコンクリートの通路。道まで 5.6m 以上なら 4割で軽トラックか乗用車を置く（広い通路） |
| 住まいの家の前（道まで 3.4m 以上・6割） | ブロック塀（7割）か生垣（3割）。入口はあける。入母屋と妻入りの家は御影石の門柱 |
| 住まいの家の両わき | 手入れされた松（入母屋・妻入り・トタンの家）・シュロ・つつじの茂み・灯籠（入母屋・妻入り） |
| 玄関の横 | スコップとスノーダンプ（4割）・自転車（車の無い家の3割。荒れた家は倒れている） |
| 作業場・倉庫の前 | 耕運機・コンテナ・タイヤ |
| 荒れ（荒れ具合 0〜3 で増える） | 伸びた草（家のまわり）・落ちた瓦（2以上）・倒れたバケツ（1以上の半分）・猪が掘り返した土（1以上の 45%）・壁のつた（2以上の 6割）・割れた窓（窓の 12%＋荒れ具合ごとに 12%） |

- 壊れた家の被害の重ね（荒れ具合 2：板を打ちつけた窓・ブルーシート、3：破られた戸口・規制テープ・がれき）は、今までの `houseDamage` と同じ形を、**元の向き・大きさの座標で**描く。がれきを探る場所（`DAMAGED` の正面の向き）と合う。泥と爪あとの貼り絵（デカール）は今までのまま壁の上に残る（壁の面は同じ所にある）。

## 6. 設定「描く細かさ：標準／軽量」（§20.4）

- 一時停止の画面の「高画質の影」の下に「描く細かさ：標準」のボタン。押すたびに 標準 ⇔ 軽量。
- 切り替えると、細かい家をいったんすべて捨てて、新しい範囲で作り直す。
- 保存は `localStorage` の `eiheiji_detail`（「高画質の影」の `eiheiji_shadow` と同じ。セーブには入れない）。
- まだ選んでいないときは、スマホ・タブレット（`LOWQ`：指で操作するか画面が小さい）は**軽量**、PC は**標準**。
- 木の数を減らすのは E-2（森林）で足す（今の森はまだ変えていない）。
