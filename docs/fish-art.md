## 0. 要点

- **魚11種・アラレガコ・ヨシノボリ**：前は箱を3〜5個並べた形だった。体を「断面（背・腹・幅）を尾から頭までつないだ形」にし、ひれ（背びれ・あぶらびれ・尾びれ・しりびれ・胸びれ・腹びれ）を薄い板で付け、色と模様を種類ごとに描いた絵（256×256）を貼った。
- **水生生物6種**（カワゲラ・トビケラ・ヤゴ・サワガニ・モクズガニ・カワニナ）：前は箱を並べた形。球・円柱・円錐・石を組んで、色を塗り直した。
- 使う所：
  1. 図鑑の絵（魚類・水生生物）
  2. **持ち物・手持ちバーの生の魚とモクズガニ**（前は料理の椀の絵になっていた。前からの不具合）
  3. アラレガコを釣ったときの近景（新しい形・ゆっくり体をくねらせる。岸が水面より高い所では魚が地面に埋もれていたので、高さを岸に合わせ、カメラを少し近づけた：2.6m → 2.2m）
  4. **新しく足した見せ方（2つ）**：釣れた魚を主人公の前に約2秒吊るして見せる／石の下で見つけた生き物を水際に約3秒出して見せる（どちらも見せるだけで、遊び方・数・セーブは変えていない）
  5. 観察地点「瀬のアユの群れ」の水の中の影（前は箱2つ）
- 状態：**コードに存在・main にコミット済み・公開（GitHub Pages）・PC（画面のない Chromium）で確認**。PC の実機と iPhone は未確認。

| アユ | 細長い・大きな背びれ・あぶらびれ・二又の尾 | 背は緑がかった灰色・腹は白・えらの後ろに黄色い斑点・ひれは黄みがかる |
| ウグイ | ふつうの体型 | 婚姻色：朱色の帯3本と黒い帯・下のひれは橙 |

| カワムツ | 目が大きい | 太い濃紺の帯・腹の前が橙 |

| ヤマメ | あぶらびれ・浅い二又の尾 | **パーマーク**（楕円の斑点9つ）・背の小さな黒点・桃色の線 |
| イワナ | あぶらびれ・ほぼまっすぐな尾 | 暗い緑褐色に**白い斑点**・橙の斑点・橙の腹・下のひれの**白い縁と黒い線** |
| ニゴイ | 細長い・**とがった長い口先**・ひげ1対 | 銀灰色・横の黒い斑点 |
| カマツカ | 細長い・**平たい腹**・とがった口先・目が上寄り・ひげ1対 | 砂色に背の鞍の模様と横の斑点・ひれに帯 |
| アラレガコ | **平たく幅の広い頭**・目は頭の上・**扇のような大きな胸びれ**・背びれ2つ・まっすぐな尾 | 石のようなまだら・背の黒い鞍3つ・あられのような白い点・ひれに帯 |
| ヨシノボリ | 頭が大きい・背びれ2つ・丸い尾・大きな胸びれ | 茶色に斑点・ほおの橙の線・第1背びれの青い点 |
| カワゲラ（幼虫） | 平たい体・長い触角と尾2本・翅の芽・横に張った脚 | 茶色と淡い帯 |
| トビケラ（幼虫） | **小石を綴った筒の巣**から頭と脚を出す | 石は灰色・茶色いろいろ |
| ヤゴ | 大きな目・幅の広い平たい腹（節の線）・翅の芽・脚 | 緑褐色 |
| サワガニ | 丸い甲羅（H の溝）・右のはさみが大きい | 赤茶・はさみの先が淡い |
| モクズガニ | 甲羅の横にとげ・長い脚（毛）・**はさみに黒い毛（手袋のよう）** | 緑がかった茶・はさみの先は白 |
| カワニナ | **細長い巻き貝**（約6巻き・先は削れて白っぽい）・殻の口から体と触角 | 黒褐色・巻きの筋 |

- 色と形は実物の写真の一般的な特徴から決めた（婚姻色・パーマークなど）。種類の見分けを優先して、少し強調している。
- ひげ・目・口・えらぶた・側線も描いた。

## 2. 作り（コード）

| 関数 | 中身 |
|---|---|
| `FISHART` | 種類ごとの形の数（体高・幅・頭の細り・目・口・ひれ）と模様の描き方 |
| `fishGeo(id, det)` | 形。`det 1`：図鑑・持ち物・近景（体 44×24 の網）、`det 0`：遠くの群れ（12×8）。種類ごとに1つ作って使い回す（群れは地域の後片付けで捨てる使い捨て） |
| `fishTex(id)`・`fishMat(id, toon)` | 模様の絵（256×256 の canvas。上半分が体の横を開いた絵、下の帯がひれ）と材質（図鑑は Lambert・ゲームの中はトゥーン） |
| `aquaGeo(id)` | 水生生物の形（色を頂点に塗る。種類ごとに1つ） |
| `fishIconObj`・`aquaIconObj` | 図鑑・持ち物の絵の向き |
| `p3dFishMesh`・`p3dShowCatch`・`p3dShowAqua`・`p3dShowTick` | アラレガコの近景・釣れた魚を見せる・見つけた生き物を見せる・揺らして消す |

## 4. 重さ

| もの | 三角形 | 備考 |
|---|---|---|
| 魚1種（図鑑・近景） | 2,248〜2,268 | 種類ごとに1つ作って使い回す。模様の絵 256×256 を種類ごとに1枚（13枚・作るのは使うときだけ） |
