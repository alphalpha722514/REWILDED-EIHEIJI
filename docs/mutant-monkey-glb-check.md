## 3. 修正方針（案）
1. **向きと原点**：前を +Z、足の裏を y=0 にする。大きさは通常の猿（高さ 1.56）の 1.2倍（高さ 1.87、主人公 2.05）で並べた画像を作った（**暫定**）。
2. **小さな三角形1枚**を消す。
3. **尾**：骨を3つ入れ、休みの形でも後ろ下がり（水平から30〜40°下）に持ち上げる。板状の薄い向きを少しふくらませて（左右に1.6倍ほど）丸みを出す。形はスクリプトで直せる（作り直し不要）。
4. **手の指先が埋まる件**：腕の骨の休みの角度を少し上げる（または歩きの動きで手が地面に触れる高さに合わせる）。
5. **生殖器**：ゲームでは目立たないよう、股の形をならして消すのがおすすめ（**ユーザー確認**）。
6. **三角形とテクスチャ**：案A。

## 4. 実装の方針
- 本編に GLB を読む仕組みを足すより、猪・ヌシと同じく、**ゲーム用の小さな形式**（位置・法線・UV・骨の重み・三角形を詰めたもの＋色テクスチャ JPEG）に変換する。
- 別ファイル（`data/models/mutant-monkey.js` の予定）にして、出番の前だけ読み込む。
- 動きは、猪・ヌシと同じく GPU で骨を動かし、**動きはコードで作る**（決まった動きのデータは持たない）。

骨（約19本）：腰・背・胸・首・頭、左右の 肩〜上腕・前腕・手、左右の 太もも・すね・足、尾3。
- 重みは、骨からの距離で付けてから、面のつながりに沿ってならす。
- 尾は脚と、左右の手足は互いに、まざらないよう分けて付ける。
- 確認用に動きの画像を作り、ユーザーの承認を得る。

### 既存の敵 AI の流用
| 必要な動き | 流用できる所 |
|---|---|
| 待機・歩く | 通常の敵の待機・うろつき・気づく（共通の処理） |
| 四つ足で走る | 追いかけ（共通）。足の運びは新しく作る |
| 飛びかかり | 通常の猿の「ため（wind）→突進（dash）」 |
| ひっかき | 熊の「ため→振りかぶり（strike）」の型（近い距離で前腕を振る） |
| ひるみ | 共通の怯み値（POISE）・のけぞり・押し返し |
| 倒れる | 共通の倒れる処理（倒れた後の扱いは決める必要あり） |

新しく作るもの：
- スズキを追う（主人公以外を狙う）
- イベントでの出現と終わり
- 新しい種類 `mutant` の動き（骨の回し方）
- 強さ（体力・攻撃力・速さ。**暫定**値から）

既存の通常の猿（`makeMonkey`）と双子猿ボスには手を入れない。

### 加工の中身（両方の版に共通）
- **股：** 出っ張り（43頂点）を、まわりを止めたまま「隣の平均」になる形に解いて縮め、平らにした。その部分の色は、まわりの毛の色で塗り直した。
- **尾：** 元の尾は、上の約3分の2がお尻のくぼみに貼りついていて、そのまま持ち上げると体との間に膜ができる。そこで次のように付け替えた。
  - 元の尾（177頂点）を、股と同じやり方で体に収めた。
  - 新しい丸い尾（250 三角形）を付けた。付け根は水平より少し上向きで、先へ行くほど垂れ、先は丸く閉じる。長さは元とほぼ同じ。
  - 正面から脚の間に見えない角度にした（初めは後ろ下がり35°で試したが、正面から脚の間に垂れて見えたのでやめた）。
  - 毛の色は、元の尾の毛の部分（テクスチャの元の尾の場所。元の尾は体に収めたので見えない）にお尻の毛の色ですじを描き直し、そこを使う。
  - 尾は軽量化で減らさない。
- **向き・大きさ：**
  - 前を +Z、足の裏を y=0 にした。原点は体の中心（元の x=−0.05）。
  - 倍率は 2.024 で、そのまま版の高さは 1.872。
- **軽量化：** 尾以外を meshoptimizer で減らした。そのまま版 5,794・デフォルメ版 5,791 三角形。色テクスチャ 1024（JPEG）、ORM・法線マップは外した。
- **離れた小さな三角形（頭の上、7mm 相当）：** 辺でほかとつながっていたため、今回の消し方では消えていない。見た目には出ない。
- **手の指先が足の裏より下に出る件：** 骨を入れる段階で直す。
