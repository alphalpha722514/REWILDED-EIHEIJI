## 2. 作り方（作り直すとき）

```
python3 tools/kamishihi/fetch.py          # 取得（取得済みなら何もしない。取り直しは --force）

```

- `osm.py`（OSM の読み込み）、`dem.py`（標高。5m を使い、欠けている所は 10m）。

## 3. 座標（光明寺の地図と同じ決め方）

光明寺の地図の座標は、下志比・光明寺の駅と踏切の位置から逆算した。

- 東西 `x = 0.8 × 東へのメートル`（原点 経度136.3476）、南北 `z = −0.8 × 北へのメートル`（原点 緯度36.089。z が大きいほど南）
- 高さ：光明寺と同じ変換（標高から。光明寺の地図の高さと照らして ±0.5 で合う）
- 光明寺と重ならないよう、上志比は `x = 5000` から東に置く（地域の仕組みで `x > 4000` はほかの地域）。

## 4. データの中身（`data/kamishihi/kamishihi-map.js`）

`window.KAMISHIHI_MAP = {…}`。約2.5MB（gzip で約0.66MB）。上志比へ移るときだけ読み込む（本編 `index.html` には入れない）。

| 項目 | 中身 |
|---|---|
| `grid` | 格子（x0=5000, z0, 間隔3.2, 814×470） |
| `terrain` | 高さ（uint16、`(h+40)×50`、base64） |
| `cls` | 地面の種類（4bit。0 草地／1 森／2 水／4 田畑／5 家の周り） |
| `water` | 九頭竜川の水面の高さ |
| `roads` | 657本（種類・幅・橋・トンネル・名前・点列） |
| `rails` `streams` `farms` | 線路15・小川36・田畑593 |
| `bld` | 建物833（中心・長さ・幅・向き・面積・集落か） |
| `pts` | 駅（山王・越前竹原）・踏切・寺社 |
| `play` `arrival` `exitWest` | 遊べる範囲（四角）・着く所（国道416号の西の端から30）・光明寺へ戻る出口（西の端） |
| `reach` | 歩ける所（1マス1ビット。川の南側と市荒川まで） |

森は「400m 四方の一番低い所より14m以上高い」か「傾きが0.22より急」な所（山すそと川岸の崖）。

## 5. ゲームの中の作り（`index.html` の「v0.60（P2 作業B）上志比」）

| もの | 作り方 |
|---|---|
| 地面の絵 | 2048×1182 の絵に、地面の種類・田畑（色を少し変える。一部は荒れた畑）・家の周り・小川・道・線路を塗る。光明寺と同じ細かい模様を重ねる |
| 地形 | 179×179 の区画ごと。遠くは粗い形（森は木の高さに盛る）。近く（区画の端から120以内）だけ細かい形を作り、離れたら捨てる（メモリを抑える） |
| 九頭竜川 | 水面。**川には入れない**（入ると直前の岸に戻り「九頭竜川は深くて入れない」） |
| 道・線路・小川 | 光明寺と同じ帯の作り方（白線・中央線・橋の欄干と橋脚） |
| 橋 | **橋の上を歩ける**（橋の上は橋の高さを地面にする） |
| 建物 | 光明寺と同じ `genBuilding`（家の種類・荒れ具合）。当たり判定つき |
| 木 | 森の所に約2万本（道と家の近くは除く）。近くは細かい杉、遠くは円錐。範囲内の木に当たり判定 |
| 出口 | 光明寺の東の端（国道416号、x≈612）に「この先 上志比」の看板。**防衛戦を終えると**、そこへ歩くと上志比へ移る（終える前は「まだ行く時ではない」）。上志比の西の端へ歩くと光明寺の東の端の手前に戻る。着いてすぐ戻らないよう、一度離れてから出口に入ったときだけ動く |
| 全体地図・ミニマップ | 上志比の絵を使う。駅・「← 光明寺」・出典を表示。光明寺だけの凡例は隠す |
| 目的の表示 | 防衛戦のあと（光明寺）：「東の出口（国道416号）から上志比へ向かえる」＋出口への矢印。上志比：「上志比を歩いて調べる（光明寺へは西の出口・国道416号から戻れる）」 |
| 区域の表示 | 上志比は「警戒」。荒れ具合 0.5（**暫定**。光明寺の南の荒れた所は 1） |

### 暫定の値
- 荒れ具合 0.5、木の密度（森のマスの約30%）、細かい地面の距離 120、出口の半径（光明寺 11・上志比 12）、着く所（西の端から30）。
- 目的・看板の文言（物語の台詞ではない案内の文。差し替え可）。
