## 0. 要点

- 今のコードに**釣りの仕組みは無い**。P3-A で、拠点の北の九頭竜川の河原（約220m×240m）に**釣り場の目印3つ**（平たい岩と杭）と、深さで色の変わる水面・川底の石・ヨシ・護岸を作ってある（`P3A.RIVER`・`P3A.fishSpots`）。
- 上志比の地図には、九頭竜川の本流（水の区画）のほかに、**名前のある支流6本**（河内川・南河内川・岩屋川・吉峰川・畝見川・犀川。幅7m）と、**名前の無い水路20本**（幅1.6〜2.2m）がある（地図データの `streams`）。これで「本流・支流・浅瀬・深場・流れの速い所・ゆるい所」を分けられる。
- 時刻（P3-B の時計）と天気（晴れ・霧・雨）は今ある。季節は無い。
- 料理はかまど（光明寺）で、鍋に入れた肉・野菜・米の割合で料理が決まる仕組み（v0.66）。魚料理はここに足す。
- **指示書で「承認後に実装」とされているもの**：釣り竿の性能（§13.5・§15.1）、魚料理の一覧（§16.1）。下に案を出す（§4・§5）。決まるまでは仮の値（暫定）で作り、main へ入れる前に直す。

## 2. 釣りの操作（§13.2 の案）

1. 釣り竿を持っていて、上志比の**水際**に立つと「釣りをする」が出る（E キー／調べるボタン）。
2. **投げる**：押している間、投げる距離のゲージが行き来する。離すと、カメラの向きへ投げる（PC はマウス、iPhone は親指を離すだけ）。
3. **待つ**：浮きが水に浮かぶ。数秒〜十数秒でアタリ（浮きが沈む・「！」・音・スマホは振動）。
4. **合わせる**：アタリから**通常の魚は約1.0秒、珍しい魚は約0.7秒**のうちに押す（§13.2 のまま）。早すぎると逃げる。
5. 成功すると短い引き寄せの演出（張力の管理は無い）→ 釣れた魚（名前・大きさ・図鑑に初めてなら「新しく記録」）。アラレガコなら専用の場面へ。
- やめるときは移動するか Esc／戻るボタン。PC とスマホで同じ1ボタン。

## 6. 宗一の出会いと加入依頼（§11 の具体化の案）

1. 上志比の川辺で**初めて釣りをした**（1匹釣ったとき、または初めて投げたとき）とき、宗一が声をかける（P3-C で承認した見た目 B：胴長・紺の上着・首にタオル・手に釣り竿と腰の魚籠）。
2. 宗一の相談：「獣に追われて川に道具を落とした。竿を直したいが部品が無い」。
3. 失くした道具を探す（3か所。川辺・河原の小屋・支流の橋の下など）：**道具箱**・**リール**・**仕掛けの箱**。1つは川の浅瀬の石の下（どかす）。
4. 直す：見つけた道具＋素材（竹2・縄2・古い機械部品1。暫定）を宗一に渡す。
5. 宗一が**協力者**になる（住居定員を使わない。Lv1→Lv2 の「住民2人」には数えない：§8.2）。釣りの相談・図鑑の報告・アラレガコの報告ができる。
6. 復興 Lv2 で空き部屋があれば**正式居住**（本部2階。仕事を任せられる）。発見・協力者・加入依頼完了・正式居住・担当を別々に記録する（P3-C で作った枠 `p3c.soichi`）。

- 宗一の台詞は §15（アラレガコ報告）だけが正式。**出会いと加入依頼の台詞は Claude が書いて一覧で出す**（P3-C と同じ扱いにしたい：§8 の問い3）。

## 7. アラレガコ（§14・§15）

- 目撃：本流の石の多い瀬で「川底をのぞく」と、まれに石に紛れた姿が見える → 図鑑に「目撃」。
- 釣れたとき：専用のカメラで姿を見せる → その場ですぐ川へ戻す（持ち物に入らない） → 「釣った後に川へ戻した」を記録。
- 宗一に報告（「釣った後に川へ戻した」記録があるとき）：§15 の台詞をそのまま流す → 川守の釣り竿 → 図鑑に「保護報告済み」。
- 保存：`observed`・`caughtReleased`・`reported`・`rodRewardClaimed` を別々に（§14.5）。報酬は1回だけ。報告のあとも、ごくまれにまた釣れる（毎回すぐ戻す）。
